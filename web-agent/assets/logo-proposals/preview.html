Yaahlan 智能工具 Agent · Logo 方案（5 选 1）

统一底：蓝→青渐变圆角方块（#5B8CFF → #42D3B2），与现有 UI accent 一致

方案 1 · 工具台栅格

推荐 · 与「工具平台」语义最贴合

2×2 栅格：三格代表 MOA/Admin/Tunnel 等能力模块，第四格星芒代表 AI 调度。当前 logo.js 即此方案。

浅色背景

方案 2 · 对话气泡

强调 Web Agent 对话入口

圆角气泡 + 三点输入态 + 右下角星芒。一眼看出是「能对话的智能助手」，弱化工具台概念。

浅色背景

方案 3 · Y 字母标

品牌记忆点最强

Yaahlan 首字母 Y：上叉像路由分发，下竖 + 圆点像执行落点。极简字母标，适合 favicon 与侧边栏小尺寸。

浅色背景

方案 4 · 轨道节点

强调 Agent 调度多能力

中心白圆 = Agent 核心，三颗卫星 = 外部工具/模块，连线暗示编排与分发。偏「平台中枢」气质。

浅色背景

方案 5 · 闪电执行

强调「一键跑能力 / 快」

单枚闪电符号，语义是快速执行 registry 能力。最简约，但与其他 AI 产品闪电图标相似度较高。

浅色背景
