### 使用说明

- **平台**：[alpha Kibana Discover](https://alpha-kibana.wemomo.com/alpha-public/app/discover)（索引 `yaahlan-log*`）
- **等价接口**：`POST …/internal/bsearch?compress=true`（与 Discover 搜索框短语 **AND** 一致）
- **时间**：默认东八区**当日**；`--hours` 为滚动窗口
- **鉴权**：内网多数场景无需 Cookie；403 时在 `Log/.env.local` 配置 `KIBANA_COOKIE`
- **与 Tunnel**：Tunnel 看客户端 HTTP；Kibana 看**服务端**应用日志（IM 推送、MOA 调用栈等）

<a id="discover_json"></a>

### 日志-JSON输出

- **功能**：结构化 JSON（total、hits[].line/timeBeijing），供 Agent 解析
- **提示词**：
  - `日志 JSON <keyword>`
- **命令**：

```bash
python3 Log/log_execute.py --today --phrase <keyword> --output json --size 50
```

### 日志-房间IM推送

- **功能**：roomId + eventId（如 811 热度榜、808 房间 CUSTOM IM）组合查 sendRoomMessage/sendIMMessage2
- **提示词**：
  - `查房间<roomId> eventId <eventId> 日志`
  - `811 推送 roomId <roomId>`
- **命令**：

```bash
python3 Log/log_execute.py --today --phrase <eventId> --phrase <roomId>
```

- **提示词**：

```bash

```

<a id="discover_phrase_today"></a>

### 日志-短语搜索（当日）

- **功能**：在 yaahlan-log* 按 Discover 短语 AND 搜索（与 Kibana 搜索框一致）；默认东八区当日；POST internal/bsearch
- **提示词**：
  - `查日志 <keyword|关键字>`
  - `Kibana 搜 <keyword1> 和 <keyword2>`
  - `yaahlan 日志 <userId|roomId|eventId>`
- **命令**：

```bash
python3 Log/log_execute.py --today --phrase <keyword>
```
