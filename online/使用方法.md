### 使用说明

- **提示词**：用户消息须含关键词「**线上环境**」
- **命令**：对应 `python3 online/online_execute.py <admin|moa|tunnel> ...`
- **配置**：`cp online/.env.example online/.env.local`（Admin + MOA + Tunnel 鉴权合一）
- **禁止**：无「线上环境」时调用本模块；含「线上环境」时禁止测试 `Admin/`、`MOA/`、`Tunnel/`
- **MOA 区号**：默认 **+966**（中国区号显式 `--phone-area-code 86`）
- **Tunnel**：`g_env=overseas`
- **在线判定**：Admin `queryUserDetail` 返回 `onlineStatus === 1` 为在线

### 环境配置

```bash
cp online/.env.example online/.env.local
# 填入 ADMIN_ONLINE_*、MOA_ONLINE_*、TUNNEL_ONLINE_*
```

| 变量前缀 | 用途 | 抓包来源 |
|----------|------|----------|
| `ADMIN_ONLINE_*` | yaahlan-admin.wemomo.com | www.yaahlan.fun 后台 |
| `MOA_ONLINE_*` | MSE httpproxy overseas | mse.wemomo.com |
| `TUNNEL_ONLINE_*` | tunnel.wemomo.com | tunnel 页面 Cookie |

### 子命令速查

| 子命令 | 底层 | 典型场景 |
|--------|------|----------|
| `admin` | Admin `--线上环境` | userId 查详情、在线状态 |
| `moa` | MOA `--线上环境` | 手机号 → userId（+966） |
| `tunnel` | Tunnel `--线上环境` | 用户 HTTP 抓包列表 |

### 典型组合

```bash
# 手机号 → userId → 是否在线
python3 online/online_execute.py moa --query-user-by-phone 19900001111
python3 online/online_execute.py admin --query-user-id <userId>

# 查用户最近抓包
python3 online/online_execute.py tunnel --momoid <userId> --since 3600
```
