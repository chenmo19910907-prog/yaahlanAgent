## P03 · 好设计是什么

> 章节：开场 · 操作：空格 · 约 30 秒

**口述**

我问一位做设计的朋友：什么是好设计？他想了想，说——**简约**。

所以我们后面讲界面、讲能力，都尽量往「少即是多」靠：能一句话说清的，就不堆术语；能一步完成的，就不让人找三个入口。

## P21 · 智能 · 01 · 日常测试，开口就能做

**标题** 第一块智能：**日常测试，开口就能做**。

**描述** 自然语言提问，Agent 全自动执行，覆盖测试同学日常大部分工作：

| 能力 | 举例 |
|------|------|
| Admin 查数 | 用户详情、在线状态、登录设备、公会信息 |
| MOA 查 userId | 手机号反查、批量查注册 |
| MOA 造数 | 发钻、改等级、砸蛋、公会 PK |
| Tunnel 抓包 | 按 userId 查 HTTP 请求和报文 |
| 接口验收 | 核对入参、返回字段、ec 码 |
| Stage 送礼 | 房间、私聊、群组验证 |
| PRD 与用例 | 读钉钉需求、测试点扩写、出 Markdown / Excel |
| 风控与设备落库 | 解除风控、mmuid 同步知识库 |

**收尾** 不用记脚本路径，说人话就行。

## P22 · 智能 · 02 · 工具组合，一句话搞定

**收尾** 你只说目标，编排是 Agent 的事。

**收尾** 新接口上线，先抓一条包，往往当天就能问、能跑。
