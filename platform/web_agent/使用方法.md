### Web Agent

#### Web Agent-打开对话页 {#open_web_agent}

启动 Web Agent HTTP 服务（默认 :18766）并在浏览器打开 chat 对话页

- **提示语示例**：
  - 打开 Web Agent
  - 打开智能工具 Agent 网页
  - 启动 web agent 对话页

- **命令**：

```bash
python3 platform/web_agent/open_web_agent.py
```

#### Web Agent-重启服务 {#restart_web_agent}

通过 server_watch 重启 Web Agent 进程并做端口健康检查

- **提示语示例**：
  - 重启 Web Agent
  - 重启 web agent 服务

- **命令**：

```bash
python3 platform/web_agent/server_watch.py --restart
```

#### Web Agent-服务端 Agent 查询 {#service_agent_query}

调用 Yaahlan 服务端 Agent Open API，查后端源码、MOA 注册、接口定义等

- **提示语示例**：
  - 问服务端 Agent：<问题>
  - 查 MOA provideDiamond ServiceUrl
  - 服务端 Agent 查询接口实现

- **命令**：

```bash
python3 platform/web_agent/service_agent_query.py --message "<问题>"
```
