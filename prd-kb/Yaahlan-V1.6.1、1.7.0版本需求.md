1. 什么是唯一标识符（Unique ID）？
唯一标识符是一个由数字、大小写英文字母或阿拉伯字母组成的6位以内字符ID。您可以用这些规则组合您喜欢的ID。
例如：
·唯一标识符可能具有重复或连续的数字或字母，例如：111111，123123，aaaaaa，abcabc；
·注意特殊id的首尾、中间不能带空格；
2. 独特 ID 的好处有哪些？
独特 ID 会出现特殊效果，出现在您的个人资料中，任何人都可以看到。
3. 如何获得Unique ID？
充值达到vip2的等级后，您可以有一次选择一个独特个人ID的机会。
联系我们的vip客服，提供您喜欢的靓号号码，我们的客服将帮您设置您的专属ID。
4. 什么是Unique ID的回收机制？
如果您设置了自己的Unique ID，在您vip等级达到2级及以上的时间，您都有Unique ID的使用权限。若您的vip等级下降到1级及以下，您的Unique ID 将会被回收，任何人都可以选择这个Unique ID。请您关注您的vip等级，避免您的Unique ID 被回收。
