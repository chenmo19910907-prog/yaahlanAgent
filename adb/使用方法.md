### 使用说明

| 项 | 说明 |
|----|------|
| **提示词** | 你对 Agent 说的自然语言口令 |
| **命令** | 下文可执行命令；默认截图目录 `adb/screenshots/`（只保留最新 2 张） |
| **目标 App** | **Yaahlan**（`com.immomo.biz.yaahlan`），不是桌面 Yaha |
| **自动化模式** | **只用片段 `macro` + 读图 / 抓包 / Admin 验收**；禁止长命令串联；已移除组合 `compose` |
| **多步流程** | `macro A` → 验收 → `macro B` → 验收 → …（每条命令只做一件事） |
| **全局参数** | `--serial <serial>` 多台设备时必传；`--no-capture` 路径确定时不截图 |

**仍用固定 macro 的模块**：`注册登录`、`消息`、`动态` 等。  
**禁用 macro 的模块**（须 AI 读图）：`游戏`、`房间`、`礼物`、`个人主页` 等 → 见 `索引.json` → `aiOperateModules`；调试加 `--force-script`。

## 0) 前置条件

- 已安装 `adb`（Android platform-tools）
- 手机 USB 调试已开，或 `adb connect <ip>:5555`
- `adb devices` 中状态为 `device`

```bash
python3 adb/adb_execute.py devices
python3 adb/adb_execute.py info
```

<a id="adb-device-screenshot"></a>

## 1) 设备与截图

<a id="capture"></a>

### 截图-读图（探索 / 纠偏）

- **功能**：截屏并返回路径；默认缩略图 `max-edge=1170` 加快 Agent 读图
- **提示词**：
  - `截屏读当前页`
  - `capture 读图确认弹窗`
- **命令**：

```bash
python3 adb/adb_execute.py capture --max-edge 1170
python3 adb/adb_execute.py capture --full-res          # 校坐标时用原图
python3 adb/adb_execute.py latest                      # 仅输出最新 PNG 路径
```

<a id="activity"></a>

### 当前页-Activity 快验

- **功能**：输出前台 Activity JSON（`hint=home/in_room/login/search/profile` 等），片段间验收比读图快
- **提示词**：
  - `当前在什么页面`
  - `验收是否进房成功`
- **命令**：

```bash
python3 adb/adb_execute.py activity
```

| `hint` | 含义 |
|--------|------|
| `home` | 首页底栏 MainActivity |
| `login` | 登录页 |
| `in_room` | 语音房内 |
| `search` | 搜索页（退房后常见） |
| `profile` | 个人资料页 |

<a id="tap"></a>

### 点击 / 滑动 / 按键

- **功能**：读图定坐标后单步操作；缩略图坐标用 `coords` / `tap --from-image` 换算
- **提示词**：
  - `点 Cancel 关弹窗`
  - `上滑看 Me 页下方`
- **命令**：

```bash
python3 adb/adb_execute.py coords 270 460
python3 adb/adb_execute.py tap 270 460 --from-image
python3 adb/adb_execute.py tap 540 1200
python3 adb/adb_execute.py swipe 540 1700 540 800 --duration 350
python3 adb/adb_execute.py key 4          # BACK（Me/home 慎用，会弹退出 App）
python3 adb/adb_execute.py text hello
```

<a id="adb-macro"></a>

## 2) 录制片段 macro（核心）

<a id="scripts"></a>

### 列出片段

- **功能**：按 testcase-kb 模块列出全部录制片段
- **提示词**：`有哪些 adb 片段` / `列出注册登录 macro`
- **命令**：

```bash
python3 adb/adb_execute.py scripts
python3 adb/adb_execute.py macros
```

<a id="macro_run"></a>

### 执行片段

- **功能**：跑一段已验证 UI 操作；支持中文名或英文 `id`；带 `params.text` 的片段须 `--text`
- **提示词**：
  - `macro 手机号登录 13311111115`
  - `发动态 5555`
  - `搜索进房 38826842`
- **命令**：

```bash
python3 adb/adb_execute.py macro 手机号登录 --text 13311111115 \
  --force-script --no-popup-gate --no-capture

python3 adb/adb_execute.py macro 发布纯文本动态 --text 5555 --no-capture

python3 adb/adb_execute.py macro 搜索进房 --text 38826842 --no-capture
```

| 常用参数 | 说明 |
|----------|------|
| `--text` | 手机号、roomId、动态正文等 |
| `--no-capture` | 不截图（路径确定、有抓包验收时推荐） |
| `--no-popup-gate` | 片段结束不跑弹窗门禁（Agent 批量跑片段时常加） |
| `--force-script` | 强制执行 aiOperateModules 内片段（仅调试） |
| `--skip KEY` | 跳过片段内步骤（如 `login_lang`、`dismiss_popup_taps`） |
| `--rtl` | 阿语等 RTL 下水平镜像 `tap_pct` |

**片段间验收**（跑完一段再跑下一段）：

```text
macro A  →  activity / capture / tunnel  →  OK  →  macro B  →  …
```

<a id="macro_chain"></a>

### 自定义步骤 chain（调试）

- **功能**：直接执行 JSON 步骤文件；日常自动化优先用 `macro`，chain 仅调试或低层试验
- **命令**：

```bash
python3 adb/adb_execute.py chain adb/录制脚本/片段/个人主页/进入个人资料详情页.json
```

<a id="adb-ai"></a>

## 3) AI 读图（首页 / Me / 房间）

<a id="ai_prepare"></a>

### AI-准备读图循环

- **功能**：对禁用 macro 的模块，输出 workflow + 截图，由 Agent 读图后 `tap`/`key`
- **提示词**：
  - `进 Me 页`
  - `退出登录到 Login`
  - `进房 / 退房纠偏`
- **命令**：

```bash
python3 adb/adb_execute.py ai goals
python3 adb/adb_execute.py ai prepare --goal enter_me
python3 adb/adb_execute.py ai prepare --goal logout
python3 adb/adb_execute.py ai prepare --goal enter_room
python3 adb/adb_execute.py ai prepare --goal exit_room
python3 adb/adb_execute.py ai prepare --goal recover
```

<a id="ai_abandon"></a>

### 脚本-连续失败废弃

- **功能**：同一 macro 连续失败 3 次后禁止再跑，改 AI + Tunnel
- **命令**：

```bash
python3 adb/adb_execute.py ai failures 手机号登录
python3 adb/adb_execute.py ai abandoned
python3 adb/adb_execute.py ai restore 手机号登录
```

## 4) Tunnel 抓包验收

> Cookie 复用 `MOA/.env.local`。详见 [Tunnel/使用方法.md](../Tunnel/使用方法.md)。

<a id="run"></a>

### 一体化 run（macro + 抓包）

- **功能**：执行一个片段 + 结束截图 + Tunnel 轮询；**以抓包为验收主依据**
- **提示词**：
  - `登录并抓包验收`
  - `进房等 heartbeat`
  - `发动态等 feed 接口`
- **命令**：

```bash
python3 adb/adb_execute.py run \
  --macro 手机号登录 --text 13311111115 \
  --tunnel-account familyLeader \
  --tunnel-keyword login \
  --tunnel-wait 30

python3 adb/adb_execute.py run \
  --macro 搜索进房 --text 38826842 \
  --tunnel-account familyLeader \
  --tunnel-keyword heartbeat \
  --tunnel-wait 20
```

<a id="tunnel_wait"></a>

### Tunnel-仅等待（UI 已手动完成）

- **命令**：

```bash
python3 adb/adb_execute.py tunnel wait \
  --account familyLeader --keyword gift/send --since 300 --wait 30 --expect-ec 200

python3 adb/adb_execute.py tunnel last \
  --account familyLeader --keyword updateUserBase --since 120
```

| 抓包关键字示例 | 场景 |
|----------------|------|
| `login` | 登录 |
| `heartbeat` | 进房 |
| `feed` | 发动态 |
| `gift/send` | 礼物面板送礼（须 `ec=200`） |
| `updateUserBase` | 保存资料 |

## 5) 弹窗分析

<a id="popup_analyze"></a>

### 弹窗-抓包 + 读图分析

- **功能**：结合 `弹窗抓包信号.json` 判断 login/home/me/room/mic 节点是否有弹窗
- **提示词**：`Me 页有没有弹窗` / `登录后关弹窗`
- **命令**：

```bash
python3 adb/adb_execute.py popup analyze \
  --scene me --account familyLeader --since 120 --capture

python3 adb/adb_execute.py run \
  --macro 手机号登录 --text 13311111112 \
  --tunnel-account familyLeader \
  --popup-scene login --popup-auto-dismiss
```

UI 细则见 [录制脚本/弹窗说明.md](录制脚本/弹窗说明.md)。

## 6) 登录 / 换号 / 开屏

<a id="login_flow"></a>

### 登录-手机号（QA 默认）

- **默认**：+86 / 验证码 `000000` / 测试手机见 `索引.json` → `loginDefaults`
- **提示词**：`用 13311111115 登录`
- **命令**（逐段，禁止长串联）：

```bash
python3 adb/adb_execute.py capture --max-edge 1170
python3 adb/adb_execute.py macro 进入设置 --force-script --no-popup-gate --no-capture
python3 adb/adb_execute.py activity    # 须 SettingComposeActivity
python3 adb/adb_execute.py macro 设置页退出登录 --force-script --no-popup-gate --no-capture
python3 adb/adb_execute.py activity    # 须 hint=login
python3 adb/adb_execute.py macro 手机号登录 --text 13311111115 \
  --force-script --no-popup-gate --no-capture
python3 adb/adb_execute.py login verify --account guildLeader --since 90
```

<a id="cold_start"></a>

### 冷启动-开屏广告

- **命令**：

```bash
python3 adb/adb_execute.py macro 启动Yaahlan --no-capture
python3 adb/adb_execute.py macro 跳过开屏广告 --no-capture
python3 adb/adb_execute.py splash verify --account guildLeader --since 45 --recover
```

<a id="standard_nickname"></a>

### 改昵称-QA 标准名

- **规则**：`133111111XX` → `CXX`；`133111112XX` → `C2XX`（见 `adb/adb/standard_nickname.py`）
- **提示词**：`把 13311111180 改成标准昵称`
- **命令**（逐段 + Admin 验收）：

```bash
python3 adb/adb_execute.py macro 资料页进入编辑页 --force-script --no-capture
python3 adb/adb_execute.py macro 资料页修改昵称为标准昵称 --text 13311111180 \
  --force-script --no-capture
python3 Admin/admin_execute.py --query-user-id <userId>
```

改次数为 0 时先 MOA 开 VIP5 再重试（见 [MOA/使用方法.md](../MOA/使用方法.md)）。

<a id="adb-exit"></a>

## 退出码与验收原则

| 退出码 | 含义 |
|--------|------|
| `0` | 成功（含 tunnelVerify.ok / activity 符合预期） |
| `2` | 参数错误或尚无截图 |
| `3` | 抓包失败、开屏验收失败、弹窗门禁 blocked 等 |

**验收优先级**：

1. 有接口 → **Tunnel 抓包**（`ec=200`），失败再读图排查  
2. 片段间判页 → **`activity`** 或 macro 输出里的 `foregroundActivity`  
3. 无抓包 / 弱 UI → **`capture` 读图**  
4. 提交类（Save/Post/登录）→ **不要以 Toast 读图为准**

**禁止**：for 循环点 UI、长 shell 串联、未确认落点就盲连下一段 macro、随意 `force-stop`（除非冷启测试）。
