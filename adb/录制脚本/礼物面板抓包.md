# 礼物面板 × Tunnel 抓包

打开礼物面板（点底部**橙色礼物盒**，非快捷礼物）后，客户端会拉取礼物列表。

## 关键接口

| 接口 | 说明 |
|------|------|
| `POST .../component/giftPanel/getGiftTabListV3` | **各 Tab 与礼物列表**（name / id / bid / price） |
| `POST .../component/giftPanel/getGiftPanel` | Banner、面板配置 |
| `POST .../component/giftPanel/sendCheckInfo` | 送礼前校验（**cpUserId**、财富/贵族等级等） |
| `POST .../component/giftPanel/propPackageList` | 背包道具 |
| `POST .../v2/gift/send` | **实际送礼**（Tunnel keyword 用 `gift/send` 或 `v2/gift/send`，非 `sendGift`） |

## UI 与数据对应

- **左右滑** Tab 栏 ↔ `getGiftTabListV3.gift_list[].tab_name`（Gift、Lucky Gift、Interaction、Privilege、nation…）
- **上下滑** 礼物格 ↔ 同一 Tab 下 `list[]` 按 4 列网格展示；列表下标 `index` 可换算行/列与需上滑次数

## CLI

```bash
# 打开礼物面板后：列出各 Tab 礼物数与价位
python3 adb/adb_execute.py gift panel analyze --account familyLeader --since 120

# 查 99 钻礼物（含 Tab、index、上下滑提示）
python3 adb/adb_execute.py gift panel find --account familyLeader --price 99 --tab Gift
```

| index | name | id | price |

送礼流程：Tunnel `find` 定 Tab 与 index → ADB 切 Tab + 上下滑 → 点选 → Send。

## 送礼验收（必读 response.em）

点 **Send** 后**必须抓包读 `v2/gift/send` 的响应体**，Toast/公屏不可靠：

| 字段 | 含义 |
|------|------|
| `response.ec` | **200** = 业务成功；非 200 = 失败 |
| `response.em` | **失败原因文案**（优先读此字段） |
| `response.data` | 补充信息（余额不足、CP 关系、等级限制等） |

```bash
# 点 Send 后等待并校验（expect-ec 200 时，抓到但 ec≠200 会返回 failureReason）
python3 adb/adb_execute.py tunnel wait --account guildLeader --keyword gift/send --since 30 --wait 25 --expect-ec 200

# 或读取最近一条 gift/send 结果（含 failureReason）
python3 adb/adb_execute.py tunnel last --account guildLeader --keyword gift/send --since 120
```

**注意**：

- 仅「未抓到 `gift/send`」≠ 业务成功，可能是 Send 未点中、未选收礼人、或客户端拦截未发请求。
- 已抓到但 `ec≠200`：`tunnelVerify.businessFailure=true`，读 `matches[0].failureReason`。
- **Room All** 送礼：点 Send 后会出现二次确认（Cost / Confirm），须点 **Confirm** 才会发出 `gift/send`。

## CP 礼物（只能送给 CP）

**业务规则**：名称含 **CP** 的礼物（如 **CP Hot Air Balloon** 100 钻）**只能送给 CP（情侣/搭档）**，不能送给普通麦位用户或 Room All。

| 抓包信号 | 含义 |
|----------|------|
| `sendCheckInfo.data.cpUserId` | 当前账号的 CP 对象 userId；**`null` = 无 CP，不可送 CP 礼物** |
| 客户端 Toast | 常见提示「CP 礼物不可以赠送 / 只能送给 CP」 |
| 无 `gift/send` | 客户端在校验阶段拦截，请求未发出 |

**自动化前预检**（打开礼物面板后）：

```bash
# 读 sendCheckInfo（gift 面板打开后会出现）
python3 -c "
from adb.adb.popup_analyze import fetch_recent_tunnel_items
items,_=fetch_recent_tunnel_items(momoid='100465989', since_seconds=120)
for x in sorted(items, key=lambda i: str(i.get('time','')), reverse=True):
    if 'sendCheckInfo' in str(x.get('url','')):
        d=(x.get('response') or {}).get('data') or {}
        print('cpUserId', d.get('cpUserId'), 'buddyUserIdSet', d.get('buddyUserIdSet'))
        break
"
```

`cpUserId` 为 `null` 时，**不要测 CP 礼物**；改测非 CP 礼物（如 Trophy 99 钻），或换有 CP 关系的账号。

若仍尝试送出且服务端有响应，读 `gift/send` 的 `response.em` 获取失败原因。
