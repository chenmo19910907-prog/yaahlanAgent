# 偶发弹窗与脚本处理

测试包在 **登录后**、**进 Me**、**发动态** 等节点可能弹出非预期对话框，导致后续点击偏移。统一用片段 **关闭常见弹窗**（`dismiss-common-popups`）处理。

## 最高优先级：Charm/PK 横幅与奖杯挂件（全局·与房间无关）

**任意 Activity**（首页、房内、WebView、Me 等）只要 `capture` 读图出现以下任一特征，**须立即暂停当前任务**，优先于 Mic invitation、关闭常见弹窗、退房、学习下一入口等一切操作：

- **大横幅**：Charm/PK 渐变横幅（`Still missing XXk`、左右 `No.50+`/`No.50` 头像、右侧 **Charm** 互换钮）
- **小挂件**：收起后的右上角 **奖杯 + 00:00** 计时条（`fl_pk_small` / `pk_small_view`）

**禁止 `key 4` / 物理返回** — 横幅无法靠 BACK 收起，必须点 `iv_switch_small` 收起钮。

1. **`macro CharmPK横幅收起拖走 --force-script --no-popup-gate`**（仅小挂件、无大横幅时，macro 内步骤①可跳过，步骤②拖走仍须执行）
2. **`capture` 验收** — 大横幅已收起、奖杯挂件已下移，不再挡按钮
3. 再继续原流程

```bash
python3 adb/adb_execute.py capture --max-edge 1170   # 见横幅或奖杯挂件 → 下一句
python3 adb/adb_execute.py macro CharmPK横幅收起拖走 --force-script --no-popup-gate
python3 adb/adb_execute.py capture --max-edge 1170   # 确认已处理
```

| 步骤 | 操作 | 坐标（uiautomator 校准 2026-06） |
|------|------|------|
| ① 收起 | 点大横幅右上 **向内双箭头** `iv_switch_small`（Charm 右侧；**勿点 Charm**） | `0.908, 0.085` ≈ 980,200 |
| ② 拖走 | 按住收起后右上角 **奖杯挂件**（trophy+00:00）向下拖 | swipe 976,180→976,520，1s |

若第 ① 步后仍见 Report/Minimize/Share/Close 大面板，**再点一次**收起，再执行 ②。

片段：`片段/通用/CharmPK横幅收起拖走.json`（**非**房间专属；退房链等仅作可选 `run_script` 引用）

## 已收录弹窗

| 弹窗 | 典型时机 | 脚本处理 |
|------|----------|----------|
| **Charm/PK 横幅 / 奖杯挂件** | **任意页**（房内/首页/WebView 等） | **最高优先级** → `macro CharmPK横幅收起拖走`（见上节） |
| **Me 页众测/账号安全** | 切号前进 Me（如 **13311111114**） | 先 `切换我的底栏` → `关闭常见弹窗`（**含 Cancel**）→ 再点设置退出 |
| 运营/礼包全屏 | 登录进首页 | `BACK` ×2 |
| Account Security（绑定手机/邮箱） | 登录后、进 Me | 点 **Cancel**（约 32%, 56%） |
| Crowd Testing Invitation | 进 Me / 个人页 | 点 **Cancel**（约 29.6%, 47.9%） |
| 退出 Yaahlan 等双按钮 | 误触退出、部分运营 | 点左侧 **Cancel**（约 35%, 52%） |
| 发布页键盘挡住 Post | 选图后 | 点空白收起键盘；**勿 BACK**（会清空已选图）再点 Post |
| **home 上盲 BACK** | **冷启动回首页** 若在 MainActivity 连按 BACK | **勿**跑关闭常见弹窗；会连弹「退出 App」二次确认 |
| **网络诊断 Excellent** | 进语音房后偶发 | `关闭网络诊断弹窗`（Close 约 86.6%, 25.3%） |
| **Mic invitation（邀请上麦）** | **进入他人语音房约 2～5s 后**顶部弹窗 | `macro 拒绝Mic邀请`（Reject **swipe 270,460** 80ms；须 swipe，`input tap` 无效；勿点 90,300 标题区） |
| **房内弹窗类小游戏全屏** | 进房后 Ludo / 7up7down / World Cup 等遮挡语音房 | **`macro 房内三方游戏最小化`**（顶部居中 **Minimize / تصغير**，`0.500, 0.171`）；**不学习游戏内 UI** |

## 接入位置

- 各 **手机号登录** 片段末尾：`run_script` → 关闭常见弹窗（登录后进 home 时）
- **冷启动回首页**：**不含**关闭常见弹窗（已在 home 时 BACK 会触发退出确认）
- **发布图片动态** 开头（切 Moment 前）
- **进入个人资料详情页** / **进入我的动态列表**：进 Me 后
- 组合 **公会长/家族长发布图片动态**：登录块后再执行一次关闭常见弹窗
- **搜索进房 / 点列表首卡进他人房**：进房后 **sleep ≥3s**，`capture` 读图；见 **Mic invitation** 横幅再 `macro 拒绝Mic邀请`；再跑礼物/退房等

## 进他人房后 Mic invitation（邀请上麦）

**规律**：从 Room 列表或搜索进入**他人**语音房，`RoomChatActivity` 加载完成约 **2～5 秒**后，顶部常弹出 **Mic invitation** 横幅（Accept / Reject），会挡住右上角 X、礼物等操作。

**Agent / 串联脚本**：

1. 进房 macro 末尾保留 **≥3s 等待**（`搜索进房` 已 4s；`房间帧点击首个房间卡片` 建议 3～4s）
2. **`capture` 读图** — 有横幅再点 Reject，**勿**未读图盲跑（Reject 坐标会误点底层 UI）
3. **`macro 拒绝Mic邀请 --force-script --no-popup-gate`**（Reject **swipe 短按 270,460 80ms**）
4. 退房、送礼前若仍有横幅：先拒绝，再 `macro 退出房间`（片段内 note 已说明）

```bash
python3 adb/adb_execute.py macro 房间帧点击首个房间卡片 --force-script --no-popup-gate
python3 adb/adb_execute.py capture --max-edge 1170   # 有 Mic invitation → 下一句
python3 adb/adb_execute.py macro 拒绝Mic邀请 --force-script --no-popup-gate
python3 adb/adb_execute.py macro 退出房间 --force-script --no-popup-gate
```

片段：`片段/房间/拒绝Mic邀请.json`

## 搜索进房（先清空，再 Search，再点结果行）

1. 聚焦输入框后，`text` 步 **`clear_before_text: true`**（MOVE_END + 退格）清空残留 roomId，再输入新 roomId。
2. 输入 roomId 后，**必须先点输入框右侧 Search**（`tap_pct` **0.861, 0.161** ≈ 930,377）触发搜索，等待结果列表出现。
3. 出现搜索结果后，**点结果列表里的房间信息行**（头像 / 房间名 / ID）进房；**不要**再点顶部搜索输入框。

```bash
python3 adb/adb_execute.py macro 搜索进房 --text 38826842
```

片段：`片段/房间/搜索进房.json`（Search 0.861, 0.161；结果行 0.35, 0.222）。

## 退出房间后的落点（片段间须验收）

### 进房遇顶部 Charm / PK 横幅时

与 **§最高优先级** 相同：任意页见横幅均 **`macro CharmPK横幅收起拖走`**，再执行退房等后续步骤。

### 进房遇弹窗类小游戏全屏时

Ludo / 7up7down / **World Cup 竞猜** 等会在 `RoomChatActivity` 上以弹窗或全屏层遮挡语音房 UI。**只需点游戏层最上方居中的收起按钮**（**Minimize / تصغير**，`tap_pct` **`[0.500, 0.171]`**），**不必录制或学习游戏内玩法**。

此时 `退出房间` 的右上角 X 点不到语音房菜单。退房链须先：

1. 若有 **Game Prizes / Game Rewards** 等运营弹窗 → 先关弹窗（World Cup 首进常见 WebView close-icon 约 **80,587**；或 `key 4` BACK）
2. 若有 **Charm/PK 横幅** → **`macro CharmPK横幅收起拖走`**（全局最高优先级）
3. **`macro 房内三方游戏最小化`**（或上表坐标点 **Minimize**）
4. 再 **`macro 退出房间 --force-script --no-popup-gate`**

片段：`片段/房间/房内三方游戏最小化.json`

从 **搜索进房** 进入的房间，执行 **退出房间** 后常回到 **Search 页**，而不是房间列表或带底栏的主页。串联脚本时：**跑完退出房间后 capture 读图**，确认不在 Search 页再跑下一段（如 `退出登录`）。

```bash
python3 adb/adb_execute.py macro 退出房间
python3 adb/adb_execute.py capture    # 读图：若在 Search 页 → macro 搜索页返回房间帧
python3 adb/adb_execute.py macro 搜索页返回房间帧
```

## Tunnel 抓包判断弹窗（推荐 Agent 流程）

登录、进首页、进 **Me**、进房、开麦等节点，弹窗**不一定每次都有**。盲目执行 `关闭常见弹窗` 的 Cancel 坐标可能误点底层 UI；可先抓包再决定是否关弹窗。

### 场景与命令

| 场景 `--scene` | 典型时机 |
|----------------|----------|
| `login` | 登录后进首页 |
| `home` | 底栏切换 / 回首页 |
| `me` | 进 Me / 个人资料 |
| `room` | 进语音房 |
| `mic` | 点上麦 / 开麦 |

```bash
# 仅分析最近 2 分钟抓包 + 截图读图
python3 adb/adb_execute.py popup analyze \
  --scene me \
  --account familyLeader \
  --since 120 \
  --capture

# 分析后自动尝试关弹窗（无抓包信号时跳过 Cancel 坐标，避免误点）
python3 adb/adb_execute.py popup analyze \
  --scene login \
  --account familyLeader \
  --auto-dismiss \
  --capture
```

### 操作 + 分析一体化

```bash
python3 adb/adb_execute.py run \
  --macro 手机号登录 \
  --text 13311111112 \
  --tunnel-account familyLeader \
  --popup-scene login \
  --popup-auto-dismiss
```

输出 JSON 含 `popupAnalysis`：

- `hasPopupSignals`：抓包规则命中（如首充 `isFirstRecharge`）
- `weakUiPopups`：抓包难覆盖、**必须读 `screenshot` 确认**（Mic invitation、众测、Account Security 等）
- `recommendation`：`capture_first` / `dismiss_then_capture` / `continue`
- `agentHint`：给 Agent 的自然语言下一步

信号登记与 URL/response 规则见 **`弹窗抓包信号.json`**（与 `弹窗说明.md` 同目录）。

## 开屏广告（冷启约 5s）

| 风险 | 说明 |
|------|------|
| 过早点击 | 广告未出就 tap → 点进 `gotoUrl` H5，`hint=webview` |
| 未验收连跑 | 下一段 macro 在广告页执行，坐标全错 |
| 处置 | 冷启宏/组合已内置 **`验收开屏广告`**；亦可 `splash verify --recover` |

```bash
python3 adb/adb_execute.py macro 冷启动回首页 --no-capture
# 宏内已含验收；单独 Tunnel 验收：

```

抓包：`ad/getOpenScreenAd`（`response.data.url` 非空则有开屏）→ 验收主页 `getUserConfigs` / `simpleUserInfo`。

## Me 页弹窗（AI 读图点 Cancel）

进 **Me** 用 **`ai prepare --goal enter_me`**，**勿 macro 切换我的底栏**。

1. `capture` 读图
2. 有弹窗 → 点 **Cancel**（勿 BACK）
3. 再 `capture` 确认后继续

```bash
python3 adb/adb_execute.py ai prepare --goal enter_me
python3 adb/adb_execute.py ai prepare --goal dismiss_me_popup
```

**home/房内弹窗**：`popup gate --scene home|room` 仅截图，读图后 Agent tap 关闭。

## 登录后签到弹窗

部分账号登录成功后会弹 **签到半屏**（`sign/signInList` → `data.signInPopupUrl`），不关掉会卡在 `WebViewActivity`，后续 macro 全偏。

```bash
python3 adb/adb_execute.py macro 手机号登录 --text 13311111111 --no-capture
python3 adb/adb_execute.py login verify --account guildLeader --since 90
# 或 popup analyze --scene login --account guildLeader --auto-dismiss
```

| 验收 | 说明 |
|------|------|
| `foregroundActivity.hint` | 应为 `home`，不能 `webview` |
| Tunnel `sign/signInList` | `signInPopupUrl` 非空 → 应有签到弹窗 |
| 关弹窗 | `login verify`（**仅 webview 时 BACK**；home 上连按 BACK 会弹「退出 App」二次确认） |

## 批量账号登录巡检（每账号抓包验收）

多账号轮换时，**每完成一个账号**须验收后再切下一个；部分账号进 **Me** 会叠众测/账号安全弹窗，不关掉会导致后续步骤全偏。

```bash
# 13311111111～13311111122 逐个：退出 → 登录 → tunnel 验登录 → 进 Me → 关弹窗 → tunnel 验 Me
python3 adb/adb_execute.py accounts sweep \
  --from 13311111111 --to 13311111122
```

| 步骤 | 验收 |
|------|------|
| 登录 | `loginTunnel` 关键字 `simpleUserInfo`，`foregroundActivity.hint=home` |
| 进 Me | `mePopupAnalysis`（抓包 + weakUi 提示） |
| 关弹窗 | **Me 页**执行 `关闭常见弹窗`（**含 Cancel**，与众测坐标匹配） |
| Me 数据 | `meTunnel` 关键字 `personalHomePageUserInfo` |

### Game 帧 AI 读图规则

在 **Game 底栏帧**（`MainActivity` + Game Tab）：

1. **无弹窗时：不要进行任何点击**（不跑 `关闭常见弹窗`、不盲点 Cancel/BACK、不点内容区）
2. **有弹窗时**：`capture` 读图，仅针对该弹窗点关闭（如 Cancel）；仍禁止点内容区
3. **需要进 Me 时**：在无弹窗遮挡的前提下，**仅点底栏 Me**（约 `tap_pct 0.90,0.956`）

内容区盲点常见后果：

| 误点区域 | 后果 |
|----------|------|
| Activities Banner / 轮播 | 打开 `WebViewActivity`（PK ATM 等活动页） |
| Online players 列表项 | 进入他人资料/私聊（`ProfileActivity` 带 Chat/Follow） |
| Casual games 图标 | 进游戏或弹窗 |
| 顶栏头像/昵称 | 非 Me 页入口，行为因账号而异 |
| Free draw 浮钮 | 打开礼包/WebView |

到 Me 后：点**顶部本人头像昵称行**（约 `0.11,0.16`）。home/Game 上 **勿 BACK**（会弹「退出 Yaahlan」）。

**注意**：

- 登录后落在 **Game 首页**时，**不要**在首页盲点 Cancel（会误触 Activities Banner 打开 WebView）；巡检脚本已跳过登录后的 Cancel，仅在 Me 页关弹窗。
- 未知手机号的 `momoid` 优先从 `索引.json` → MOA 查号 → tunnel-probe；无 momoid 时 tunnel 验收会跳过，看 `momoidSource`。
- 单账号调试：`macro 手机号登录 --text 13311111111 --skip login_lang --no-capture` → `tunnel wait --account guildLeader --keyword simpleUserInfo` → `macro 切换我的底栏` → `popup analyze --scene me --account guildLeader --auto-dismiss`。

## 维护

新弹窗真机出现后：

1. 在 `片段/注册登录/关闭常见弹窗.json` 的 `popups` 与 `steps` 中补坐标，并在本表登记
2. 若该弹窗有稳定 HTTP 接口，在 **`弹窗抓包信号.json`** 对应 `scene.signals` 中补 `urlPatterns` 与 `rules`
3. 优先用 **BACK** 关全屏层，再补 **Cancel** 比例坐标
