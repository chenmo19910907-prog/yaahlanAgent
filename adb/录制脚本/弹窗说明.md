# 偶发弹窗与脚本处理

测试包在 **登录后**、**进 Me**、**发动态** 等节点可能弹出非预期对话框，导致后续点击偏移。统一用片段 **关闭常见弹窗**（`dismiss-common-popups`）处理。

## 已收录弹窗

| 弹窗 | 典型时机 | 脚本处理 |
|------|----------|----------|
| 运营/礼包全屏 | 登录进首页 | `BACK` ×2 |
| Account Security（绑定手机/邮箱） | 登录后、进 Me | 点 **Cancel**（约 32%, 56%） |
| Crowd Testing Invitation | 进 Me / 个人页 | 点 **Cancel**（约 29.6%, 47.9%） |
| 退出 Yaahlan 等双按钮 | 误触退出、部分运营 | 点左侧 **Cancel**（约 35%, 52%） |
| 发布页键盘挡住 Post | 选图后 | `发布图片动态` 内已 `BACK` 再点 Post |

## 接入位置

- 各 **手机号登录** 片段末尾：`run_script` → 关闭常见弹窗
- **发布图片动态** 开头（切 Moment 前）
- **进入个人资料详情页** / **进入我的动态列表**：进 Me 后
- 组合 **公会长/家族长发布图片动态**：登录块后再执行一次关闭常见弹窗

## CLI

```bash
# 默认：BACK + 尝试点 Cancel
python3 adb/adb_execute.py macro 关闭常见弹窗

# 确认当前无弹窗、避免 Cancel 误点底层 UI 时：
python3 adb/adb_execute.py compose 家族长发布图片动态 --skip dismiss_popup_taps
```

## 搜索进房（勿点输入框）

出现搜索结果后，**必须点结果列表里的房间信息行**（头像 / 房间名 / ID）进房；**不要**再点顶部搜索输入框或键盘搜索键。

```bash
python3 adb/adb_execute.py macro 搜索进房 --text 38826842
```

片段：`片段/首页-房间帧/搜索进房.json`（结果行约 `tap_pct` 0.35, 0.222）。

## Tunnel 抓包判断弹窗（推荐 Agent 流程）

登录、进首页、进 **Me**、进房、开麦等节点，弹窗**不一定每次都有**。盲目执行 `关闭常见弹窗` 的 Cancel 坐标可能误点底层 UI；可先抓包再决定是否关弹窗。

### 场景与命令

| 场景 `--scene` | 典型时机 |
|----------------|----------|
| `login` | 登录后进首页 |
| `home` | 底栏切换 / 回首页 |
| `me` | 进 Me / 个人资料 |
| `room` | 进语音房 |
| `mic` | 点上麦 / 开麦 |

```bash
# 仅分析最近 2 分钟抓包 + 截图读图
python3 adb/adb_execute.py popup analyze \
  --scene me \
  --account familyLeader \
  --since 120 \
  --capture

# 分析后自动尝试关弹窗（无抓包信号时跳过 Cancel 坐标，避免误点）
python3 adb/adb_execute.py popup analyze \
  --scene login \
  --account familyLeader \
  --auto-dismiss \
  --capture
```

### 操作 + 分析一体化

```bash
python3 adb/adb_execute.py run \
  --compose 家族长冷启动登录 \
  --tunnel-account familyLeader \
  --popup-scene login \
  --popup-auto-dismiss
```

输出 JSON 含 `popupAnalysis`：

- `hasPopupSignals`：抓包规则命中（如首充 `isFirstRecharge`）
- `weakUiPopups`：抓包难覆盖、**必须读 `screenshot` 确认**（Mic invitation、众测、Account Security 等）
- `recommendation`：`capture_first` / `dismiss_then_capture` / `continue`
- `agentHint`：给 Agent 的自然语言下一步

信号登记与 URL/response 规则见 **`弹窗抓包信号.json`**（与 `弹窗说明.md` 同目录）。

## 维护

新弹窗真机出现后：

1. 在 `片段/注册登录/关闭常见弹窗.json` 的 `popups` 与 `steps` 中补坐标，并在本表登记
2. 若该弹窗有稳定 HTTP 接口，在 **`弹窗抓包信号.json`** 对应 `scene.signals` 中补 `urlPatterns` 与 `rules`
3. 优先用 **BACK** 关全屏层，再补 **Cancel** 比例坐标
