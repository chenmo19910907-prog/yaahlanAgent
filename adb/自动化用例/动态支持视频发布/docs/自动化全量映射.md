## 等级与自动化状态（可自行调整）

| 等级 | 含义 | 本需求条数 |
|------|------|-----------|
| **P0** | 主链路写操作（发布成功） | 1 |
| **P1** | 核心入口 / 编辑链路 | 37 |

| **P4** | 敏感审核、老版本、超管 | 10 |

|------------------|------|-----------|
| **auto** | 已有 JSON + macro + Tunnel/Activity 可验 | 2 |

## 扩展自动化建议（按优先级）

1. **P1 · 文字+视频动态**：在 `发布视频动态` macro 前加输入文案步骤，或新片段 `发布文字视频动态`  
2. **P2 · 列表播放**：补 `动态帧Discover进入动态详情` + 读图断言播放键（需 AI 读图或新 activity 验收）  
3. **P2 · 互斥选片**：分场景片段「先选图再点视频」，验收 Toast（抓包无写接口时仍偏 manual）  
4. **P3 · 权限弹窗**：需 ADB 改权限或分设备池，不宜纳入默认可执行集  

## Agent 整理新需求时的流程

1. `dingtalk-excel-read` 读手工表 → 生成 `registry/<需求名>.json`（115 条结构）  
2. 对照 PRD + `KB对照.md` 标 `priority` / `automationStatus`  
3. 对 `auto`/`semi` 项 `autotest generate` → 微调 JSON → 写入 `catalog.json`  
4. `autotest run --requirement <id>` 试跑 → 附 `report.html`
