# 奖励领取

原始文档：https://alidocs.dingtalk.com/i/nodes/Gl6Pm2Db8D3xKamahzYABLlKJxLq0Ee4（奖励领取 sheet）

## 一、功能流程

| 编号 | 功能模块 | case步骤描述 | 预期结果 |
| --- | --- | --- | --- |
|  | 任务记值 | 记值方式-日累计，送礼/收礼/充值/下注/返奖，查看当日记值 | 当日累计记值正确 |
|  |  | 次日查看任务记值 | 记值清空，重新累计 |
|  |  | 记值方式-总累计，送礼/收礼/充值/下注/返奖，查看当日记值 | 当日累计记值正确 |
|  |  | 次日查看任务记值 | 记值未清空，展示昨日数值 |
|  |  | 次日继续做任务 | 任务值=昨日+今日 |
|  |  | 活动未开始，做任务 | 不增加任务值 |
|  |  | 活动开始，做任务 | 增加任务值 |
|  |  | 活动结束，做任务 | 不增加任务值 |
|  | 固定奖励 | 未完成任务，查看领取奖励按钮 | 领取按钮置灰不可点击 |
|  |  | 已完成任务，查看领取奖励按钮 | 领取按钮高亮 |
|  |  | 点击领取按钮 | 领取成功 |
|  |  |  | 进入钱包/背包/我的道具查看，奖励下发成功 |
|  |  |  | 水晶/金币下发数量正确 |
|  |  |  | 背包礼物个数正确 |
|  |  |  | 配件有效期正确 |
|  |  | 下发水晶/金币奖励 | 查看钱包/金币记录，展示对应记录 |
|  |  | 连续点击领取按钮 | 奖励只可下发一次(幂等) |
|  |  | 任务类型为日任务，已完成任务，当日未领取奖励，次日查看 | 任务重置，领取按钮变成去完成按钮 |
|  |  | 任务类型为日任务，已完成任务，当日未领取奖励，未退出页面，次日点击领取按钮 | 无法领取奖励，toast提示"任务未完成" |
|  |  | 任务类型为总任务，已完成任务，当日未领取奖励，次日查看 | 任务还是完成状态，点击领取，奖励下发成功 |
|  |  | 任务类型为总任务，已完成任务，当日未领取奖励，未退出页面，次日点击领取按钮 | 奖励下发成功 |
|  |  | 奖励领取无延长时间，活动结束 | 无法领取奖励 |
|  |  | 奖励领取有延长时间，活动结束 | 在规定时间内可领取奖励 |
|  | 累计奖励 | 活动未开始，完成任务 | 不增加奖励 |
|  |  | 活动开始，第一天做任务，查看奖励 | 增加第一天可领取奖励，但无法领取 |
|  |  | 第二天查看奖励 | 展示第一天生成奖励 |
|  |  | 点击领取 | 成功领取第一天奖励 |
|  |  | 连续点击领取按钮 | 奖励只可下发一次(幂等) |
|  |  | 领取奖励后，再次做任务，查看奖励 | 展示第二天生成奖励，但无法领取 |
|  |  | 第三天点击领取 | 成功领取第二天奖励 |
|  |  | 第三天未做任务 | 不累计奖励 |
|  |  | 每天做任务，次日领取奖励 | 领取成功，每次领取上一天奖励 |
|  |  | 第一天做任务，第二天继续做任务，第N天，查看奖励 | 当前奖励=第一天+第二天+第N天 |
|  |  | 点击领取 | 成功领取第一天奖励，第二天奖励无法领取，剩余奖励=总奖励-已领取第N-1天奖励 |
|  |  | 活动结束，做任务 | 不增加奖励 |
|  |  | 活动结束第一天 | 可领取前一天奖励 |
|  |  | 活动结束，在规定延长时间内 | 领取奖励 |
|  |  | 活动结束，超过规定延长时间 | 奖励清空，无法领取 |
|  |  | 下发水晶奖励 | 查看钱包记录，展示对应记录 |
|  | 奖励IM | 完成任务 | 下发可领取奖励IM |
|  |  | 点击IM消息 | 跳转至活动页 |
|  |  | 日任务 | 每天完成后下发一条 |
|  |  | 总任务 | 只发送一条 |
