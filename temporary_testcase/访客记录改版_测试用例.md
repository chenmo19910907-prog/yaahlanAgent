# 访客记录改版 测试用例

| 编号 | 功能模块 | 测试步骤 | 预期结果 |
|------|----------|----------|----------|
| VR_001 | 入口改版 | 进入「我的」页面，查看访客记录入口名称 | 入口名称显示「访客记录」 |
| VR_002 | 入口改版 | 查看访客记录入口的说明文案 | 说明文案显示「查看谁看过我和我看过谁」 |
| VR_003 | 权限拦截｜非VIP | 使用非VIP账号，点击「访客记录」入口 | 进入页面后整体拦截，内容无法查看，底部展示升级卡片 |
| VR_004 | 权限拦截｜非VIP | 非VIP进入访客记录页，查看底部吸底卡片内容 | 卡片展示最近3名访客的头像 |
| VR_005 | 权限拦截｜非VIP | 非VIP底部卡片访客不足3名时，查看头像展示 | 按实际访客数量展示头像 |
| VR_006 | 权限拦截｜非VIP | 查看底部卡片文案内容 | 文案显示「Active VIP1 to view all people interested in you」 |
| VR_007 | 权限拦截｜非VIP | 点击底部卡片「Activate Now」按钮 | 跳转至 VIP 开通页 |
| VR_008 | 权限拦截｜VIP | 使用已开通VIP的账号点击「访客记录」入口 | 正常进入页面，展示「谁看过我」和「我看过谁」双 Tab |
| VR_009 | 谁看过我｜列表字段 | VIP账号进入「谁看过我」Tab，查看列表每行展示内容 | 每行展示：头像（含头像框）、昵称、性别+年龄、VIP标签、国家icon、语音房在房状态、访问日期+时间、「去查看」按钮 |
| VR_010 | 谁看过我｜访问时间 | 查看「谁看过我」列表中的访问时间格式 | 展示绝对时间（如：2026-04-16 10:30），与手机本地时间一致 |
| VR_011 | 谁看过我｜去查看按钮｜iOS | iOS设备，点击列表右侧「去查看」按钮 | 跳转至该用户的 Profile 页 |
| VR_012 | 谁看过我｜去查看按钮｜Android | Android设备，点击列表右侧「去查看」按钮 | 跳转至该用户的 Profile 页 |
| VR_013 | 谁看过我｜在房状态 | 列表中某访客当前在语音房，点击其在房状态 | 跳转至对应语音房 |
| VR_014 | 谁看过我｜在房状态 | 列表中某访客在私密语音房 | 不展示在房状态 |
| VR_015 | 谁看过我｜数据上限 | 账号被超过200名用户访问后进入「谁看过我」列表 | 列表最多展示200条记录，底部显示「仅支持查看最近 200 条访客记录」 |
| VR_016 | 谁看过我｜下拉刷新 | 在「谁看过我」列表中执行下拉刷新 | 列表数据刷新成功，无异常 |
| VR_017 | 谁看过我｜红点气泡 | 有新用户访问我的 Profile 页 | 底导 Tab icon 右上角出现红点气泡，展示实际新增数量 |
| VR_018 | 谁看过我｜红点数值 | 新访客数量 ≤ 99 时查看红点 | 红点显示实际数字 |
| VR_019 | 谁看过我｜红点数值 | 新访客数量超过 99 时查看红点 | 红点固定显示「99+」 |
| VR_020 | 谁看过我｜红点消除 | 进入「访客记录」页面后退出 | 底导 Tab icon 红点消除 |
| VR_021 | 谁看过我｜红点与刷新联动 | 在列表查看时有新访客到来，未执行下拉刷新，退出列表 | 退出后底导 icon 仍展示红点气泡 |
| VR_022 | 谁看过我｜红点与刷新联动 | 在列表查看时有新访客到来，执行下拉刷新后退出列表 | 退出后底导 icon 不展示红点气泡 |
| VR_023 | 我看过谁｜记录触发 | 使用账号A访问账号B的 Profile 页，然后进入账号A的「我看过谁」Tab | 「我看过谁」列表中出现账号B的访问记录 |
