# BD系统 测试用例

> 需求版本：Yaahlan-2.5.5

| 功能模块 | 测试步骤 | 预期结果 |
|---------|---------|---------|
| 【BD入口展示】 | 使用已加入白名单的BD账号登录App，进入个人主页 | 个人主页显示BD中心入口 |
| | 使用非BD账号登录App，进入个人主页 | 个人主页不显示BD中心入口 |
| | BD账号被萨克从后台移除后，重新打开App | BD中心入口消失，不再展示 |
| 【BD中心布局】 | BD用户点击个人主页BD中心入口 | 进入BD中心，顶部展示标题、专属下载链接；展示公会/大R切换tab（默认定位大R tab）；底部有吸底规则文案；右上角有规则页跳转按钮 |
| | 点击右上角规则跳转按钮 | 跳转至规则页 |
| 【BD大R列表】 | 进入大R tab，查看列表字段 | 展示：用户ID、VIP等级（注册30日内）、进入平台时间；按注册时间倒序排列 |
| | 在大R tab下方切换筛选为"周期内" | 仅展示注册未满30日的大R挖猎记录 |
| | 切换筛选为"周期外" | 仅展示注册已满30日的大R挖猎记录 |
| | 该BD暂无任何大R挖猎行为时 | 列表展示空页面 |
| | 大R奖励已下发，查看对应条目按钮 | 显示"已下发"跳转按钮 |
| | BD身份为主播时，点击已下发按钮 | 跳转至薪资明细页，定位至对应记录 |
| | BD身份为非主播时，点击已下发按钮 | 跳转至个人钱包金币下发明细页，定位至对应记录 |
| | 大R充值未达奖励标准，查看对应条目状态 | 显示"无奖励" |
| | 大R奖励被后台拒绝，查看对应条目状态 | 显示"已拒绝" |
| | 点击"已拒绝"按钮 | 弹出弹窗，根据拒绝原因显示对应文案；工单被拒绝时显示特殊原因 |
| | 奖励未到打款时间（大R注册未满30天），查看大R tab条目 | 显示VIP等级信息，无下发/已拒绝相关按钮 |
| | 点击大R挖猎条目的奖励查看按钮 | 弹出弹窗，包含"查看收到奖励"文案；点击钻石奖励按钮跳转钻石明细页；点击美金奖励按钮跳转薪资/钱包明细页 |
| | 点击弹窗内取消按钮 | 关闭弹窗 |
| 【BD公会列表】 | 点击公会tab切换按钮 | 切换至公会挖猎列表 |
| | 查看公会列表字段 | 展示：公会长ID、公会ID、返利计算开始时间、第一周期薪资、第二周期薪资；按返利计算时间倒序排列 |
| | 在公会tab切换筛选为"周期内" | 仅展示仍在第一/第二周期内的公会挖猎记录 |
| | 切换筛选为"周期外" | 仅展示已完成两个周期的公会挖猎记录 |
| | 该BD暂无任何公会挖猎行为时 | 列表展示空页面 |
| | 公会奖励已下发，查看状态 | 显示跳转按钮，逻辑与大R一致 |
| 【BD专属链接】 | 查看BD中心顶部专属下载链接 | 每位BD有唯一专属下载链接 |
| | 新用户通过该BD专属链接下载注册 | 用户与该BD关联，在BD中心对应tab中出现该用户记录 |
| 【大R奖励发放】 | 大R用户注册满31天00:00，查看后台奖励状态 | 按注册30天内实际达到的VIP等级，对应奖励进入待审批状态 |
| | 大R注册30天内达到VIP3与达到VIP5的奖励对比 | 不同VIP等级对应不同钻石和美金数量，档位正确 |
| | 奖励审批通过后，BD身份为主播 | 美金奖励发放至BD薪资账户 |
| | 奖励审批通过后，BD身份为非主播 | 美金奖励发放至BD个人账户 |
| 【公会奖励发放】 | 工会建立后第一周期结束 | 按该周期公会薪资（含预提）对应档位，第一周期奖励进入待审批状态 |
| | 第二周期结束 | 第二周期奖励进入待审批状态；周期1与周期2各自独立 |
| | 奖励计算中的公会薪资是否含预提 | 公会前两个周期薪资包含预提部分 |
| 【挖猎道具奖励】 | 大R被添加到挖猎列表后达到VIP2 | 道具奖励发送至大R用户个人装扮；小助手发送带跳转按钮的提醒消息，点击跳转至我的装扮页 |
| | 大R被添加到挖猎列表但未达到VIP2 | 不发放道具奖励 |
| | 公会长被添加到公会挖猎列表 | 道具奖励发放至公会长背包礼物；小助手发送带跳转按钮的提醒消息，点击跳转至背包礼物页 |
| | 用户身份先为大R后转变为公会长 | 需发送两份道具奖励（大R奖励+公会长奖励） |
| 【大R挖猎列表】 | 萨克进入挖猎运营页，查看默认定位tab | 默认定位至大R挖猎tab |
| | 查看大R挖猎顶部统计 | 展示挖猎大R总数、总发出奖励 |
| | 查看大R挖猎列表字段 | 展示：挖猎大R ID、名称、注册日期、VIP等级（30天内）、注册30天内累充金额（实时更新）、BD返利（钻石和美金）、打款时间（精确到分钟）、挖猎BD ID、同设备历史关联账号（仅录入时查询）、单条挖猎状态、操作栏 |
| | 查看列表默认排序 | 按注册时间倒序排列 |
| 【大R挖猎筛选】 | 在搜索框输入用户ID | 列表过滤为匹配用户 |
| | 在搜索框输入BD ID | 列表过滤为匹配BD的挖猎记录 |
| | 筛选"周期内" | 仅展示用户注册未满31天的挖猎记录 |
| | 筛选"周期结束" | 仅展示用户注册已满31天的挖猎记录 |
| | 筛选状态"待审批" | 仅展示待审批状态的记录 |
| | 筛选状态"已拒绝" | 仅展示已拒绝状态的记录 |
| | 筛选状态"已同意工单进行中" | 仅展示工单进行中状态的记录 |
| | 筛选状态"工单被拒绝" | 仅展示工单被拒绝状态的记录 |
| | 筛选状态"工单通过已打款" | 仅展示已打款状态的记录 |
| 【大R挖猎导出】 | 点击导出按钮 | 导出Excel，字段与列表完全一致 |
| | 点击打款记录导出，选择单日后确认 | 导出该日期已打款（已同意且工单通过）的挖猎记录Excel |
| | 选择一段时间后导出 | 导出该时间段内的已打款记录 |
| 【大R打款审批】 | 用户注册满31天00:00，查看该条操作栏和状态 | 操作栏出现"同意打款"和"拒绝"按钮；状态变为"待审批" |
| | 点击同意打款按钮 | 弹出二次确认弹窗，包含打款金额和收款账户UID |
| | 二次确认弹窗点击确认 | 生成线上审批工单；状态变为"已同意工单进行中"；同意/打款金额修改/身份修改按钮隐藏 |
| | 工单审批通过 | 打款生效；打款时间更新为工单生效时间；状态变为"工单通过已打款"；操作按钮全隐藏 |
| | 工单被拒绝 | 状态变为"工单被拒绝"；打款时间更新为工单拒绝时间；操作按钮全隐藏 |
| | 工单生成后工单审批前，点击拒绝打款按钮 | 弹出特殊拒绝弹窗，含额外文案"此打款已在审批中是否确认修改为拒绝，拒绝后将不打款且无法修改" |
| | 在上述特殊拒绝弹窗确认拒绝 | 状态变为"已拒绝"；最终打款中该笔不生效 |
| 【大R打款拒绝】 | 未到审批中时，点击拒绝打款按钮 | 弹出拒绝打款原因填写弹窗 |
| | 在弹窗手动填写英语和阿语原因后 | 无法再点击常用原因选项 |
| | 在弹窗选择常用原因选项（单选） | 无法再手动填写；无需手动填写原因 |
| | 确认拒绝 | 状态变为"已拒绝"；打款金额修改/同意拒绝/身份修改按钮全隐藏 |
| 【大R金额修改】 | 在用户注册30天内查看修改按钮 | 修改按钮不显示 |
| | 同意或拒绝后查看修改按钮 | 修改按钮不显示 |
| | 在可修改期间（注册30天后且未同意/拒绝）点击修改按钮 | 弹出修改弹窗，文本框内显示原打款金额，可编辑 |
| | 修改金额后点击确定 | 实际打款金额更新；BD返利栏显示修改后的钻石和美金数量 |
| 【大R身份修改】 | 点击身份修改按钮 | 弹出身份修改弹窗，包含公会实际成立日期（不可修改）、返利开始计算日期（单日选择）、公会ID（必填） |
| | 填写完整信息后确认 | 该挖猎记录从大R列表删除；公会列表新增该记录；BD返利与该公会绑定 |
| | 已同意/拒绝后查看身份修改按钮 | 按钮隐藏，不可修改 |
| 【大R手动新增】 | 点击新增按钮，填写用户ID和BD ID后确认 | 新增成功，列表中出现该条挖猎记录 |
| | 填写列表中已存在的用户ID后确认 | toast提示用户ID重复，新增失败 |
| 【公会挖猎列表】 | 点击公会挖猎tab | 顶部展示挖猎公会总数和总发出奖励；列表按返利计算时间倒序排列 |
| | 查看公会挖猎列表字段 | 展示：挖猎公会ID、公会长ID、公会名称、成立时间（精确到天）、返利计算周期开始时间（精确到天）、周期1/2公会总薪资（不含子公会）、周期1/2 BD返利（钻石和美金）、周期1/2打款时间（精确到分钟）、挖猎BD ID、同设备历史关联账号（仅录入时查询）、状态栏、操作栏 |
| 【公会挖猎筛选】 | 搜索公会ID | 列表过滤为匹配公会 |
| | 搜索BD ID | 列表过滤为匹配BD的公会挖猎记录 |
| | 筛选"周期内" | 仅展示仍在第一/第二周期内的公会 |
| | 筛选"周期结束" | 仅展示已完成两个周期的公会 |
| | 筛选挖猎状态（不区分第一/第二周期） | 对应状态的记录正确过滤 |
| 【公会周期1打款】 | 周期1结束后次日00:00，查看操作栏 | 出现"周期1打款"和"周期1拒绝"按钮；状态栏变为"周期1待审批" |
| | 点击周期1打款，二次确认弹窗确认 | 状态变为"周期1打款工单审批中"；周期1同意/金额修改/返利开始时间修改按钮隐藏 |
| | 周期1工单审批通过 | 打款生效；周期1打款时间更新；状态变为"周期1工单通过已打款" |
| | 周期1工单被拒绝 | 状态变为"周期1工单被拒绝"；打款时间改为工单拒绝时间 |
| | 周期1工单生成后再次点击拒绝 | 弹出特殊弹窗提示"此打款已在审批中"，确认后单笔打款不生效 |
| 【公会周期2打款】 | 周期2结束后次日00:00，查看操作栏 | 出现"周期2打款"和"周期2拒绝"按钮；状态栏包含"周期2待审批"；周期1状态不受影响 |
| | 周期1已打款完成，单独操作周期2打款 | 周期1状态不变；周期2独立完成打款流程 |
| 【公会返利时间修改】 | 点击修改返利开始计算时间按钮 | 弹出日历选择器（仅支持选择单日），修改后返利周期随之调整 |
| | 任意一周期已同意或拒绝后查看修改按钮 | 修改按钮隐藏，不可修改 |
| 【公会金额修改】 | 在周期结束前查看对应周期金额修改按钮 | 修改按钮不显示 |
| | 在可修改期间修改周期1打款金额 | 修改成功；BD返利栏金额更新 |
| | 周期1修改金额后，查看周期2修改按钮 | 周期2独立，不受影响 |
| 【公会手动新增】 | 点击新增公会，填写公会ID、BD ID、返利开始时间（均必填），确认 | 新增成功，公会挖猎列表出现该记录 |
| | 有任意必填项为空时确认 | 新增失败，必填项提示 |
| 【公会挖猎导出】 | 点击导出按钮 | 导出Excel，字段与列表一致 |
| | 点击打款记录导出，选择时间段 | 导出该时间段内任意周期（周期1或周期2）有打款的记录 |
| 【BD管理列表】 | 进入BD管理tab，查看顶部统计 | 展示：当前APP内BD总人数、近30天挖猎总大R数、近30天挖猎总公会数、近30天发出总奖励 |
| | 查看BD列表字段 | 展示：BD ID、BD真实姓名、入职时间（萨克同意申请的时间）、WhatsApp号码、近30天挖猎总数、近30天收到返利、操作栏 |
| | 搜索BD ID | 列表过滤为匹配BD |
