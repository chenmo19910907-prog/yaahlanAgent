# 币商在线充值-真人认证 测试用例

| CRT_002 | 真人认证触发｜30日周期 | 币商上次认证距今未满 30 个自然日，点击「在线充值」 | 不触发真人认证，直接进入充值流程 |
| CRT_003 | 真人认证触发｜30日周期 | 币商上次认证距今恰好满 30 个自然日（临界值），点击「在线充值」 | 触发真人认证弹窗，需重新完成认证 |
| CRT_004 | 真人认证触发｜30日周期 | 币商上次认证距今超过 30 个自然日，点击「在线充值」 | 触发真人认证弹窗，需重新完成认证 |
| CRT_005 | 真人认证触发｜30日周期 | 币商完成真人认证后，在 30 日内再次点击「在线充值」 | 不触发真人认证，直接进入充值流程 |
| CRT_006 | 真人认证触发｜换绑手机号 | 币商更换绑定手机号后，首次点击「在线充值」 | 触发真人认证弹窗，需完成认证后方可继续充值 |

| CRT_008 | 真人认证触发｜更换设备 | 币商更换设备（设备 ID 变更）后，首次点击「在线充值」 | 触发真人认证弹窗，需完成认证后方可继续充值 |
| CRT_009 | 真人认证触发｜更换设备 | 币商更换设备后完成真人认证，在同一设备再次点击「在线充值」 | 不再因设备变更触发认证，正常进入充值流程 |
| CRT_010 | 真人认证触发｜更换设备 | 币商完成认证后再次更换新设备，点击「在线充值」 | 再次触发真人认证弹窗 |
| CRT_011 | 真人认证触发｜IP 国家变更 | 币商切换所在国家 IP 后，首次点击「在线充值」 | 触发真人认证弹窗，需完成认证后方可继续充值 |
| CRT_012 | 真人认证触发｜IP 国家变更 | 币商切换 IP 后完成真人认证，在同一 IP 环境再次点击「在线充值」 | 不再因 IP 变更触发认证，正常进入充值流程 |
| CRT_013 | 真人认证触发｜IP 国家变更 | 币商完成认证后切换到第三个国家 IP，点击「在线充值」 | 再次触发真人认证弹窗 |
| CRT_014 | 真人认证触发｜多条件叠加 | 币商同时满足「30日已到期 + 换绑手机号 + 更换设备」，点击「在线充值」 | 触发真人认证弹窗（任一条件满足即触发），完成一次认证后即可继续充值 |
| CRT_015 | 认证流程｜正常通过 | 触发认证弹窗后，币商完成真人认证（眨眼检测通过） | 认证成功，弹窗关闭，自动进入充值流程；认证时间节点重置（30 日重新计算） |
| CRT_016 | 认证流程｜认证失败 | 触发认证弹窗后，真人认证失败（检测未通过） | 认证失败提示，无法进入充值流程；可重新发起认证 |
| CRT_017 | 认证流程｜取消认证 | 触发认证弹窗后，币商主动关闭/取消认证弹窗 | 关闭弹窗，不进入充值流程；下次点击「在线充值」仍需触发认证 |
| CRT_018 | 认证流程｜无相机权限 | 触发认证弹窗后，用户未授权相机权限，点击「开始认证」 | 弹出相机权限引导弹窗，拒绝后无法完成认证，充值流程不继续 |
| CRT_019 | 信息一致性校验｜通过 | 币商完成真人认证，认证信息与币商上传的信息一致 | 认证通过，可正常进入充值流程 |
| CRT_020 | 信息一致性校验｜不一致 | 币商完成真人认证，但认证信息与币商上传信息不一致 | 认证失败，提示信息不一致，无法进入充值流程 |
| CRT_021 | 非币商用户｜不受影响 | 普通用户（非币商）进行充值操作 | 不触发真人认证流程，正常充值 |
