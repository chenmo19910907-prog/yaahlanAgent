# 主播提现增加二次确认弹窗 测试用例

| 功能模块 | 测试步骤 | 预期结果 |
|----------|----------|----------|
| 【提现入口-原倒计时移除】 | 主播/子工会长进入提现页，选择"转账给母公会长"方式 | 提现页原有确认倒计时不再展示，按钮直接可点击 |
| 【二次确认弹窗-触发】 | 主播在提现页选择"转账给母公会长"，点击确认按钮 | 弹出二次确认弹窗 |
| | 子工会长在提现页选择"转账给母公会长"，点击确认按钮 | 弹出二次确认弹窗 |
| 【二次确认弹窗-内容展示】 | 弹窗弹出后，查看转出金额 | 显示本次实际转出金额，与填写金额一致 |
| | 查看弹窗内对方信息 | 对方头像、ID、昵称均展示正确 |
| | 查看弹窗提示文案 | 展示"请仔细确认是否转账给此人，转出后无法撤销，谨防诈骗" |
| | 使用长昵称的母公会长，查看弹窗昵称展示 | 长昵称不截断异常，展示正常 |
| 【二次确认弹窗-语音播放】 | 弹窗弹出，查看右上角按钮 | 右上角存在语音播放按钮 |
| | 点击语音播放按钮（非语音房场景） | 播放固定音频，内容为"请仔细确认是否转账给此人，转出后无法撤销，谨防诈骗" |
| | 用户在语音房内，点击语音播放按钮 | 无法播放，toast 提示对应文案 |
| 【二次确认弹窗-确认按钮倒计时】 | 弹窗刚弹出时，查看确认按钮状态 | 确认按钮置灰不可点击，按钮上显示倒计时 |
| | 倒计时期间点击确认按钮 | 点击无响应，不发起转账 |
| | 等待倒计时结束，查看确认按钮状态 | 按钮变为高亮可点击状态 |
| | 倒计时结束后点击确认按钮 | 关闭弹窗，转账发起成功 |
| 【二次确认弹窗-取消】 | 弹窗弹出后，点击取消按钮 | 仅关闭弹窗，不发起转账，返回提现页面 |
| | 倒计时期间点击取消按钮 | 同样仅关闭弹窗，不发起转账 |
| 【转账金额边界】 | 填写最小金额 1 美元后触发弹窗，确认转账 | 转账成功，金额扣减正确 |
| | 填写最大金额 10000 美元后触发弹窗，确认转账 | 转账成功，金额扣减正确 |
| 【其他提现方式不受影响】 | 主播选择其他提现方式（如现金提现、代收提现等） | 其他提现方式流程不受本次改动影响，展示正常 |
| 【多语言】 | 分别切换英语、阿语、土语、俄语，触发二次确认弹窗 | 弹窗内文案、按钮翻译正确；阿语 RTL 布局展示正常 |
