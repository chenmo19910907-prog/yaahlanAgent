# 客服转工单 测试用例

> PRD 来源：Yaahlan-2.5.4 版本需求 - 客服转工单
> 知识库对照：testcase-kb/客服.md、documents/客服.md
> 生成时间：2026-06-09

---

## 疑问点

1. "取消每个用户一天只能联系两次游戏客服的限制"——是否仅对转单场景取消，还是整体取消？如何验证？
2. 满单后"再派5单"——是每名已满单客服各可再派5单，还是整体额外增加5单配额？
3. 强弹弹窗"从上划到底"的判定标准——滚动到最后一条消息即可，还是需滚动条触底？
4. 无工单时点击转单按钮的具体 toast 文案是什么？

---

## 测试用例

| 功能模块 | 测试步骤 | 预期结果 |
|---------|---------|---------|
| 【开关控制】 | 服务端关闭转单开关，客服接到工单后点击操作栏"转工单"按钮 | 弹出 toast 提示无法转单，工单不转出 |
|  | 无工单时点击转工单按钮 | 弹出 toast 提示对应文案（当前暂无可转出工单），操作无效 |
| 【转单入口与菜单】 | 客服接到工单后，查看聊天页底部操作栏 | 展示"转工单"按钮 |
|  | 点击"转工单"按钮 | 打开转单菜单，菜单内展示可选的目标客服类型 |
|  | 在转单菜单中点击目标类型按钮 | 按钮变为选中态，其余按钮取消选中 |
|  | 选中目标类型后点击确定 | 弹窗关闭，工单转出成功 |
|  | 点击转单菜单右上角关闭按钮 | 菜单关闭，工单不转出，转单按钮仍可点击 |
| 【工单分配】 | 所有在线客服均已满 50 单，此时产生一个转单工单 | 转单工单正常派发，满单客服允许再接该转单工单（超出正常 50 单上限） |
| 【计时重置】 | 工单转单成功后，接收方客服与用户重新开始计时，验证超时逻辑 | 双方12分钟无消息、客服10分钟不回复用户、用户10分钟不回复客服的超时计时均从转单后重新开始，与转出前无关 |
| 【转单限制】 | 已转出工单的转出方客服，在该聊天页再次点击转工单按钮 | toast 提示"当前暂无可转出工单"，无法再次转出 |
|  | 该用户产生新工单后，转出方客服再次点击转工单按钮 | 转单菜单正常打开，可进行新一轮转单 |
|  | 目标用户已与目标类型客服有正在进行中的工单，点击确认转出 | toast"无法转出，用户已有与xx客服正在进行中的工单"，转单失败，原工单继续 |
| 【转出方反馈】 | 转出工单成功后，观察转出方客服端 | toast"工单结束，已成功转出"；聊天框内出现系统消息"已转单至xx客服（仅客服可见）"；操作栏转单按钮消失（工单已结束） |
| 【接收方IM列表】 | 转单后，接收方客服查看 IM 消息列表 | 该转单工单在 IM 列表做特殊标识（区别普通派单），客服记录列表中同样有特殊显示 |
|  | 转单工单结束后，接收方客服查看 IM 列表 | 该工单恢复正常显示样式（特殊标识消失） |
| 【接收方聊天页】 | 接收方客服点击进入转单工单的聊天页 | 聊天页显示一条系统消息（仅客服可见）：提示接到转单工单、需查看历史记录，文案末尾有"聊天历史记录"按钮 |
| 【接收方操作栏】 | 接收方客服查看转单聊天页底部操作栏 | 展示"历史记录"按钮，不展示"转工单"按钮 |
|  | 转单工单结束后，接收方查看操作栏 | "历史记录"按钮消失 |
| 【历史记录弹窗】 | 接收方客服首次进入转单聊天页 | 自动强弹历史记录弹窗；弹窗标题"历史记录"，包含系统消息提示和转出前聊天记录 |
|  | 在强弹弹窗内将内容上划到底，然后点击返回/关闭按钮 | 弹窗关闭，判定客服已接单，系统向用户发送消息"xxx接单了" |
|  | 在强弹弹窗内未划到底，点击弹窗内返回按钮 | toast"服务前需阅读用户与上一位客服间的历史记录"，弹窗不关闭，强制继续阅读 |
|  | 查看弹窗内记录内容，尝试上下滑动、长按消息、点击图片/视频/语音 | 上下滑动流畅；长按消息可复制；图片/视频支持浏览，语音支持收听 |
|  | 工单进行中，点击聊天页系统消息内的"历史记录"按钮 | 始终打开此次转单相关的历史聊天记录，不随新转单更新为最新记录 |
| 【用户视角】 | 客服转单成功后，用户查看与转出客服的聊天页 | 收到系统消息"已转单至xx客服，点击链接跳转至对应聊天页"（仅用户可见，客服侧不可见） |
|  | 客服转单时，用户正在与转出客服的聊天页内 | 用户页面自动跳转至接收方客服聊天页，聊天页内显示系统消息"已转单至xx客服，请稍等，聊天记录已同步无需再次说明"（仅用户可见） |
|  | 用户点击系统消息中的跳转链接 | 跳转至接收方客服聊天页；在该页内点击返回，回到 IM 列表 |
|  | 转单完成后，用户查看 IM 列表 | 列表中同时显示与转出方和接收方两个不同类型客服的聊天卡片，均展示正常 |
|  | 转单时用户不在与客服的聊天页，转单后用户查看 IM 列表 | 接收方客服 IM 卡片出现，预览消息处显示系统消息内容，有红点标识 |
| 【VIP客服转单】 | VIP 客服接单后点击转工单，查看菜单 | 菜单中展示"游戏客服"选项；选中后点确定，工单正常转出至游戏客服 |
| 【游戏客服转单】 | 游戏客服接单，用户 VIP 等级 ≥ 1，点击转工单 | 菜单中展示"VIP 客服"选项；选中后点确定，工单正常转出至 VIP 客服 |
|  | 游戏客服接单，用户 VIP 等级 < 1，点击转工单后选择 VIP 客服并确认 | toast 提示（用户未达 VIP 等级1），无法转出 |
| 【语音房客服转单】 | 语音房客服接单，用户 VIP ≥ 1，查看转单菜单 | 菜单中展示"VIP 客服"和"游戏客服"两个选项，均可正常转出 |
|  | 语音房客服接单，用户 VIP < 1，查看转单菜单 | 菜单中不展示"VIP 客服"选项，仅展示"游戏客服"选项 |
| 【后台记录】 | 转单结束的工单，查看后台工单数据的结束方式字段 | 结束方式包含"转单结束"状态（区别于用户手动/客服手动/系统超时结束） |
|  | 查看转出方工单的消息详情 | 详情中包含转出后接收方客服与用户的后续聊天记录 |
|  | 查看接收方工单的消息详情 | 详情中包含转出前转出方客服与用户的历史聊天记录 |
