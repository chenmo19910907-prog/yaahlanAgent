# 代收增加关联子账号 测试用例

| 功能模块 | 测试步骤 | 预期结果 |
|----------|----------|----------|
| 【子账号-提现限制】 | 使用已配置为子账号的账户，进入钱包页点击提现 | toast 提示"你的账号没有操作权限"，提现流程不发起 |
| 【子账号-转账限制】 | 子账号打开与非主账号用户的聊天框 | 聊天框内不显示转账操作入口 |
| | 子账号尝试通过其他入口向非主账号用户转账 | 操作被拦截，无法发起转账 |
| 【子账号-向主账号转账】 | 子账号打开与主账号的聊天框，发起转账 | 转账入口正常显示，操作成功，主账号余额正确增加 |
| 【子账号-接收转账】 | 其他主播对子账号发起转账 | 转账成功，子账号余额正确增加 |
| 【代收推荐】 | 推荐命中带子账号的代收，主账号在线、子账号离线 | 推荐主账号 |
| | 推荐命中带子账号的代收，子账号在线、主账号离线 | 推荐子账号 |
| | 推荐命中带子账号的代收，主账号与多个子账号均在线 | 从所有在线关联账号中随机推荐 1 个 |
| | 推荐命中带子账号的代收，主账号和所有子账号均离线 | ⚠️ 预期结果待确认：是否不推荐该代收或降级处理 |
| 【取消子账号】 | 服务端将某账号从子账号列表移除后，该账号点击提现 | 提现正常，不再出现权限拦截 toast |
| | 服务端移除子账号配置后，该账号打开与任意用户的聊天框 | 转账入口恢复正常显示，可向非主账号发起转账 |
| 【代收推荐-信息展示】 | 代收推荐展示子账号时，查看该账号名片 | 头像、头像框、徽章、ID、昵称展示正确；长昵称不截断异常，动态头像正常播放 |
| 【账单明细】 | 其他主播向子账号转账成功后，子账号进入账单明细查看收款记录 | 收款时间、金额、转账人信息均展示正确；点击转账人可跳转私信页 |
| 【基础回归-代收提现】 | 主账号（未取消子账号配置）正常发起代收提现流程 | 主账号代收提现流程不受本次子账号改动影响，流程正常 |
| 【多语言】 | 分别切换英语、阿语、土语、俄语，子账号点击提现 | 各语言环境下拦截 toast 文案翻译正确；阿语 RTL 布局展示正常 |
