# 活动房一键邀请所有好友 测试用例

> 需求来源：Yaahlan-2.5.0 版本需求
> 涉及模块：活动房设置页通知开关、活动房内一键分享、普通房一键邀请

| 用例编号 | 功能模块 | case步骤描述 | 预期结果 |
|---------|----------|-------------|---------|
| INV_001 | 设置页开关｜默认状态 | 进入创建活动房设置页面，查看「开始时通知所有好友」开关状态 | 开关默认为关闭状态 |
| INV_002 | 设置页开关｜位置展示 | 进入创建活动房设置页面，查看开关位置 | 开关显示在 starting time 选项上方，展示正确 |
| INV_003 | 设置页开关｜创建前开启 | 在创建活动房设置页面将开关开启，完成创建，等待到达活动开始时间 | 到达开始时间时，房主自动通过私聊给所有好友各发送一条活动房邀请消息 |
| INV_004 | 设置页开关｜创建前保持关闭 | 在创建活动房设置页面保持开关关闭，完成创建，等待到达活动开始时间 | 到达开始时间时，不自动发送任何好友邀请消息 |
| INV_005 | 设置页开关｜活动未开始时修改为开启 | 活动房已创建但尚未开始，进入活动房设置页，将开关从关闭改为开启，保存 | 修改成功；到达活动开始时间时，自动给所有好友发送邀请消息 |
| INV_006 | 设置页开关｜活动未开始时修改为关闭 | 活动房已创建（开关为开启状态）但尚未开始，进入活动房设置页，将开关关闭，保存 | 修改成功；到达活动开始时间时，不发送好友邀请消息 |
| INV_007 | 设置页开关｜好友数为0 | 开启开关后到达活动开始时间，但房主当前好友列表为空 | 不发送消息，无异常崩溃 |
| INV_008 | 邀请消息｜消息到达 | 开关开启，活动开始后，以好友 A 身份查看私聊列表 | 在与房主的私聊中收到一条活动房邀请卡片消息 |
| INV_009 | 邀请消息｜消息样式 | 好友收到邀请消息后，查看消息卡片样式 | 卡片样式与现有活动房邀请消息一致 |
| INV_010 | 邀请消息｜活动未开始时点击卡片 | 好友在活动开始前点击收到的邀请卡片 | 跳转至活动房详情页 |
| INV_011 | 邀请消息｜活动已开始后点击卡片 | 好友在活动开始后点击收到的邀请卡片 | 直接进入活动房间 |
| INV_012 | 邀请消息｜多好友均收到 | 开关开启，房主有多位好友，活动开始时，以不同好友账号查看私聊 | 每位好友均在与房主的私聊中收到一条邀请消息，无遗漏 |
| INV_013 | 活动房内一键分享｜房主分享菜单入口 | 活动房开始后，房主打开分享菜单，查看菜单内容 | 分享菜单中包含「一键分享给所有好友」按钮 |
| INV_014 | 活动房内一键分享｜管理员分享菜单入口 | 活动房开始后，房间管理员打开分享菜单，查看菜单内容 | 分享菜单中包含「一键分享给所有好友」按钮 |
| INV_015 | 活动房内一键分享｜普通成员无入口 | 活动房开始后，普通成员（非房主非管理员）打开分享菜单 | 分享菜单中无「一键分享给所有好友」按钮 |
| INV_016 | 活动房内一键分享｜活动未开始时无入口 | 活动房尚未开始，房主打开分享菜单 | 分享菜单中无「一键分享给所有好友」按钮 |
| INV_017 | 活动房内一键分享｜点击分享 | 活动房开始后，房主点击分享菜单中的「一键分享给所有好友」 | toast 提示「分享成功」 |
| INV_018 | 活动房内一键分享｜按钮置灰变invited | 房主点击「一键分享给所有好友」后，查看该按钮状态 | 按钮变为置灰且文案更改为「invited」 |
| INV_019 | 活动房内一键分享｜单人分享按钮同步置灰 | 房主点击「一键分享给所有好友」后，查看分享菜单中单独分享给单个用户的按钮 | 单个用户分享按钮同步置灰，文案更改为「invited」 |
| INV_020 | 活动房内一键分享｜私聊消息发送 | 房主点击「一键分享给所有好友」后，以好友身份查看私聊 | 在与房主的私聊中收到一条活动房邀请消息，消息内容与单人分享消息一致 |
| INV_021 | 活动房内一键分享｜重新打开分享菜单状态 | 房主分享后关闭菜单，再次打开分享菜单 | 「一键分享给所有好友」按钮仍为置灰/invited 状态 |
| INV_022 | 活动房内一键分享｜10分钟内点击已分享按钮 | 分享后 10 分钟内，房主重新打开分享菜单，点击置灰的「一键分享给所有好友」按钮 | toast 提示「已分享，请稍后再试」，不重复发送消息 |
| INV_023 | 活动房内一键分享｜10分钟内点击单人置灰按钮 | 分享后 10 分钟内，房主重新打开分享菜单，点击某个单个用户的置灰分享按钮 | toast 提示「已分享，请稍后再试」，不重复发送消息 |
| INV_024 | 活动房内一键分享｜10分钟后恢复 | 房主点击一键分享后等待超过 10 分钟，重新打开分享菜单 | 「一键分享给所有好友」按钮及单个用户分享按钮恢复为可点击状态 |
| INV_025 | 活动房内一键分享｜管理员独立冷却 | 管理员点击「一键分享给所有好友」后 10 分钟内，房主再次查看分享菜单 | 房主侧分享按钮状态不受管理员操作影响，各自独立计算冷却 |
| INV_026 | 活动房内一键分享｜好友为0 | 房主好友列表为空，点击「一键分享给所有好友」 | toast「分享成功」（或无好友提示），不崩溃，无异常 |
| INV_027 | 普通房一键邀请｜分享面板入口 | 进入普通房，打开分享面板 | 分享面板中包含「一键邀请所有好友」功能入口 |
| INV_028 | 普通房一键邀请｜点击后发送消息 | 在普通房分享面板中点击「一键邀请所有好友」 | 给所有好友各发送一条该房间邀请私聊消息 |
| INV_029 | 普通房一键邀请｜接收方限频-10分钟内不重复 | 用户 A 在普通房点击一键邀请，10 分钟内再次点击，好友 B 查看私聊 | 好友 B 在 10 分钟内只收到一条该房间邀请消息，不重复接收 |
| INV_030 | 普通房一键邀请｜接收方限频-10分钟后可再收 | 用户 A 第一次点击邀请后等待超过 10 分钟，再次点击一键邀请，好友 B 查看私聊 | 好友 B 可再次收到邀请消息 |
| INV_031 | 普通房一键邀请｜不同房间限频独立 | 用户 A 在房间 X 邀请好友 B，10 分钟内切换到另一个房间 Y，再次一键邀请 | 好友 B 可收到房间 Y 的邀请消息（不同房间限频独立计算） |
| INV_032 | 多语言｜英语 | 系统语言设为英语，触发活动房设置开关文案、一键分享按钮、分享成功 toast、invited 文案 | 所有相关文案正确显示英语，无乱码 |
| INV_033 | 多语言｜阿语 | 系统语言设为阿语，完成同上验证 | 所有文案正确显示阿语，无乱码；RTL 布局镜像正常 |
| INV_034 | 多语言｜土语 | 系统语言设为土语，完成同上验证 | 所有文案正确显示土语，无乱码 |
| INV_035 | 多语言｜俄语 | 系统语言设为俄语，完成同上验证 | 所有文案正确显示俄语，无乱码 |
