## E2E 能力清单（自动生成）

> 由 `e2e/scripts/generate_index.py` 根据 `e2e/config/registry.json` 生成。

### 使用说明

- **定位**：独立于 `adb/`；**识别 → 思考 → 执行** 三步循环
- **入口**：`python3 e2e/e2e_execute.py`
- **识别**：`perceive` · **单步**：`cycle --step`
- **用例**：`cases/*.json` 的 `flow[]`
- **知识库**：`testcase-kb/`、`verified-kb/`
- **报告**：`e2e/reports/`

## 1) 三步循环

### 单步循环（识别→思考→执行）

- **功能**：对一条自然语言步骤完成 perceive + think + act
- **命令**：

```bash
python3 e2e/e2e_execute.py cycle --step "<自然语言步骤>" --case <caseId>
```

## 2) 三步循环 · 识别

### 识别屏幕

- **功能**：读取当前屏 Activity + ui.clickables（adb observe --fast）
- **命令**：

```bash
python3 e2e/e2e_execute.py perceive
```

## 3) 基础

### 环境自检

- **功能**：检查 e2e 目录、config、cases、adb 桥接
- **命令**：

```bash
python3 e2e/e2e_execute.py doctor
```

## 4) 执行

### 运行自然语言用例

- **功能**：按 cases/*.json 的 flow[] 逐步执行三步循环，并 Tunnel 验收
- **命令**：

```bash
python3 e2e/e2e_execute.py run --case <caseId>
```

## 5) 用例

### 列出用例

- **功能**：扫描 cases/ 下 JSON 用例
- **命令**：

```bash
python3 e2e/e2e_execute.py list
```
