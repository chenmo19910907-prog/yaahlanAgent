### 使用说明

- **用途**：把 Tunnel 抓到的客户端 HTTP body，套成 MSE httpproxy 可调的 MOA payload（双写 `header` + `params`）
- **环境**：测试环境（alpha / stage 代理）；勿用于线上
- **前置**：Tunnel 拿到 request body；MSE 调用链拿到真实 **ServiceUrl** + **Method**（禁止仅凭 HTTP 路径瞎猜 ServiceUrl）
- **套壳铁律**：`header` = body 的 JSON 字符串；`params[0].type=json` 且 `value`/`json` 与 header 同内容。只写 params 易 System error；body 当 TXT 字符串易 ClassCastException
- **推荐入口**：工作流 `moa-generative-run`（与 `run_generative_moa.py` 同逻辑）；报告见 `.tmp/workflow_runs/`
- **strict**：`0`（默认）代理调通即成功（已签到/已点赞等业务拒绝也算过）；`1` 要求业务 `success=true` / `ec=200`
- **对照表**：已验证 HTTP↔MOA 见 `MOA-generative/mappings.md`；步骤详解见 `MOA-generative/README.md`
- **结果解读**：`Method not found` 改 method 大小写；`No address found` 改 ServiceUrl；业务拒绝通常表示代理已通

## 2) 生成式MOA（抓包转MOA）

### 生成式MOA-一键脚本

- **功能**：与工作流同逻辑的一键脚本：build_payload + moa_execute；stdout 输出 ok/proxyOk/business 摘要 JSON。
- **提示词**：
  - `生成式MOA 一键 --url <ServiceUrl> --method <Method> --body-file <body.json>`
  - `run_generative_moa <ServiceUrl> <Method> <body.json>`
- **命令**：

```bash
python3 MOA-generative/scripts/run_generative_moa.py \
  --url <ServiceUrl> \
  --method <Method> \
  --body-file <capture-body.json> \
  --out .tmp/generative_moa_payload.json \
  --timeout-ms 20000 \
  --strict 0
```

<a id="moa_generative_build_only"></a>

### 生成式MOA-仅生成payload

- **功能**：只根据抓包 body + ServiceUrl + Method 生成双写 header+params 的 payload JSON，不执行。再用 moa_execute --payload-file 试跑。
- **提示词**：
  - `生成式MOA 生成 payload <ServiceUrl> <Method> <body.json>`
  - `build_payload 抓包转MOA`
- **命令**：

```bash
python3 MOA-generative/scripts/build_payload.py \
  --url <ServiceUrl> \
  --method <Method> \
  --body-file <capture-body.json> \
  --out .tmp/generative_moa_payload.json \
  --timeout-ms 20000

python3 MOA/moa_execute.py \
  --payload-file .tmp/generative_moa_payload.json \
  --timeout-ms 20000
```

<a id="moa_generative_workflow_run"></a>

### 生成式MOA-工作流执行

- **功能**：推荐入口：Tunnel 抓包 body + 调用链 ServiceUrl/Method → 双写 header+params 生成 payload 并 moa_execute。默认 strict=0（代理调通即成功，业务拒绝也算过）；strict=1 要求业务 success/ec=200。
- **提示词**：
  - `生成式MOA 工作流 serviceUrl=<ServiceUrl> method=<Method> bodyFile=<body.json>`
  - `抓包转MOA 执行 <ServiceUrl> <Method> <body.json>`
  - `执行工作流 moa-generative-run`
- **命令**：

```bash
python3 workflow/workflow_execute.py run moa-generative-run \
  --service-url <ServiceUrl> \
  --method <Method> \
  --body-file <capture-body.json> \
  --timeout-ms 20000 \
  --strict 0
```
