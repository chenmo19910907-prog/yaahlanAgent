## 登录

### 手机号登录

**QA 账号登录**
- 启动 → 语言/协议 → 手机号 + 验证码 → 进入 MainActivity 首页
- 默认：+86、验证码 000000

**登录后关弹窗**
- 常见 Account Security / Crowd Testing 等弹窗可 Cancel 关闭

## 设置·账号与隐私

### 从 Me 进入设置

**设置齿轮**
- Me 右上 → 设置列表

**Notifications**
- 通知设置页可进入

**Language**
- 语言设置页可进入

**Blacklist**
- 黑名单页可进入

**Account Management**
- → AccountManagerActivity

**Stealth / 隐身**
- → HideActivity

**About**
- 关于页可进入

**Help**
- → WebView 帮助页（非历史 RoomChatActivity）

**Clear cache**
- 清除缓存操作可完成
