## 进房与退房

### 房内弹窗

**拒绝 Mic 邀请**
- Mic invitation 弹窗点 Reject 后可继续操作顶栏

**CharmPK 横幅 / 奖杯挂件**
- 任意页出现须先拖走挂件再继续

### 退房

**退出他人房**
- 右上 X → Close → Room Reminder 确认 Exit Now → 回到房间列表或 MainActivity

### 房内功能面板（iv_room_close）

**打开面板**
- 右上 X（非 Hourly Ranking）→ Mute / Minimize / Share / Close、Floating message、Network Speed、Close the room

**Network Speed**
- 弹出网络诊断（Testing / Excellent）→ Close 关闭

**Share**
- Whatsapp / Facebook / Copy Link + Invite friends 列表

**Mute（公屏禁言）**
- 弹出时长选择 → Cancel 关闭

**Close the room 开关**
- 圆钮 **白=开、灰=关**；勿信 uiautomator `checked`；用 `room close-switch probe/set`

### 房内其它入口

**Hourly Ranking**
- 顶栏 room_rank_container → WebView Contribution 榜（Daily / Monthly）

**Room function 菜单**
- 底栏 more → Room function（Mysterious、Red Packet、PK ATM…）；上滑见 Room entertainment 游戏格

- CP Ferris Wheel → WebView CP Ferris Wheel Rewards

- Billiards → 房内台球对局（Result 弹窗 / 球桌 UI）
