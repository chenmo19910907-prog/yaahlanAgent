# 新手上手引导

> 适用分支：`yaahlan`。`git pull` 只会同步代码，**不会**同步各人的登录 Cookie / Token。按本文完成本地配置后，即可使用 MOA、Admin、Risk 与 Cursor 用例能力。

## 你需要准备什么

| 项 | 要求 |
|----|------|
| Python | **3.8+**（`python3 --version`） |
| 网络 | 能访问 `mse.wemomo.com`、测试后台等内网域名（通常需公司 VPN） |
| 浏览器 | 已登录 MSE MOA、Yaahlan Admin、钉钉文档（按需） |
| Cursor | 用于 Agent / MCP 生成用例（可选） |

---

## 第一步：拉代码

```bash
git clone git@git.wemomo.com:soulchill-qa/auto-generate-testcase.git
cd auto-generate-testcase
git checkout yaahlan
git pull origin yaahlan
```

## 第二步：配置文件一览（必看）

以下文件 **不在 Git 里**，每台电脑需自己从 `.env.example` 复制并填写。

| 用途 | 复制命令 | 本地配置文件 | 是否常用 |
|------|----------|--------------|----------|
| **MOA**（VIP/房间/钻石等） | `cp MOA/.env.example MOA/.env.local` | `MOA/.env.local` | **必配** |
| **Admin**（查用户详情/房间 ID） | `cp Admin/.env.example Admin/.env.local` | `Admin/.env.local` | 推荐 |
| **Risk**（风控加白/解除） | `cp Risk/.env.example Risk/.env.local` | `Risk/.env.local` | 按需 |
| **钉钉 MCP**（读文档/写 Excel） | 编辑已有文件 | `.cursor/mcp.json` 内 `env` | 用 Cursor 生成用例时 |

**已在仓库中、一般不用改**：`MOA/config/thresholds.json`、`MOA/config/registry.json`、`MOA/templates/*.json`、`Admin/config.json`、`Risk/config.json`。

## 第三步：配置 MOA（约 5 分钟）

### 3.1 创建配置文件

```bash
cp MOA/.env.example MOA/.env.local
```

### 3.2 获取 Cookie

1. 浏览器打开 [MSE 管理平台](https://mse.wemomo.com) 并登录  
2. 打开任意 MOA 测试请求（F12 → 网络）  
3. 复制请求头里完整的 **`Cookie:`** 一行（含 `JSESSIONID`、`tunnel_login_session`、`auth_cookie` 等）

### 3.3 写入 `MOA/.env.local`

```bash
MOA_ENTRY_URL=https://mse.wemomo.com/apirest/httpproxy/moa/test
MOA_COOKIE=这里粘贴完整 Cookie
MOA_ORIGIN=https://mse.wemomo.com
MOA_REFERER=https://mse.wemomo.com/
MOA_USER_AGENT=Mozilla/5.0
MOA_REQUEST_SOURCE=moaProxy
```

### 3.4 验证 MOA

```bash
python3 MOA/moa_execute.py \
  --payload-file "MOA/templates/VIP-增加经验值.json" \
  --vip-user-id 100465989 \
  --vip-query-current
```

成功时应输出 JSON，含 `vipLevel`、`currentVipExp` 等字段。

### 3.5 自然语言 / 命令速查

- 能力清单与可复制命令：[MOA/使用方法.md](../MOA/使用方法.md)  
- 技术说明与抓包约定：[MOA/README.md](../MOA/README.md)  
- 对 Cursor 说：「用户 `<userId>` 升级到 VIP5」→ Agent 会按清单调用脚本  

示例：

```bash
# 永久升到 VIP5
python3 MOA/moa_execute.py \
  --payload-file "MOA/templates/VIP-增加经验值.json" \
  --vip-user-id <userId> \
  --vip-level 5

# 下发 1 天 VIP5 体验（秒）
python3 MOA/moa_execute.py \
  --payload-file "MOA/templates/VIP-下发体验卡.json" \
  --vip-try-user-id <userId> \
  --vip-try-level 5 \
  --vip-try-duration-seconds 86400

# 设置房间等级
python3 MOA/moa_execute.py \
  --payload-file "MOA/templates/房间-设置等级.json" \
  --room-set-level-room-id <roomId> \
  --room-set-level <level>
```

## 第四步：配置 Admin（查手机号 → userId → 房间）

### 4.1 创建配置文件

```bash
cp Admin/.env.example Admin/.env.local
```

### 4.2 获取 Token

1. 打开 [Yaahlan 测试后台](https://yaahlan-admin-alpha.wemomo.com) 并登录  
2. F12 → 任意接口请求 → 请求头复制：  
   - `sso-token` → `ADMIN_SSO_TOKEN`  
   - `yaahlan-jwt` → `ADMIN_YAAHLAN_JWT`  

### 4.3 验证 Admin

```bash
python3 Admin/admin_execute.py --query-user-id 100465989
```

应返回昵称、手机、**roomId**、VIP 等级等摘要 JSON。

### 4.4 手机号查 userId（MOA）

```bash
python3 MOA/moa_execute.py \
  --payload-file "MOA/templates/用户-按手机号查userId.json" \
  --query-user-by-phone 13311111111 \
  --phone-output summary
```

典型链路：**手机号 → MOA 得 userId → Admin 得 roomId / 资料**。

## 第六步：Cursor 用例生成（可选）

### 6.1 MCP

检查 `.cursor/mcp.json` 中：

| 服务器 | 关键环境变量 |
|--------|----------------|
| `dingtalk-doc` | `DINGTALK_COOKIE` |
| `dingtalk-excel-read` / `write` | `DINGTALK_AEGIS_KEY`、`DINGTALK_AEGIS_SECRET`、`DINGTALK_WORKID` |

Cookie / Aegis 失效时，在钉钉文档页重新抓包更新。**勿将个人 Cookie 提交到 Git。**

### 6.2 推荐流程

1. 提供钉钉需求文档 URL  
2. Agent 使用 `prd-review`、`dingtalk-doc-read` 解析需求  
3. 用例写入 `temporary_testcase/`  
4. 使用 `testcase-to-excel` 同步到钉钉表  

主流程见根目录 [SKILL.md](../SKILL.md)、[README.md](../README.md)。

### 6.3 工具链自检（推荐）

```bash
python3 scripts/doctor.py
python3 scripts/check_testcase_md.py          # 校验 temporary_testcase 下用例
python3 scripts/suggest_kb_for_module.py 礼物  # 生成前查看应读知识库
```

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `缺少 Cookie` | 没有 `MOA/.env.local` 或未填 `MOA_COOKIE` | 按第三步配置 |
| 返回 HTML 登录页 | Cookie 过期 | 重新登录 MSE，更新 `MOA/.env.local` |
| `python3: command not found` | 未安装 Python 3 | 安装后重试 |
| 同事能用我不能用 | `.env.local` 不随 Git 同步 | 每人独立配置，不能复制别人的过期 Cookie |
| Admin 401 / 空数据 | `ADMIN_*` Token 过期 | 重新抓后台请求头 |
| MOA 业务 `ec:10011` | 体验 VIP 等级冲突等 | 先 `delVipInfo` 或发更高等级体验卡，见 MOA 使用方法说明 |
| 钉钉 MCP 鉴权失败 | `DINGTALK_COOKIE` 失效 | 更新 `.cursor/mcp.json` 中对应 env |
