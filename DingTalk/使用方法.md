## 2) 钉钉目录

<a id="folder_list_all"></a>

### 目录-列举全部表格

- **功能**：列举 yaahlan-testcases 目录下全部用例表格链接
- **提示词**：
  - `列举 Yaahlan 测试用例目录全部表格`
  - `版本迭代用例有哪些文件`
- **命令**：

```bash
python3 DingTalk/lookup_execute.py --list
```

<a id="collect_links"></a>

### 目录-列举全部表格链接

- **功能**：通过 Box API 分页列举目录下全部子文档链接（默认 yaahlan-testcases 约 144 项）；无需开浏览器
- **提示词**：
  - `列举钉钉目录下全部用例表`
  - `导出版本迭代用例链接清单`
  - `遍历钉钉目录拿每个表格 URL`
- **命令**：

```bash
python3 DingTalk/collect_execute.py --only-spreadsheet
```

<a id="collect_links_export"></a>

### 目录-导出链接 JSON

- **功能**：列举并导出 name/node_id/url/kind/extension 到 JSON 文件
- **提示词**：
  - `导出钉钉目录表格链接到 JSON`
  - `保存用例表清单到文件`
- **命令**：

```bash
python3 DingTalk/collect_execute.py --only-spreadsheet --output ~/Documents/cursor-mcp/dingExcel/folder-links.json
```

<a id="folder_lookup"></a>

### 目录-按关键词查文件链接

- **功能**：在默认目录 yaahlan-testcases 中按文件名关键词查找表格 URL（如 2.5.4、消息）
- **提示词**：
  - `找 2.5.4 版本用例表链接`
  - `Yaahlan 用例目录里文件名含消息的表格`
  - `查一下这个目录里的某张表`
- **命令**：

```bash
python3 DingTalk/lookup_execute.py <关键词>
```

## 3) testcase-kb 同步

<a id="kb_sync_full"></a>

### 知识库-全量同步

- **功能**：按版本升序同步全部用例表到 testcase-kb/；较新版本覆盖同名模块；结束后跑优化流水线
- **提示词**：
  - `把钉钉用例整理到知识库`
  - `全量同步 testcase-kb`
  - `同步版本迭代用例到 testcase-kb`
- **命令**：

```bash
python3 DingTalk/kb_sync_execute.py
```

<a id="kb_sync_workbook"></a>

### 知识库-单表同步

- **功能**：仅同步指定表格 node URL 到 testcase-kb
- **提示词**：
  - `同步这一张钉钉用例表到知识库`
  - `把这个表格链接写入 testcase-kb`
- **命令**：

```bash
python3 DingTalk/kb_sync_execute.py --workbook-url <表格URL>
```

<a id="kb_sync_version"></a>

### 知识库-按版本同步

- **功能**：仅处理文件名匹配某一版本号（如 2.5.4）的工作簿
- **提示词**：
  - `只同步 2.5.4 版本用例到知识库`
  - `按版本同步 testcase-kb`
- **命令**：

```bash
python3 DingTalk/kb_sync_execute.py --only-version <x.y.z>
```

<a id="kb_sync_list"></a>

### 知识库-预览可同步版本表

- **功能**：列举目录内可识别的版本用例 Excel，不写入 testcase-kb
- **提示词**：
  - `预览钉钉目录有哪些版本用例表`
  - `list-only 钉钉用例同步`
- **命令**：

```bash
python3 DingTalk/kb_sync_execute.py --list-only
```
