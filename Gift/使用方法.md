### 使用说明

- **环境**：仅 Stage（alpha/stage），禁止用于线上
- **鉴权**：`CMDB_TOKEN`（可选 `Gift/.env.local` 覆盖；未配置时使用内置 fallback）
- **与 MOA 背包区别**：本模块直连 `/v2/gift/send`；MOA `addPackageGift` 仅下发背包，`sendMiddlePackageGift` 通常不触发真实送礼
- **UI 验收**：客户端流程仍须 ADB 礼物面板 + Tunnel `gift/send ec=200`
- **输出**：stdout 为 JSON；`response.ec != 0` 时读 `error` / `response.em`

## 1) CP·亲密关系

<a id="stage_gift_intimate_invite"></a>

### Stage送礼-亲密关系申请

- **功能**：私聊送礼并发起亲密关系申请（ext.intimate_invite_gift=1，source=p2p；CP/挚友预览页送礼同路径）。须 --scene private；giftId 取自对应预览 gift 列表。
- **提示词**：
  - `Stage 用户<sender|userId>给<receiver|userId>送礼物<giftId|礼物ID>发起亲密关系申请`
- **命令**：

```bash
python3 Gift/gift_execute.py \
  --scene private \
  --sender <sender> \
  --receivers <receiver> \
  --gift-id <giftId> \
  --num 1 \
  --intimate-invite
```
