### 使用说明

| 项 | 说明 |
|----|------|
| **提示词** | 你对 Agent 说的自然语言口令 |
| **命令** | 下文可执行命令；HTML 默认与 xlsx **同目录**输出 |
| **输入** | 版本用例 xlsx，或钉钉 Excel 完整 URL |
| **输出** | `{文件名}_内网测试总结.html`、`{文件名}_外网测试总结.html` |
| **推荐路径** | 钉钉 URL → 拉表 → 生成 → 打开浏览器 → 数秒后删本地临时文件 |

## 0) 前置条件

- Python 3.10+（与项目其他模块一致）
- 依赖：`openpyxl`（本地生成）；钉钉拉表另需 `httpx`

```bash
python3 -m venv Report/.venv
source Report/.venv/bin/activate
python -m pip install -r Report/requirements.txt
```

未建 venv 时，脚本会尝试使用 `Report/.venv`、项目根 `.venv-xlsx` 或 `.venv`（需已装 openpyxl）。

钉钉拉表鉴权（三选一，**不需浏览器 Cookie**）：

1. 环境变量：`DINGTALK_AEGIS_KEY`、`DINGTALK_AEGIS_SECRET`、`DINGTALK_WORKID`
2. 自动读取 `~/.cursor/mcp.json` 里 `dingtalk-excel-read` 的 `env`（与 MCP 相同）
3. 代码内置默认值（团队默认 Key 失效时需改 1 或 2）

## 1) 钉钉 URL 一键生成（推荐）

<a id="dingtalk-generate"></a>

### 钉钉链接-生成内外网报告

- **功能**：拉取钉钉表格全部 sheet → 保存桌面 xlsx → 生成内网/外网 HTML → 自动打开浏览器 → 等待后删除本地 3 个临时文件
- **提示词**：
  - `用这个钉钉表格生成测试报告 <url>`
  - `从钉钉链接出内外网总结`
  - `生成 2.5.x 版本测试报告`
- **命令**：

```bash
python3 Report/dingtalk_report_execute.py "https://alidocs.dingtalk.com/i/nodes/XXXX"
```

流程说明：

| 步骤 | 行为 |
|------|------|
| 拉表 | 全量 sheet 写入 `~/Desktop/{版本}版本用例_钉钉.xlsx`（从表内前几行猜版本号，猜不到则用 `钉钉版本用例_钉钉.xlsx`） |
| 链接 | 缺陷 / 回归链接写死；**版本用例链接** = 命令行传入的 URL |
| 统计 | D2 为空或公式未缓存时，脚本按 D/E 或 B/C/D 列回退计算 |
| 打开 | 先外网 HTML，再内网 HTML |
| 清理 | 默认等 **5 秒** 后删除 xlsx + 两份 HTML（避免浏览器未加载完就被删） |

<a id="dingtalk-xlsx-only"></a>

### 钉钉链接-仅下载 xlsx

- **功能**：只拉钉钉表到本地，不生成 HTML
- **提示词**：
  - `先把钉钉用例表下载成 xlsx`
  - `只拉表不生成报告`
- **命令**：

```bash
python3 Report/dingtalk_report_execute.py --xlsx-only "https://alidocs.dingtalk.com/i/nodes/XXXX"
```

<a id="dingtalk-output"></a>

### 钉钉链接-指定输出路径

- **功能**：自定义 xlsx 保存位置，再生成报告
- **提示词**：
  - `下载到桌面并生成报告`
  - `保存为 2.5.2版本用例.xlsx 再出报告`
- **命令**：

```bash
python3 Report/dingtalk_report_execute.py \
  -o ~/Desktop/2.5.2版本用例.xlsx \
  "https://alidocs.dingtalk.com/i/nodes/XXXX"
```

## 2) 本地 xlsx 生成报告

<a id="local-generate"></a>

### 本地 xlsx-生成内外网报告

- **功能**：读取本地版本用例 xlsx，输出同目录两份 HTML；终端打印需求摘要列表
- **提示词**：
  - `用这个 xlsx 生成测试报告`
  - `生成内外网测试总结`
  - `出 2.5.2 版本报告`
- **命令**：

```bash
python3 Report/report_execute.py /path/to/2.5.2版本用例.xlsx
```

相对路径相对于**当前工作目录**：

```bash
cd ~/Downloads
python3 ~/CursorProjects/auto-generate-testcase/Report/report_execute.py 2.5.2版本用例.xlsx
```

未传路径时，在当前目录找**第一个** `.xlsx`：

```bash
cd ~/Desktop
python3 Report/report_execute.py
```

生成后默认**自动打开**内外网 HTML（先外网后内网）。不想弹浏览器：

```bash
COUNT_NO_BROWSER=1 python3 Report/report_execute.py /path/to/版本用例.xlsx
```

## 4) xlsx 数据约定

### 参与统计的 sheet

- 仅 **visible**（非隐藏）sheet
- 各 sheet **D2 非空**（或可由脚本回退计算）才计入报告
- **隐藏**的「AI生成」等草稿 sheet 自动跳过

### 单元格含义

| 位置 | 含义 |
|------|------|
| 各需求 sheet 的 **D2** | 需求摘要。普通需求：「xxx：用例条数 N 条，实际执行 M 条，执行率 X%」；技术优化：「技术优化需求：」+ 子项列表 |
| **Sheet1**（或首个 I2 非空的 visible sheet）的 **I2** | 缺陷链接、版本用例链接、回归用例链接；未完成/已完成缺陷各级数量 |
| **D 列**（第 7 行起） | 有「预期结果」的行 → 用例条数 |
| **E 列**（第 7 行起） | 有「测试组结果-android」的行 → 实际执行条数 |
| **B/C/D 列**（技术优化 sheet，第 7 行起） | B 非空且 C、D 均为空 → 分组标题行 |

### 需求类型识别

| 类型 | sheet 名规则 | D2 统计方式 |
|------|--------------|-------------|
| 普通新需求 | 非「优化需求 / 技术优化」且名称不含「技术优化」 | D/E 列计数 + 执行率 |
| 技术优化 | 名为 `优化需求`、`技术优化`，或名称含「技术优化」 | B 列分组标题生成子项 |

终端会输出：`本次版本共{N}个新需求及{M}个优化需求`，并列出编号摘要。

## 5) D2 自动统计公式

在钉钉/Excel 里可预先填公式；**报告脚本在 D2 为空或仅为未缓存公式时，会按相同规则从单元格回退计算**，无需先手工打开 Excel 刷新。

<a id="d2-normal"></a>

### D2 公式-普通需求 sheet

在 **D2** 填入：

```excel
=IF(COUNTA(D7:D10000)=0,IF(ISERROR(FIND("（",SHEETSNAME(A1)&"（")),SHEETSNAME(A1),LEFT(SHEETSNAME(A1),FIND("（",SHEETSNAME(A1)&"（")-1))&"：用例条数0条，实际执行"&COUNTA(E7:E10000)&"条，执行率0.00%",IF(COUNTA(E7:E10000)>COUNTA(D7:D10000),IF(ISERROR(FIND("（",SHEETSNAME(A1)&"（")),SHEETSNAME(A1),LEFT(SHEETSNAME(A1),FIND("（",SHEETSNAME(A1)&"（")-1))&"：用例条数"&COUNTA(E7:E10000)&"条，实际执行"&COUNTA(E7:E10000)&"条，执行率100.00%",IF(ISERROR(FIND("（",SHEETSNAME(A1)&"（")),SHEETSNAME(A1),LEFT(SHEETSNAME(A1),FIND("（",SHEETSNAME(A1)&"（")-1))&"：用例条数"&COUNTA(D7:D10000)&"条，实际执行"&COUNTA(E7:E10000)&"条，执行率"&TEXT(COUNTA(E7:E10000)/COUNTA(D7:D10000),"0.00%")))
```

说明：

- sheet 名含 `（` 时，摘要标题取括号前一段
- 实际执行条数 **大于** 用例条数时，两项均取实际执行数，执行率固定 **100.00%**

<a id="d2-tech-opt"></a>

### D2 公式-技术优化 sheet

在 **优化需求**、**技术优化**（或名称含「技术优化」）sheet 的 **D2** 填入：

```excel
="技术优化需求："&CHAR(10)&TEXTJOIN(CHAR(10),TRUE,SEQUENCE(ROWS(FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))))&") "&IF(IFERROR(FIND("【",FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))),9999)<IFERROR(FIND("（",FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))),9999),IF(IFERROR(FIND("【",FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))),9999)>=9999,FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990="")),LEFT(FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990="")),IFERROR(FIND("【",FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))),9999)-1)),IF(IFERROR(FIND("（",FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))),9999)>=9999,FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990="")),LEFT(FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990="")),IFERROR(FIND("（",FILTER(B7:B990,(B7:B990<>"")*(C7:C990="")*(D7:D990=""))),9999)-1))))
```

说明：

- 分组标题行：**B 非空** 且 **C、D 均为空**
- 子项标题在 `【` 或 `（` 处截断（`【` 优先于 `（`）

## 6) 报告链接规则

### 本地 xlsx 流程

从 **I2** 解析三类链接；可用环境变量覆盖（见下节）。

### 钉钉 URL 流程（`dingtalk_report_execute.py`）

| 链接 | 来源 |
|------|------|
| 缺陷链接 | 写死 Teambition TB 地址 |
| 回归用例链接 | 写死钉钉回归表地址 |
| 版本用例链接 | 命令行传入的钉钉表格 URL |

缺陷各级数量仍从表格 **I2** 读取（未完成 / 已完成：阻碍、严重、一般、轻微）。

<a id="report-env"></a>

## 7) 环境变量

| 变量 | 说明 |
|------|------|
| `DINGTALK_AEGIS_KEY` | 钉钉 OpenAPI 鉴权 Key（拉表用） |
| `DINGTALK_AEGIS_SECRET` | 钉钉 OpenAPI 鉴权 Secret |
| `DINGTALK_WORKID` | 操作人工号 |
| `COUNT_NO_BROWSER=1` | 生成后不自动打开浏览器 |
| `REPORT_DELETE_DELAY_SEC` | 钉钉流程：打开报告后、删除本地文件前的等待秒数（默认 `5`） |
| `REPORT_DEFECT_TB_URL` | 覆盖报告中的缺陷链接 |
| `REPORT_VERSION_CASE_URL` | 覆盖版本用例链接 |
| `REPORT_REGRESSION_CASE_URL` | 覆盖回归用例链接 |

## 8) 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `拉取钉钉表格失败` / 403 | Aegis 凭据无效或未配置 | 检查 `mcp.json` 中 `dingtalk-excel-read` 的 `env`，或导出三件套到环境变量 |
| 报告需求数为 0 | 各 sheet D2 为空且 D/E 列也无数据 | 补填 D2 公式，或确认用例行从第 7 行起有 D/E 内容 |
| 技术优化被当成普通需求 | sheet 名未识别为优化类 | 将 sheet 命名为 `优化需求`、`技术优化`，或名称含「技术优化」 |
| 执行率显示异常（>100%） | E 列执行数多于 D 列用例数 | 脚本已对齐为 100%；D2 公式同样按实际执行数封顶 |
| `无法读取文件（可能正在被 Excel 占用）` | xlsx 正被 Excel/WPS 打开 | 关闭表格后重试 |
| 钉钉流程报告闪一下就没了 | 本地临时文件被自动删除 | 正常行为；内容已在浏览器打开。要保留文件用本地 xlsx 流程，或 `--xlsx-only` 先下载 |
| MCP 能读表、脚本 403 | 环境变量与 MCP 不一致 | 脚本已自动读 `mcp.json`；确认 Cursor 里 MCP 能用的那套 Key 已写入 |

### 输出文件命名

| 输入 | 内网 HTML | 外网 HTML |
|------|-----------|-----------|
| `2.5.2版本用例.xlsx` | `2.5.2版本用例_内网测试总结.html` | `2.5.2版本用例_外网测试总结.html` |
| `2.5.2版本用例_钉钉.xlsx` | `2.5.2版本用例_钉钉_内网测试总结.html` | `2.5.2版本用例_钉钉_外网测试总结.html` |

外网 HTML 表线样式与内网邮件版一致，可直接复制到邮箱发送。
