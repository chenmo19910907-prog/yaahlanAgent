### 6.2 返回字段说明

| data | Object/Array | 否 | 响应数据 | { } |

| error | Object | 否 | 错误详情（失败时返回） | { } |

| 响应码 | 说明 | 处理建议 |
|--------|------|---------|
| 0 | 成功 | 正常处理 |

## 7. 异常处理

### 7.1 异常类型

| 异常类型 | HTTP状态码 | 响应码 | 说明 | 处理方式 |
|---------|-----------|--------|------|---------|
| 参数验证异常 | 400 | 1001 | 请求参数不符合要求 | 检查并修正请求参数 |
| 认证异常 | 401 | 1002 | 认证信息无效或过期 | 重新获取认证令牌 |
| 权限异常 | 403 | 1003 | 用户无权限访问 | 联系管理员分配权限 |
| 资源不存在 | 404 | 1004 | 请求的资源不存在 | 检查资源ID是否正确 |
| 业务逻辑异常 | 400 | 1005 | 业务规则校验失败 | 查看错误详情，调整业务逻辑 |
| 系统异常 | 500 | 5000 | 服务器内部错误 | 联系技术支持，记录错误日志 |
| 服务不可用 | 503 | 5001 | 服务暂时不可用 | 稍后重试，或联系技术支持 |

### 7.2 异常处理流程

1. **客户端异常处理：**
   - 捕获HTTP异常状态码
   - 解析响应体中的错误信息
   - 根据错误码进行相应处理
   - 记录错误日志（可选）

2. **服务端异常处理：**
   - 统一异常捕获
   - 记录详细错误日志
   - 返回标准化错误响应
   - 敏感信息脱敏处理

### 9.1 cURL 示例

```bash
  -H 'Authorization: Bearer [token]' \

  -d '{
    "field1": "value1",
    "field2": "value2"
  }'
```

### 9.3 Python (Requests) 示例

```python
import requests

url = '[接口地址]'

    'Authorization': 'Bearer [token]',
    'Content-Type': 'application/json'
}

    'field1': 'value1',
    'field2': 'value2'
```

### 9.4 Java (OkHttp) 示例

```java
import okhttp3.*;
import java.io.IOException;

public class ApiClient {
    public static void main(String[] args) throws IOException {
        OkHttpClient client = new OkHttpClient();
        
        MediaType mediaType = MediaType.parse("application/json");
        RequestBody body = RequestBody.create(mediaType, 
            "{\"field1\":\"value1\",\"field2\":\"value2\"}");
        
        Request request = new Request.Builder()
            .url("[接口地址]")
            .method("[请求方法]", body)
            .addHeader("Authorization", "Bearer [token]")
            .addHeader("Content-Type", "application/json")
            .build();
        
        Response response = client.newCall(request).execute();
        System.out.println(response.body().string());
    }
}
```

### 9.5 Go 示例

```go
package main

import (
    "bytes"
    "encoding/json"
    "net/http"
)

func main() {
    url := "[接口地址]"
    
    data := map[string]string{
        "field1": "value1",
        "field2": "value2",
    }
    
    jsonData, _ := json.Marshal(data)
    
    req, _ := http.NewRequest("[请求方法]", url, bytes.NewBuffer(jsonData))
    req.Header.Set("Authorization", "Bearer [token]")
    req.Header.Set("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
}
```
