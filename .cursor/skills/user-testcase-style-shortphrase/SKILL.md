# 用户用例风格：短语两段式（可复用）

## 目标

当用户提供其历史用例并要求“按我的风格”，输出用例需满足：

- **短语两段式**：测试步骤写“场景/动作短语”，预期结果写“可验结果短句”
- **高密度可验词**：展示/不展示/可以/无法/打开/没有反应/累加正确/扣除正确/时间正确/自动取消佩戴
- **多断言拆条**：同一场景多结果，拆成多行，不在一格里长串

## 适用时机

- 用户明确提出“改成我的风格/按我的习惯写”
- 用户给出示例用例，且示例呈现“短语两段式”表达

## 执行步骤（给 Agent 的操作规约）

1. **抽取风格词表**：从用户示例中提取高频动词与固定术语（展示/不展示/打开资料卡/没有反应等）
2. **风格改写**：
   - 将“进入/查看/观察/承接上条”等叙述式长句，压缩为场景短语
   - 将“符合预期/一致/正常”等空话，替换为可验现象短句
3. **拆条**：一个判定点一行；同一测试点可连续多行覆盖多个断言
4. **不改变覆盖**：不新增测试点未包含的表内用例；需求扩展仅放在“建议补测”
