### 子账号配置规则（服务端后台配置）

- A 配置成 B 的子账号后，不能再配置成 C 的子账号
- 配置成主账号后，不能再配置成子账号
- 配置成子账号后，不能再配置成主账号
- 一个主账号下最多绑定 **2 个**子账号
- 子账号提现：服务端兜底拦截
- 子账号兑换钻石：拦截
- 子账号兑换钻石到币商：拦截
- 子账号在公会内兑换钻石：拦截；**薪资预提不拦截**

- 子账号进入钱包页点击提现 → toast「你的账号没有操作权限」，提现流程不发起；**提现栏直接隐藏**
- 子账号为公会主播 → 公会页点击提现（自主提现、USDT）均拦截，**点击提现入口时即拦截**

### 子账号-转账限制

- 子账号与**非主账号**的聊天框：**不显示**转账操作入口
- 子账号通过其他入口向非主账号转账：前端在提现入口直接拦截

### 代收推荐逻辑（命中带子账号的代收）

## 提现与转账·主播提现增加二次确认弹窗

> 版本 2.5.2；涉及角色：主播 → 公会长、子公会长 → 母公会长、母公会长 → 子公会长

### 提现入口-原倒计时移除

- 主播进入提现页，选择「转账给公会长」：原有 5s 确认倒计时**不再展示**，按钮直接可点击
- 子公会长进入提现页，选择「转账给母公会长」：同上，倒计时移除
- 母公会长转给子公会长：同上，倒计时移除

### 二次确认弹窗-触发

| 场景 | 结果 |
|-----|------|
| 主播选择「转账给公会长」，点击确认按钮 | 弹出二次确认弹窗 |
| 子公会长选择「转账给母公会长」，点击确认按钮 | 弹出二次确认弹窗 |
| 母公会长转给子公会长，点击确认按钮 | 弹出二次确认弹窗 |

### 二次确认弹窗-内容展示

- 转出金额：显示本次实际转出金额，与填写金额一致
- 对方信息：头像、ID、昵称均展示正确
- 提示文案：「请仔细确认是否转账给此人，转出后无法撤销，谨防诈骗」
- 长昵称不截断（母公会长等长昵称场景验证）

### 二次确认弹窗-语音播放

- 弹窗弹出后**自动播放**语音
- 语音内容：「请仔细确认是否转账给此人，转出后无法撤销，谨防诈骗」
- 语言规则：
  - 非阿语环境 → 播放**英文**语音
  - 阿语环境 → 播放**阿语**语音
- 播放过程中点击暂停，再次点击继续播放
- 用户在**语音房内**点击播放按钮 → 无法播放，toast 提示对应文案

### 二次确认弹窗-确认按钮倒计时

| 状态 | 行为 |
|-----|------|
| 弹窗刚弹出 | 确认按钮显示 **10s 倒计时**，不可点击 |
| 倒计时期间点击确认 | 无响应，不发起转账 |
| 倒计时结束 | 按钮高亮可点击 |
| 倒计时结束后点击确认 | 关闭弹窗，转账发起成功；确认到账 |

### 二次确认弹窗-取消

- 点击取消按钮：仅关闭弹窗，不发起转账，返回提现页面
- 倒计时期间点击取消：同样仅关闭弹窗，不发起转账

### 转账金额边界

- 最小金额 $1：弹窗确认后转账成功，金额扣减正确
- 最大金额 $10000：弹窗确认后转账成功，金额扣减正确

### 其他提现方式不受影响

- 其他提现方式（现金提现、代收提现等）：流程不受本次改动影响，正常展示

### 多语言

- 分别切换英语、阿语、土语、俄语，触发二次确认弹窗：文案与按钮翻译正确
- 阿语下 RTL 布局展示正常

### 回测-1v1私聊转账卡片

- 1v1 发起转账成功后，进入私聊页面，卡片上的**倒计时自动确认**和**手动确认**逻辑不变
