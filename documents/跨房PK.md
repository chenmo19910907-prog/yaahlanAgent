## 知识地图（总览）

跨房 PK 在本用例中按**时间线**拆成五张表，对应从入口到收尾的完整链路：

| 阶段 | 工作表 | 内容重心 |
|------|--------|----------|
| 入口与撮合 | PK邀请和匹配 | 房间 PK / 跨房 PK 切换、开关与规则、随机匹配与指定邀请、匹配池与等级、邀请搜索与推荐、匹配/邀请弹窗与拒绝逻辑等 |
| 开局前 | PK准备 | 倒计时弹窗、跨房 PK 面板 UI、红蓝麦席与主持位、各房型麦位保留/下麦规则、进房与弱网、老版本踢房策略 |
| 进行中 | PK流程 | PK 计时、送礼与榜单、武器档位、胜负与动画等流程内行为（详见该表各功能模块） |
| 结束 | PK关闭 | 面板消失、房间模式与人数恢复、静音与音频边界、准备/进行中/结束各阶段点「关闭」的差异、记录与 toast；**提前断开惩罚与限制**见专章「PK断开惩罚与限制（v2.4.1）」 |
| 双房操作 | PK房间操作 | **开局默认闭音（v2.4.1）**、对方房间静音组合场景、上麦/下麦/换麦/抱麦在双房约束下的规则 |

**跨版本与运营**：老版本仅房间 PK、未开放 tab 的 toast、活动房不可跨房、开关与主持位状态以服务端/最新操作者为准、多处阈值（匹配降级时长、弹窗频次、流水等级档位等）标注为**后端可配置**。

### 随机匹配逻辑-房间匹配池划分

- **步骤**：根据平台所有房间日均流水 → **预期**：T+1进行刷新
- **预期**：取7日内流水/实际有流水天数
- **预期**：T+2 天根据 T+1及之前6天的流水更新等级正确
- **预期**：需要分区
- **步骤**：等级 → **预期**：等级判断正确；各档钻石阈值**可配置**（示例如下表）。

| 等级 | 流水区间（钻石，示例） |
|------|-------------------------|
| S | ≥ 5w |
| A | 3w – 4.99w |
| B | 1w – 2.99w |
| C | 5000 – 9999 |
| D | 2000 – 4999 |
| E | ＜1999 |

- **步骤**：整体匹配规则（线上配置需要更改） → **预期**：发起匹配时，5s内优先取当前同时在匹配的房间
- **预期**：5s后，优先当前房间所属的匹配池（匹配池中都是活跃房间）进行平级匹配
- **预期**：同匹配池内，优先匹配正在发起随机匹配的房间(前5s)
- **预期**：其次是打开了PK 开关，且正在开播、非密码房的房间
- **预期**：若以上房间不够匹配数据，则依次优先向上匹配池匹配B-A，匹配到S结束
- **预期**：若已匹配完最高等级，还是不够匹配数据，则依次向下匹配，匹配到E等级结束
- **预期**：S 级的匹配池，是依次向下匹配
- **预期**：E级的匹配池，是依次向上匹配
- **预期**：匹配成功的两个房间，做30分钟的匹配降级；即30分钟内已匹配的两个房间，再下次匹配时，优先级最低；如果向上&向下都没有匹配到，才将 2 个房间再次进行匹配
- **预期**：匹配成功的两个房间，30分钟的匹配降级时间后端可配置
- **步骤**：发送匹配消息匹配策略 → **预期**：服务端按照以上规则，批量向满足条件的房间发送匹配消息进行匹配
- **预期**：一次性发20 个房间
- **预期**：发送下一批数据需要过滤已发送的房间
- **预期**：若所有房间拒绝，未到5s 则按照整体匹配规则，不用立即发起第二波匹配
- **预期**：若5s内未匹配到，则按照整体匹配规则，立即发起第二波匹配消息
- **预期**：最多发送到第30s
- **预期**：x s发送一拨  最多发送到xx  s 都可配置
- **预期**：1 个房间，5分钟内，最多收到3 个弹窗
- **预期**：x分钟内，最多收到x个弹窗 可配置
- **预期**：1分钟到，没有匹配上房间 则展示发送无匹配数据（有弹窗）toast提示：未匹配到房间
- **步骤**：活跃的房间 → **预期**：有人在麦上的房间（线上5m刷一次  内网5s ）

### 房间PK分（v2.4.1）

用于匹配与推荐侧统计的「房间 PK 分」及衍生指标（与流水匹配池规则叠加，具体以服务端与 MSE 配置为准）。

- **步骤**：房间 7 日均流水数据 → **预期**：流水数值正确

| 统计项 | 预期（口径摘要） |
|---|---|
| 房间 7 日均跨房 PK **场均流水** | 双方 PK 值均为 0 的场次**不计入场次**；仅一方为 0 **计入场次**；准备/结算阶段送礼**不计入**；PK 中增加 PK 值**计入**；场均正确 |
| 房间 7 天 PK **胜场** | 双方均为 0 **不计**；一方为 0 **可计**；有 PK 值时对方退出我方胜**可计**；平局**不计**；再次 PK **可计**；胜场数、7 天胜率正确 |
| 房间 7 天 PK **完结** | **提前结束**场次**不计**；正常结束**可计**；再次 PK **可计**；完结场数、完结率正确 |
| 房间 7 天 PK **总场数** | 正常结束、准备阶段提前结束、PK 中提前结束、再次 PK 等口径下总场数正确 |
