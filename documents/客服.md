# 客服

> 来源：历史测试用例整理，涵盖 vip客服、游戏客服、语音房客服三种身份的完整流程。

---

## 功能模块：客服登录

| 功能模块 | 用例步骤描述 | 预期结果 |
|---------|------------|---------|
| 客服身份设置 | 开发者后台添加客服身份 | 支持 vip客服、游戏客服、语音房客服三种身份 |
| 客服登录入口-位置 | 具有客服身份的用户查看消息帧顶部 | 展示客服登录入口 |
| 客服登录入口-展示内容 | 查看登录入口内容 | 主标题内容（如"vip客服"）、副标题内容、今日收到反馈次数 |
| 客服登录入口-展示内容 | 查看今日收到反馈统计规则 | 统计周期：每日凌晨5:00至次日5:00为一个自然日（不同大区不一样）；统计范围：平台整体工单数；计数逻辑：同一用户会话结束后多次提交，按实际提交次数累计，每个用户算一次；用户结束后再次反馈，次数+1 |
| 客服登录入口-交互 | 查看登录入口默认状态 | 默认状态为「已下线」 |
| 客服登录入口-交互 | 点击「上线 login」 | 切换为「在线 online」状态，同时开关变为箭头 |
| 客服登录入口-交互 | 开启状态下，点击功能区 | 跳转至「Service Records」页面 |
| 客服登录入口-交互 | 客服未使用 app 超过 15 分钟 | 客服心跳停止，自动下线 |

## 功能模块：客服记录页（Service Records）

| 功能模块 | 用例步骤描述 | 预期结果 |
|---------|------------|---------|
| 客服记录页-入口 | 客服登录后，点击消息帧顶部客服登录条 | 进入 Service Records 页面 |
| 客服记录页-顶部 | 查看页面顶部元素 | 返回按钮（点击返回上级）、标题「Service Records」、刷新按钮、登出按钮 |
| 客服记录页-顶部 | 点击刷新按钮 | 拉取最新记录列表数据 |
| 客服记录页-顶部 | 点击登出按钮 | 客服记录页关闭，弹 toast 提示；聊天页登录条变为已下线状态 |
| 客服记录页-导航栏 | 查看导航栏 Tab | 共 4 个：①所有（默认，展示所有会话）②等待处理（用户已发消息客服未回应）③处理中（用户已发消息客服有回应但未结束）④已处理 |
| 客服记录页-导航栏 | 已处理 Tab 内容 | 包含系统自动结束、用户手动结束、客服手动结束的会话 |
| 客服记录页-导航栏 | 已结束会话用户再次发消息 | 从已处理移到等待处理 Tab（需手动刷新） |
| 客服记录页-消息列表 | 查看消息列表 | 支持上下滑动；导航栏 Tab 可来回切换且展示对应对话；分页 20 条；点击刷新拉取最新数据 |
| 客服记录页-消息列表 | 从列表进入对话页后返回列表 | 页面数据不刷新；切 Tab 会刷新 |
| 客服记录页-对话信息 | 查看对话列表项展示字段 | 用户头像（支持动态头像、头像框）、昵称（支持红名彩名，超长省略号展示）、性别年龄标签、VIP 等级、财富等级、消息时间、最后一条消息外显 |
| 客服记录页-对话信息 | 点击对话列表项 | 进入对话页 |
| 客服记录页-消息存储 | 消息超过三个月后查看 | 不展示过期消息记录 |

## 功能模块：客服接单

| 功能模块 | 用例步骤描述 | 预期结果 |
|---------|------------|---------|
| 自动派单条件 | vip客服/语音房客服/游戏客服 | 需同时满足：客服上线 + 后台接单 |
| 客服未上线时用户发消息 | 用户发送消息时无客服在线 | 自动下发 notice：【当前为非工作时间，无客服在线，你可以进行留言，我们会第一时间与您联系】；客服未上线用户可正常发送消息，无限制 |
| 自动派单逻辑-vip/语音房客服 | 5 个等待工单，a 客服上线后 b 客服再上线 | a 分到 5 个工单，b 不分工单 |
| 自动派单逻辑-vip/语音房客服 | 55 个等待工单，a 客服上线后 b 客服再上线 | a 分到 50 个（上限），b 分到 5 个 |
| 自动派单逻辑-vip/语音房客服 | 有等待工单，a 客服达上限后完成一个工单 | 再派一个工单给 a |
| 自动派单逻辑-vip/语音房客服 | 设置客服最大未读数为 1 | 下发工单后客服读消息才继续自动派单；不读消息则不继续派单 |
| 自动派单逻辑-游戏客服 | 2 个等待工单，a 客服上线 | a 先分到 1 个，回复消息后再分到另 1 个 |
| 自动派单逻辑-游戏客服 | 3 个等待工单，a 上线后 b 再上线 | a 分到 1 个，b 分到 1 个，a 回复消息后再分到剩余 1 个 |
| 手动接单条件 | 客服上线 + 后台接单 / 客服上线 + 后台不接单 / 客服不上线 + 后台接单 | 均可手动接单 |
| 手动接单逻辑 | 客服主动与用户发起聊天 | 触发手动接单，手动接单无上限 |
| 自动关单逻辑 | 客服 15 分钟内不回复 | 订单自动结束 |
| 手动关单逻辑-客服视角 | 已接单状态点击关闭工单按钮 | toast 提示，工单关闭 |
| 手动关单逻辑-客服视角 | 非该客服接的单点击关闭工单 | 无反应 |

## 功能模块：客服聊天

| 功能模块 | 用例步骤描述 | 预期结果 |
|---------|------------|---------|
| 客服视角-用户信息展示 | 接单+上线 / 不接单+上线 / 接单+不上线 状态下查看用户信息 | 展示用户头像（支持动态头像、头像框）、昵称（支持红名彩名，超长省略号）、VIP 等级、财富等级、在线状态；点击头像进入个人资料页；用户在房间时显示在房状态，点击可进入语音房 |
| 客服视角-支持功能（接单/上线状态） | 测试各消息类型发送 | 文本、表情、礼物、语音、图片、拍照均可正常发送；支持语音通话 |
| 客服视角-支持功能（接单/上线状态） | 查看功能限制 | 不展示加好友按钮、不展示游戏按钮；跟陌生人聊天条数不受限制 |
| 客服视角-支持功能（接单/上线状态） | 图片消息长按 | 出现功能栏（iOS 有转发，Android 没有）；复制在第一位；点击 toast 提示【复制成功】；复制图片链接到剪切板，粘贴后展示复制链接 |
| 客服视角-支持功能（接单/上线状态） | 视频消息长按 | 出现功能栏；复制在第一位；复制视频链接到剪切板，粘贴后展示正确视频链接 |
| 客服视角-支持功能（接单/上线状态） | 语音房客服只能收到对应用户的消息 | 不会收到其他类型用户的反馈 |
| 客服视角-支持功能（接单/上线状态） | 有其他客服与该用户聊过 | 对话页展示其他客服与用户的聊天记录 |
| 客服视角-支持功能（接单/上线状态） | 未被派单到的客服点击结束按钮 | 无反应 |
| 客服视角-支持功能（接单/上线状态） | 被派单到的客服接单时点击结束按钮 | toast 提示 |
| 客服视角-支持功能（不接单+不上线） | 测试各消息类型发送 | 文本、表情、礼物、语音、图片、拍照、游戏邀请均可正常发送；支持语音通话 |
| 客服视角-支持功能（不接单+不上线） | 查看功能 | 展示加好友按钮（非好友）；支持消息撤回、删除、复制、转发 |
| 消息通知-服务接入 | 用户发消息，客服进入聊天页 | notice 提示：【感谢您的耐心等待，客服x将为您提供服务】 |
| 消息通知-无客服在线 | 用户发消息时无客服在线 | notice 提示：【当前为非工作时间，无客服在线，你可以进行留言，我们会第一时间与您联系】 |
| 消息通知-客服繁忙 | 客服 5 分钟内没有回复用户 | notice 提示：【当前客服繁忙，请您稍作等待】 |
| 消息通知-结束预警 | 客服回复后，用户超 10 分钟没有回复 | notice 提示：【已经太久没有收到您的消息了，系统将在2分钟后自动关闭客服连接】 |
| 消息通知-会话结束 | 预警后再过 2 分钟未出现新消息 | 下发结束 notice：【本次服务已结束，感谢你对我们的支持】 |
| 消息外显 | 查看各消息类型外显 | 文本、表情、礼物、语音、图片、消息通知均有正确外显 |
| Push-客服侧 | 客服账号收到用户消息 | 有 push 提示；点击 push 跳转至与用户聊天页 |
| Push-用户侧 | 用户收到客服消息 | 有 push 提示；点击 push 跳转至与客服聊天页 |
| Push-角标 | 客服发给用户的消息 | 累积到用户红点及消息总数（app 角标总数：消息帧 + 谁看过我） |
| 用户视角-客服信息展示 | 用户侧查看客服信息 | 展示客服头像、昵称、VIP 等级、财富等级、在线状态；不能点击头像进入客服个人资料页；客服在房时显示在房状态，点击可进入语音房 |
| 用户视角-支持功能 | 测试各消息类型发送 | 文本、表情、礼物（含动效+卡片）、语音消息、图片、拍照均可正常发送 |
| 用户视角-支持功能 | 查看功能限制 | 不支持语音通话；不展示加好友和游戏按钮；跟陌生人聊天条数不受限制；长按消息不出现功能栏 |
| 客服给用户送礼 | 上线+接单状态下送礼 | 正常展示礼物 |

## 功能模块：客服查询游戏信息

| 功能模块 | 用例步骤描述 | 预期结果 |
|---------|------------|---------|
| 游戏信息查询-入口 | 游戏客服聊天页，查看输入框下方 | 最后一个位置展示【游戏信息查询】按钮；点击打开用户游戏信息页 |
| 游戏信息查询-入口 | 打开用户个人信息页，点击【...】 | 展示【游戏信息查询】选项；点击后打开游戏信息页 |
| 游戏信息查询-权限控制 | 非客服身份 | 不展示入口 |
| 游戏信息查询-权限控制 | 游戏客服身份 | 展示入口（访问他人个人主页时展示；1v1聊天页不展示；客服聊天页展示） |
| 游戏信息查询-权限控制 | 普通 vip 客服或语音房客服 | 不展示入口 |
| 游戏信息查询-权限控制 | 取消游戏客服身份或取消指定id | 不再展示入口 |
| 游戏信息页-用户信息 | 查看用户信息展示 | 用户头像（支持动态头像）、昵称（过长正确截断）、用户id（不展示靓号id） |
| 游戏信息页-游戏等级 | 游戏等级 < 4 级 | 只展示用户信息、游戏等级、等级对应收益比例；不展示其他信息、重置按钮、下发按钮 |
| 游戏信息页-游戏等级 | 游戏等级 ≥ 4 级 | 展示全部信息 |
| 游戏信息页-等级收益比例 | 查看不同等级的收益比例 | 对照等级收益比例正确 |
| 游戏信息页-最后查询时间 | 进入页面并下发钻石 | 最后查询时间更新，精确到秒；他人操作下发钻石也会更新 |
| 游戏信息页-最后查询时间 | 进入页面不下发钻石 | 最后查询时间不更新 |
| 游戏信息页-最后查询时间 | 无最后查询时间 | 前端不展示该字段 |
| 游戏信息页-最后查询时间 | 最后查询时间是当天 | 只展示到最后查询时发放数量；下方展示「今日已处理，请勿重复操作」；不展示【下发】按钮 |
| 游戏信息页-最后查询时间 | 最后查询时间不是当天 | 展示全部信息 |
| 游戏信息页-时间范围 | 查看时间范围展示（北京时间） | 起始时间为最后查询日期的0点，结束时间为昨天24点（最长1个月）；无最后查询时间则起始为上个月1日0点 |
| 游戏信息页-用户投注 | 查看时间范围内投注数据 | 展示时间范围内用户投注钻石总额；未投注展示0；今天参加投注，次日钻石累加 |
| 游戏信息页-用户收益 | 查看时间范围内收益数据 | 展示时间范围内收益钻石总额；未获得展示0；今天获得收益，次日累加 |
| 游戏信息页-可下发数量 | 计算可下发数量 | 根据用户亏损（投注-收益）× 游戏等级对应比例计算；不同等级计算结果正确 |
| 游戏信息页-重置按钮 | 可下发数量 < 10000 | 展示【重置】按钮；点击后页面刷新、支持防连点、后台生成一条已查询数据 |
| 游戏信息页-下发按钮 | 可下发数量 < 10000 时点击置灰的下发按钮 | 提示「由于当前时间范围内，该用户亏损<10000，无法下发钻石」 |
| 游戏信息页-下发按钮 | 可下发数量 ≥ 10000 | 仅展示【下发并同步后台】按钮（亮起）；游戏客服身份才展示 |
| 游戏信息页-下发按钮 | 非游戏客服点击亮起的下发按钮 | 提示「非游戏客服身份无下发钻石权限」 |
| 游戏信息页-下发二次确认 | 游戏客服点击亮起的下发按钮 | 弹出二次确认弹窗：「本次将发放x个，确认向该用户发放吗？」 |
| 游戏信息页-下发二次确认 | 点击取消 | 关闭弹窗 |
| 游戏信息页-下发二次确认 | 点击确认，发送成功 | 关闭弹窗并刷新页面；用户钱包余额、钻石明细和来源展示正确；钻石下发成功有小助手通知；客服聊天页显示下发成功通知 |
| 游戏信息页-下发二次确认 | 点击确认，发送失败 | 提示服务端拦截信息，关闭弹窗并刷新页面 |
| 多语言 | 英语、阿语环境 | 展示正常 |
| 镜像 | 阿语环境 | 镜像正常 |

## 功能模块：客服发钻

| 功能模块 | 用例步骤描述 | 预期结果 |
|---------|------------|---------|
| 用户侧发钻-通知 | 钻石下发成功后，用户收到小助手通知 | 有小助手通知消息；计入未读红点 |
| 用户侧发钻-外显 | 查看会话列表中该条消息外显 | 显示「游戏额外奖励钻到账通知」 |
| 用户侧发钻-卡片内容 | 点击会话进入详情，查看钻石奖励卡片 | 展示：游戏额外奖励标题、钻石数量（与实际一致）、内容文案、到账时间（时间戳）、【去钱包】按钮 |
| 用户侧发钻-去钱包 | 点击【去钱包】按钮 | 跳转到明细页，弹出该笔钻石明细弹窗；明细和来源展示正确；关闭弹窗后停留在明细页 |
| 用户侧发钻-卡片交互 | 点击卡片除【去钱包】之外的地方 | 无响应 |
| 客服侧发钻-卡片内容 | 查看客服侧钻石奖励卡片 | 展示：游戏额外奖励标题、钻石数量（与实际一致）、内容文案、到账时间 |
| 客服发钻-自动接单场景 | 客服设为自动接单，给用户发钻后 | 客服视角的会话详情页直接展示钻石奖励卡片 |
| 客服发钻-手动上线不回复 | 客服手动上线不回复，直接发送钻石 | 客服视角会话详情页不展示钻石奖励卡片；退出并重新进入后正常展示 |
| 客服发钻-手动上线回复后发钻 | 客服回复消息后给用户发钻 | 客服视角的会话详情页直接展示钻石奖励卡片 |
| 客服发钻-结束服务后发钻 | 客服结束服务后，回到列表再次进入该用户会话发钻 | 客服视角会话详情页不展示钻石奖励卡片；退出并重新进入后正常展示 |
| 多语言 | 英语、阿语环境 | 展示正常 |
| 镜像 | 阿语环境 | 镜像正常 |
