## 1. 客服类型概览

平台共有三种客服类型，各自服务不同场景的用户：

| 客服类型 | 用户入口 | 适用场景 |
|---------|---------|---------|
| VIP 客服 | 用户设置页点击「反馈」 | 服务 VIP 用户 |
| 游戏客服 | 用户游戏等级页点击客服卡片 / 设置页点击「反馈」 | 处理游戏相关问题（仅中东大区） |
| 语音房客服 | 用户在语音房客服个人资料页点击「聊天」 | 语音房场景客服服务 |

## 2. 客服登录

### 2.1 客服身份设置

客服身份在开发者后台设置，共三类：VIP 客服、游戏客服、语音房客服。

### 2.2 登录入口位置

- 拥有客服身份的用户，在**消息帧顶部**展示客服登录入口（三种类型均如此）。

### 2.3 登录入口展示内容

| 展示项 | 说明 |
|-------|------|
| 主标题 | VIP 客服 / 游戏客服 / 语音房客服 |
| 副标题 | 今日收到反馈：x 次 |
| 统计周期 | 北京时间每日凌晨 5:00 至次日 5:00 为一个自然日（不同大区不一样） |
| 统计范围 | 平台整体工单数 |
| 计数逻辑 | 同一用户会话结束后多次提交反馈，按实际提交次数累计；每个用户会话结束再次反馈则次数 +1 |

### 2.4 上下线交互

- 默认状态为「已下线」。
- 点击「上线 Login」→ 切换为「在线 Online」状态，开关变为箭头。
- 开启状态下点击功能区 → 跳转至「Service Records」页面。
- **心跳机制**：客服未使用 App **15 分钟**后自动下线。

## 4. 客服记录页

### 4.1 入口

客服登录后，点击语音房 / 消息帧客服登录条，进入客服记录页。

### 4.2 顶部功能

| 功能 | 说明 |
|------|------|
| 返回按钮 | 返回上级页面 |
| 刷新按钮 | 刷新记录列表，拉取最新数据 |
| 登出按钮 | 点击后登出客服，记录页关闭，弹 Toast 提示；聊天页登录条变为登出状态 |

### 4.3 导航栏 Tab

| Tab | 展示内容 |
|-----|---------|
| 所有 | 默认选中，展示全部会话 |
| 等待处理 | 用户发消息但客服未回应的会话 |
| 处理中 | 用户发消息且客服有回应但未结束的会话 |
| 已处理 | 已完成的会话（含系统自动结束、用户手动结束、客服手动结束） |

> 注：已结束会话，用户再发消息会从「已处理」移回「等待处理」（需手动刷新）。

### 4.4 消息列表

- 支持上下滑动，分页 20 条。
- 从列表进入对话页后返回，**页面数据不刷新**；切 Tab 会刷新。
- 对话信息展示：用户头像（支持动态头像 + 头像框）、昵称（支持红名彩名，超长省略号）、性别年龄标签、VIP 等级、财富等级、消息时间、最后一条消息内容。
- 消息只存三个月，过期后不展示。

## 5. 客服接单

### 5.1 VIP 客服 / 语音房客服

#### 自动派单

- **前提**：客服上线 + 后台开启接单。
- **逻辑**：按客服上线时间顺序自动派单，**单个客服上限 50 单**。
- **未读限制**：设置未读消息数上限为 1，客服读消息后才触发下一次派单；未读不派新单。
- 客服未上线时，系统向用户下发 Notice：「当前为非工作时间，无客服在线，你可以进行留言，我们会第一时间与您联系」。
- 用户仍可给未上线客服发消息（无限制，含异性用户）。

#### 手动接单

- 前提：客服上线 + 后台接单 / 客服上线 + 后台不接单 / 客服不上线 + 后台接单（任意满足）。
- 客服主动与用户聊天即触发手动接单，**无上限**。

#### 自动关单

- 客服 **15 分钟**内不回复，工单自动结束。

#### 手动关单

- 客服对话页展示「关闭工单」按钮。
- 已接单状态点击 → Toast 提示（关闭成功）。
- 非该客服接的单，点击关闭无反应。

### 5.2 游戏客服

- 自动派单逻辑同 VIP 客服（上限 50），但**客服回复消息后才触发下一次派单**。
- 示例：有 2 个等待工单，A 客服上线 → 先分到 1 个，回复消息后再分另 1 个。

## 6. 客服聊天

### 6.1 客服视角（已接单/上线状态）

#### 用户信息展示

| 展示项 | 说明 |
|-------|------|
| 头像 | 支持动态头像、头像框 |
| 昵称 | 支持红名彩名，超长省略号 |
| VIP / 财富等级 | 展示等级标识 |
| 在线状态 | 在房间时显示在房状态，可点击进入语音房 |
| 头像点击 | 可进入用户个人资料页 |

#### 支持的消息类型

文本、表情、礼物、语音、图片、拍摄照片、语音通话。

#### 其他规则

- 跟陌生人聊天，聊天条数不受限制。
- **不展示**加好友按钮、游戏按钮。
- 语音房客服只能收到语音房用户反馈的消息。
- 图片消息长按可复制（复制图片链接到剪切板）；视频消息同理。
- 有其他客服与该用户的历史记录，对话页会展示。
- 被派单到的客服接单状态可点击结束按钮（Toast 提示）；非派单客服点击无反应。

#### 消息通知（Notice）

| 触发条件 | Notice 内容 |
|---------|------------|
| 客服接入会话 | 「感谢您的耐心等待，客服 x 将为您提供服务」 |
| 无客服在线 | 「当前为非工作时间，无客服在线，你可以进行留言，我们会第一时间与您联系」 |
| 客服 5 分钟未回复 | 「当前客服繁忙，请您稍作等待」 |
| 客服回复后用户 10 分钟未回复 | 「已经太久没有收到您的消息了，系统将在 2 分钟后自动关闭客服连接」 |
| 再过 2 分钟无新消息 | 「本次服务已结束，感谢你对我们的支持」 |

### 6.2 客服视角（未接单/未上线状态）

与普通用户私聊一致，支持：文本、表情、礼物、语音、图片、拍摄、语音通话、游戏邀请，展示加好友按钮，消息支持撤回/删除/复制/转发。

### 6.3 用户视角

- 展示客服头像（不可点击进入资料页）、昵称、VIP/财富等级、在线状态。
- 支持：文本、表情、礼物（含礼物动效和礼物卡片）、语音、图片、拍摄。
- **不支持**语音通话。
- 与客服聊天，聊天条数不受限制。
- **不展示**加好友按钮、游戏按钮。
- 消息长按**不出现功能栏**。

### 6.4 Push 通知

| 触发条件 | Push 内容 |
|---------|----------|
| 用户给客服发消息 | 客服账号收到 Push 提示，点击跳转至与该用户的聊天页 |
| 客服给用户发消息 | 用户收到 Push，点击跳转至与客服的聊天页 |
| 客服发送消息 | 计入 App 角标总数（消息帧 + 谁看过我） |

## 7. 客服查询个人信息

### 7.1 入口

- 打开用户个人信息页 → 点击「...」→ 选择「个人信息查询」 → 进入账号信息查询页。

### 7.2 账号信息查询页

- 展示该用户的**基本信息 + 状态**。
- 客服角色可修改用户信息（如性别），点击修改按钮 → Toast「修改成功」。
- 支持展示：用户状态、设备状态、禁言状态。

### 7.3 多语言

- 支持英语、阿语；镜像布局正常。

## 8. 客服查询游戏信息

### 8.1 入口

| 入口位置 | 说明 |
|---------|------|
| 游戏客服聊天页输入框下方 | 最后一个位置展示「游戏信息查询」按钮 |
| 用户 Profile 页 | 点击「...」→「游戏信息查询」 |

> 打开自己的 Profile 页时，右上角展示「编辑」按钮（非客服入口）。

### 8.2 权限控制

| 用户身份 | 是否展示入口 |
|---------|------------|
| 非客服身份普通用户 | 不展示 |
| 游戏客服身份 | 展示（Profile 页 + 聊天页） |
| 指定 ID 用户（访问他人 Profile） | 展示 |
| 指定 ID 用户（1v1 聊天页） | 不展示 |
| 指定 ID 用户（非游戏客服，客服聊天页） | 不展示 |
| 普通 VIP 客服 | 不展示 |
| 语音房客服 | 不展示 |
| 取消游戏客服身份后 | 不再展示 |

### 8.3 游戏信息页内容

| 展示项 | 说明 |
|-------|------|
| 用户信息 | 头像（支持动态）、昵称（超长截断）、用户 ID（不展示靓号 ID） |
| 游戏等级 | 与游戏等级页一致 |
| 等级 < 4 级 | 只展示用户信息、游戏等级、等级对应收益比例；不展示其他信息、重置按钮、下发按钮 |
| 等级 ≥ 4 级 | 展示全部信息 |

### 8.4 最后查询时间

- 精确到秒，以北京时间为基准。
- 进入页面但不下发钻石 → 时间不更新。
- 进入页面并下发钻石 → 时间更新。
- 最后查询时间是**当天**：只展示截至该时间的数据，下方显示「今日已处理，请勿重复操作」，**不展示下发按钮**。
- 最后查询时间**不是当天**：展示全部信息。

### 8.5 时间范围（北京时间）

- 有最后查询时间：起始 = 最后查询日期 0 点，结束 = 昨天 24 点（最长 1 个月）。
- 无最后查询时间：起始 = 上个月 1 日 0 点，结束 = 昨天 24 点。

### 8.6 数据字段

| 字段 | 说明 |
|-----|------|
| 最后查询时发放数量 | 上次下发的钻石数；未发放则展示 0；他人操作也会更新 |
| 用户投注 | 时间范围内用户投注的钻石总额 |
| 用户收益 | 时间范围内用户投注的钻石收益总额；当天投注次日累加 |
| 可下发数量 | 用户亏损 × 游戏等级对应比例 |

### 8.7 下发钻石逻辑

| 条件 | 处理 |
|-----|------|
| 可下发数量 < 10,000 | 展示重置按钮；点击重置刷新数据，后台生成已查询记录 |
| 点击置灰的下发按钮 | Toast「由于当前时间范围内，该用户亏损 <10000，无法下发钻石」 |
| 可下发数量 ≥ 10,000 | 仅展示「下发并同步后台」按钮 |
| 游戏客服身份 | 可见并点击下发按钮 |
| 非游戏客服 | 点击按钮提示「非游戏客服身份无下发钻石权限」 |

#### 下发确认弹窗

- 文案：「本次将发放 x 个，确认向该用户发放吗？」
- 点击取消 → 关闭弹窗。
- 点击确认成功 → 关闭弹窗，刷新页面；钻石到账，用户钱包余额正确，明细来源正确，有小助手通知，客服聊天页显示下发成功通知。
- 点击确认失败 → 提示服务端拦截信息，关闭弹窗并刷新。

## 9. 客服发钻

> 此模块为「客服查询游戏信息」的发钻扩展，主要补充用户侧和客服侧的展示样式。

### 9.1 用户侧发钻展示

钻石下发成功后：

- 有小助手通知消息。
- 会话列表外显：「游戏额外奖励钻到账通知」，计入未读红点。
- 点击进入会话详情页，展示钻石奖励卡片：

| 卡片内容 |
|---------|
| 标题：游戏额外奖励钻到账通知 |
| 钻石数量（与下发数量一致） |
| 内容文案 |
| 到账时间（发放时的时间戳） |
| 【去钱包】按钮 |

- 点击「去钱包」→ 跳转到钱包明细页，弹出该笔钻石的明细弹窗；关闭弹窗后停留在明细页。
- 点击卡片其他区域 → 无响应。

### 9.2 客服侧发钻展示

客服视角钻石奖励卡片内容：

| 卡片内容 |
|---------|
| 标题：游戏额外奖励 |
| 钻石数量（与下发数量一致） |
| 内容文案 |
| 到账时间（发放时的时间戳） |

### 9.3 卡片展示条件说明

| 客服状态 | 发钻后卡片是否立即展示 |
|---------|-------------------|
| 自动接单（后台开启） | 立即展示 |
| 手动上线未回复用户，直接发钻 | **不立即展示**，退出再进入会话页后正常展示 |
| 手动上线已回复用户，再发钻 | 立即展示 |
| 客服已结束服务后发钻 | **不立即展示**，退出再进入会话页后正常展示 |

## 10. 客服评价

### 10.1 评价按钮状态

| 场景 | 按钮状态 |
|-----|---------|
| 用户进入聊天页但未聊天 | 按钮高亮，点击弹 Toast（工单未开始提示） |
| 工单进行中，用户未评价 | 按钮高亮，点击弹出评价弹窗 |
| 工单关闭 48 小时内，用户未评价 | 按钮高亮，点击弹出评价弹窗 |
| 工单关闭超过 48 小时，用户未评价 | 按钮高亮，点击 Toast「该工单评价已过期（超 2 天），暂无法评价」 |
| 超时后用户与客服再次聊天建立新工单 | 按钮高亮，点击弹出新工单评价弹窗 |
| 用户已完成评价 | 点击按钮提示「您已提交本次咨询的评价，无需重复操作」 |

### 10.2 评价卡片

#### 触发时机

- 客服手动关单 或 系统自动关单时：
  - 用户在聊天页 → 页面直接下发评价卡片。
  - 用户不在聊天页 → 用户重新进入时下发评价卡片。

#### 卡片内容

主标题、副标题、「立即评价」按钮、「稍后评价」按钮。

#### 卡片交互

| 操作 | 结果 |
|-----|------|
| 点击「立即评价」 | 弹出评价弹窗，卡片消失 |
| 点击「稍后评价」 | 卡片消失 |
| 未点击任何按钮 | 5 分钟后卡片自动消失 |

> 评价卡片消息无外显、无红点。

### 10.3 评价弹窗

#### 必填项

1. **满意度**：不满意 / 一般 / 满意（无默认选中，不可取消选中，可切换）
2. **问题解决状态**：已解决 / 未解决 / 处理中（无默认选中，不可取消选中）

#### 选填项

- **评价原因**：文本输入框，最多 500 字符；空格开头/末尾过滤；过长自动截断。

#### 提交规则

| 情况 | 结果 |
|-----|------|
| 满意度 + 问题解决状态均已选（可不填理由） | 提交成功，Toast「评价成功，感谢您的反馈！」，后台完整记录 |
| 未选满意度 | Toast「请完成满意度评价」，停留在评价页 |
| 未选问题解决状态 | Toast「请完成问题解决状态评价」，停留在评价页 |
| 两项均未选 | Toast「请完成满意度与问题解决状态评价」，停留在评价页 |

### 10.4 后台评价管理

后台新建「服务评价」目录，包含：VIP 评价详情、语音房评价详情、游戏评价详情。

#### 筛选条件

客服 ID / 工单 ID / 用户 ID / 关键字模糊搜索 / 满意度 / 问题处理状态 / 评价时机（工单进行中 / 工单结束后）/ 开始-结束时间（精确到秒，最大跨度 1 个月，默认展示前一周）。

- 支持多条件组合筛选（交集）。
- 支持重置功能（清空所有筛选条件并恢复默认数据）。
- 支持导出 Excel（有数据时可导出，无数据时按钮置灰）。

#### 评价记录列表字段

工单 ID / 用户 ID / 客服 ID / 满意度 / 问题状态 / 评价时机 / 关单时间 / 评价时间 / 评价理由 / 详情按钮。

#### 操作记录

工单创建时间 / 客服接单时间 / 关单时间 / 用户评价时间（时区按选择的大区展示）。

#### 时区支持

支持切换北京时间 / 埃及时间，切换后页面刷新，时间按所选时区展示。

## 11. 客服分区

### 11.1 分区规则

- 客服只服务**本大区**的工单：消息列表只展示本大区工单，自动派单只分本大区工单，手动接单也只能接本大区工单。
- 切换大区后刷新页面，展示新大区工单。

### 11.2 切换大区

- 切换大区前有未结束工单 → 切换后所有未结束工单**全部自动结单**。

### 11.3 各类型客服分区入口

| 类型 | 入口限制 |
|-----|---------|
| VIP 客服 | 所有大区用户均可从设置页反馈 |
| 游戏客服 | **仅中东大区**有入口，其他大区无 |
| 语音房客服 | 从客服 mini 资料卡进入 |

### 11.4 客服对话页（分区场景）

**客服视角（已登录 + 后台接单，或已登录 + 未接单，或未登录 + 已接单）：**
支持文本、表情、礼物、语音、图片（支持长按复制）、拍摄；支持语音通话；不展示加好友、游戏按钮。

**客服未登录 + 未接单：** 页面显示为用户私聊。

**用户视角（任意上述接单/登录组合）：**
支持文本、表情、礼物、语音、图片、拍摄；不支持语音通话；聊天条数不受限制；不展示加好友、游戏按钮；消息长按不出现功能栏（iOS 有转发和删除）。

### 11.5 系统关单

用户 **10 分钟**内不回复，工单自动结束（分区场景）。

## 12. 客服快捷回复

### 12.1 入口与权限

| 客服状态 | 是否展示快捷回复入口 |
|---------|------------------|
| 已接单 + 已上线 | 展示 |
| 已接单 + 未上线 | 展示 |
| 未接单 + 已上线 | 展示 |
| 未接单 + 未上线 | **不展示** |
| 已取消客服身份 | **不展示** |
| 非客服身份普通用户 | **不展示** |
| 游戏客服 | 展示 |
| 语音房客服 | 展示 |

### 12.2 快捷回复入口

- 入口位置固定可见，文案与产品文案表一致，热区符合规范。
- 点击展开快捷回复列表，列表为空时展示空文案，底部展示「添加」和「管理」按钮。
- 输入框有内容时点击快捷回复，输入框内容正常展示（不清空）。
- 收起面板不清空输入框内容；切换会话后清空。

### 12.3 快捷回复列表

- 按**最后编辑保存时间降序**排列（最近保存的在最上方）。
- 支持首屏后下滑加载更多。
- 点击列表任意一条 → 内容填入输入框（不自动发送），发送按钮高亮。
- 已选内容支持修改后再发送；连续点击多条时以最后一条为准。

### 12.4 添加快捷回复

- 上限 **20 条**（可由服务端配置），达到上限时点击「Add」提示「最多只能保存 20 条快捷回复」。
- 删除一条后可重新新增。
- 正文最多 **1,000 字符**，超长自动截断；支持英语、阿语、emoji、换行符。
- 列表展示最多两行，超过两行省略号显示。

### 12.5 管理页

- 顶部展示当前条数/上限（如 12/20），随服务端配置动态变化。
- 支持独立编辑每条，互不影响。
- 长按条目弹出菜单（置顶 / 删除 / 取消）：
  - **置顶**：该条在管理列表和文案列表移至最上，重进后保持置顶。
  - **取消置顶**：移回未置顶前的位置，不算编辑（不更新最后保存时间）。
  - **删除**：条目删除，分子 -1，上限规则仍生效。
- 新添加的条目展示在置顶条目下方。

### 12.6 多语言与兼容性

- 支持英语、阿语、土语、俄语正常展示。
- 支持镜像布局。
- 大屏/小屏兼容。
- 老版本客服不展示快捷回复入口。
