## 1. 等级体系

贵族共 **6 个等级**，按月度消费值解锁：

| 等级 | 名称 | 解锁所需消费值 | 勋章/标签 |
|------|------|-------------|---------|
| LV1 | 骑士 | 25,000 | 静态 |
| LV2 | 男爵 | 400,000 | 静态 |
| LV3 | 子爵 | 1,800,000 | 动态（LV3 起支持动态 + 扫光） |
| LV4 | 伯爵 | 4,000,000 | 动态 |
| LV5 | 侯爵 | 12,500,000 | 动态 |
| LV6 | 公爵 | 21,000,000 | 动态 |

## 2. 消费值规则

### 2.1 换算比例

**1 钻石 = 1 消费值**

### 2.2 增加消费值的场景

- 赠送基础面板中的**普通礼物**
- 赠送基础面板中的**道具礼物**
- 花费钻石**购买道具**（头像框、座驾、房间背景等所有道具）
- 花费钻石**购买特权**（房间背景上传特权、修改昵称特权等）
- **购买 VIP 成长值**
- 赠送**幸运礼物**

### 2.3 不增加消费值的场景

- 游戏消耗钻石
- 赠送背包中的钻石礼物
- 赠送背包中的道具礼物
- 购买消费值本身不增加消费值

## 3. 有效期与月度重置机制

### 3.1 有效期

- 道具有效期 = **当月剩余天数**（包括升级当月）
- 有效期格式：`天 HH:MM:SS`；< 1 天只显示小时；< 1 小时显示 `00:MM:SS`
- 每次进入贵族页面拉取倒计时；停留期间到期后自动刷新，显示 `00:00:00`

### 3.2 月度周期（以沙特时间次月 1 日 0 点为结算节点）

| 时间点 | 发生的事情 |
|------|---------|
| 当月任意时间 | 消费值实时累加；累加后超过某等级门槛即时升级，按**当月剩余天数**下发道具 |
| 次月 1 日 0 点 | 根据**上月消费值**确定本月初始贵族等级；下发**本月有效天数**的道具；消费值**重置为 0** |
| 次月 1 日系统消息 | 通知用户上月消费值及本月等级；跳转主态贵族页；若上月无消费则单独文案提示失去贵族特权 |

### 3.3 次月初始等级计算逻辑

- **升级**：上月消费值超过上月初始等级 → 本月初始等级按上月消费值计算
- **保级**：上月消费值在上月初始等级区间内 → 本月初始等级与上月相同
- **降级**：上月消费值低于上月初始等级 → 本月初始等级按上月消费值重新计算，按初始等级下发道具
- **当月消费值低于/等于初始等级**：维持当前权益，不重新下发道具
- **当月消费值高于初始等级**：按当月剩余天数下发升级后等级的道具

### 3.4 等级保留说明

- 当月消费值未达到当前等级（上月保留等级）：展示「{x}月贵族等级保留特权，生效中」
- 点击说明 icon 弹出贵族等级保留说明弹窗

## 4. 入口

### 4.1 特权中心

- **Banner 位**：文案「Yaahlan 贵族 彰显财富」+ 图片；点击打开贵族页面，锚点到自己的等级 tab（无等级定位到 LV1）
- **贵族入口**：展示顺序为 VIP → 贵族 → 魅力 → 游戏
  - 未解锁：整个模块置灰 + 锁 icon；展示最低等级 icon 和「贵族」文案
  - 已解锁：展示当前等级 icon + 名称 + 标签（LV3-LV6 有扫光 + 动态）

### 4.2 我的页面

- 展示贵族 icon + 标题「贵族」
- 未解锁：不显示等级标签
- 已解锁：展示当前等级标签（LV3-LV6 扫光 + 动态）

### 4.3 资料页 / mini 资料页

- 展示顺序：VIP → 贵族 → 财富 → 魅力（资料页）；VIP → 贵族 → 魅力 → 游戏（mini资料页）；一行展示不下可滑动
- 未解锁：icon 置灰；不展示贵族名称
- 已解锁：展示当前等级 icon + 名称（LV1-LV6 名称：骑士/男爵/子爵/伯爵/侯爵/公爵）
- **客态开启贵族隐身**：icon 和名称隐藏；**主态**：icon 和名称正常展示
- 点击入口：打开贵族主态页面，锚点到自己的等级

### 4.4 上线落地页

- 入口：房间列表 banner、礼物栏上方 banner
- 落地页内容：背景图、标题、说明文案（什么是贵族/等级/特权）、权益图片展示
- 底部「查看贵族」吸底按钮 → 点击进入主态贵族页面

## 5. 贵族主页面

### 5.1 顶部

- **标题**：贵族
- **返回按钮**：
  - 从房间内特权中心打开 → 直接关闭
  - 从我的页面打开 → 直接关闭
  - 从个人资料页贵族徽章打开 → 关闭后回到个人主页
  - 从 mini 资料页打开 → 关闭后展示 mini 资料页
- **更多按钮**：
  - 规则 → 打开贵族说明规则页（可返回到贵族页面，返回后定位到自己等级）
  - 设置 → 打开隐身设置页（财富/魅力/游戏/贵族隐身开关，与全局设置同步）

### 5.2 等级信息区

- 进入默认展示**我已达到的贵族等级**；若当月开始，等级为上月结算所得，展示初始等级
- 展示：贵族勋章、等级（LV1-LV6）、等级名称、解锁所需消费值
- LV3-LV6 勋章动态展示
- 支持左右按钮和左右滑动切换等级；到端点时隐藏对应方向按钮/无法继续滑动
- 切换时下方权益区同步更新

**查看未解锁等级**：
- 展示锁头图标
- 解锁信息：「解锁 {LV.x 等级名称} 还需要获得 {y} 消费值」（y = 所查看等级门槛 - 当前消费值，实时更新）

**查看已解锁等级**：
- 解锁信息：「已解锁贵族特权」

### 5.3 权益（Privilege）展示规则

标题「特权」，权益图标固定排列顺序：

**贵族勋章 → 贵族标签 → 贵族头像框 → 贵族入场特效 → 麦位声波 → 贵族专属礼物 → 贵族送礼条 → mini 资料卡背景 → 隐藏贵族等级 → 贵族座驾 → 升级广播 → 进房广播 → 资料页特效 → 贵族资料页背景**

| 等级 | 展示的权益 |
|------|---------|
| LV1 骑士 | 贵族勋章、贵族标签、贵族头像框、贵族入场特效 |
| LV2 男爵 | + 麦位声波、贵族专属礼物、贵族送礼条、mini 资料卡背景 |
| LV3 子爵 | + 隐藏贵族等级、贵族座驾、升级广播 |
| LV4 伯爵 | + 进房广播 |
| LV5 侯爵 | + 资料页特效 |
| LV6 公爵 | + 贵族资料页背景 |

### 5.4 吸底区域

| 区域 | 内容 |
|------|------|
| 本月消费值 | 1 钻石 = 1 消费值；次月沙特 0 点重置为 0；超过 LV6 阈值正常展示 |
| 有效期倒计时 | 当月剩余天数；未获得贵族时也展示 |
| 次月等级信息 | 文案「到期后，当前消费值可以在 {y 月} 获得 {LV.x 名称} 特权」；未解锁不显示；若无消费但有上月等级，显示「到期后无法获得特权」 |
| 购买按钮 | 点击打开购买页面 |
| 送礼按钮 | 点击打开礼物面板；余额不足时送礼弹起充值弹窗 |

**购买页面规则**：
- 1 钻石可购买 3 点消费值
- 系统自动填充「解锁下一等级所需差值」（不超过钻石余额）
- 最低购买 3 消费值（1 钻石）；输入量 < 3 自动填充为 3
- 购买后：钻石减少、消费值增加、账号消费记录新增「购买贵族消费值」

## 6. 权益详情说明

权益详情为半屏弹窗，顶部为所有权益图标 tab（可滑动）；点击/左右滑动切换。

| 权益 | 解锁等级 | 说明 |
|------|---------|------|
| 贵族勋章 | ≥ LV1 | 6 个勋章；LV3-LV6 支持动态（svga/webp） |
| 贵族标签 | ≥ LV1 | 6 个标签；LV3-LV6 支持动态扫光 |
| 贵族头像框 | ≥ LV1 | 6 个头像框；LV3-LV6 动态；LV6 每 30 天额外获得 1 款定制头像框（联系客服） |
| 贵族入场特效（入场条） | ≥ LV1 | 6 个入场条 |
| 麦位声波 | ≥ LV2 | 5 个（LV2-LV6）；说话时声波展示 |
| 贵族专属礼物 | ≥ LV2 | LV3-LV4 礼物有声音；LV5-LV6 礼物有声音 + 用户头像和昵称 |
| 贵族送礼条 | ≥ LV2 | LV2-LV6 各自专属；赠送礼物时展示 |
| mini 资料卡背景 | ≥ LV2 | LV2-LV4 各 1 款；LV5-LV6 为**定制**款（联系客服） |
| 隐藏贵族等级 | ≥ LV3 | 隐藏后：贵族标签、mini 资料卡背景、资料页背景均不显示 |
| 贵族座驾 | ≥ LV3 | LV3-LV6；进房播放，有声音；展示头像 + 名称；LV6 每 30 天额外获得 1 款定制座驾 |
| 升级广播 | ≥ LV3 | LV3-LV5 房间广播；LV6 全平台广播（见 §7） |
| 进房广播 | ≥ LV4 | 进房自动触发；开启进房隐身不触发；文案：主标「昵称」，副标「进入房间」 |
| 资料页特效 | ≥ LV5 | 佩戴的座驾在资料页播放（主态/客态）；未佩戴座驾不播放 |
| 贵族资料页背景 | ≥ LV6 | 佩戴定制背景展示定制样式；取消佩戴恢复普通背景；开启隐藏等级不影响主态展示 |

## 10. 房间内贵族列表

### 10.1 统计维度

- 统计**当前在房间内的贵族用户**
- 未获得贵族、进房隐身、隐藏贵族等级的用户**不展示**
- 打开页面刷新数据；切换 tab 不刷新；用户离房/被踢/退场后从列表移除

### 10.2 排序规则

1. 按贵族等级从高到低
2. 相同贵族等级按 VIP 等级排
3. 贵族和 VIP 等级都相同则随机排序

### 10.3 显示信息

- 头像（静态/动态）+ 头像框
- 房间身份标识（位置在名称前）
- 昵称（支持 VIP 彩色昵称；超长…截断）
- 标签：性别、VIP、贵族、财富等级
- 贵族 icon（支持动态）
- 翻页：30 条一翻页

### 10.4 吸底区

- 主态用户头像（支持动态；不支持头像框；不支持点击跳转）
- 贵族信息：未解锁显示「需要消费 💎x 解锁 {LV.1 贵族名称} 特权」；已解锁显示距下一等级所需消费值
- 点击消费信息 → 打开主态贵族页
- 送礼按钮 → 打开礼物面板

## 12. 隐藏贵族等级（隐身设置）

- 设置路径：贵族页面右上角更多 → 设置 → 隐身设置
- 开关默认**关闭**
- **解锁条件**：LV3 子爵及以上；未达到时提示「{LV.3 贵族等级} 解锁特权」并跳转对应贵族等级页面

**开启隐藏贵族等级后，以下位置隐藏贵族信息**：

mini 资料卡 / 个人资料页 / 全服榜（贡献/魅力/PK/CP/总榜）/ 房间榜（贡献/魅力/Room Boss）/ 在线成员 / 公屏发言 / 贵族列表（不显示该用户）/ 升级广播（不显示）/ 其他展示贵族标签的地方

**例外**：自己查看自己时，mini 资料卡、资料页、我的帧**不隐藏**贵族标签或勋章

## 13. 勋章展馆

## 15. 贵族实时更新要求
