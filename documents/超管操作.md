# 超管操作知识库

## 一、超管身份说明

超管（Super Admin）是平台层级最高的管理员，拥有对所有房间进行违规处置的权限。普通用户、主播及普通房管均无法触发超管操作。

---

## 二、超管操作入口

超管进入任意语音房间后，可在「关闭面板（Room Closing Panel）」中看到 **「Punish the room」** 操作入口。

- 非超管用户不展示「Punish the room」入口。

---

## 三、Punish the room 操作菜单

点击「Punish the room」后弹出操作菜单，各选项排列顺序如下：

| 顺序 | 操作项 | 说明 |
|------|--------|------|
| 1 | Reset Room Background | 重置房间背景 |
| 2 | Reset Room Welcome Message | 重置房间欢迎消息 |
| 3 | Reset Room Notice | 重置房间公告 |
| 4 | Reset Room Name | 重置房间名称 |
| 5 | Reset Room Avatar | 重置房间头像 |
| 6 | Cancel | 取消，关闭菜单 |

---

## 四、通用操作流程

所有重置操作均遵循以下统一流程：

1. 超管点击对应菜单项
2. 弹出**二次确认弹窗**，文案提示本次操作不可逆，请确认是否存在违规内容
3. 弹窗包含「Cancel」和「Confirm」两个按钮
   - 点击「Cancel」：关闭弹窗，内容不变
   - 点击「Confirm」：执行重置，即时生效
4. 重置后，对应内容清空为空

---

## 五、各操作详情

### 5.1 重置房间公告（Reset Room Notice）

- **触发条件**：房间公告内容存在违规
- **重置效果**：房间公告置为空，房间内及房间详情页均不展示原有内容
- **房主查看**：重置后房主进入房间，公告显示为空，历史违规内容不可见、不可恢复
- **IM 通知**：确认重置后，系统向房主下发官方 IM 通知
  - 通知文案（英文）：*Your room notice has been removed by the platform due to suspected violations. Please adhere to the platform rules and operate cautiously.*
  - 通知包含「Go to check >>」按钮，点击跳转至房主个人语音房；房间不存在时合理兜底处理
- **钉钉群同步**：操作完成后同步至对应钉钉审核群
  - 消息模板：
    ```
    房主uid：{uid}
    房间公告：{原始公告内容}
    ```

### 5.2 重置房间欢迎消息（Reset Room Welcome Message）

- **触发条件**：房间欢迎消息内容存在违规
- **重置效果**：欢迎消息置为空，新用户进入房间时不再展示欢迎消息
- **IM 通知**：确认重置后，系统向房主下发官方 IM 通知
  - 通知文案提示欢迎消息已被平台移除，请遵守平台规则
  - 通知包含「Go to check >>」按钮，点击跳转至房主个人语音房
- **钉钉群同步**：操作完成后同步至对应钉钉审核群
  - 消息模板：
    ```
    房主uid：{uid}
    房间欢迎消息：{原始欢迎消息内容}
    ```

### 5.3 重置房间背景（Reset Room Background）

- **触发条件**：房间背景图片存在违规
- **重置效果**：房间背景恢复为默认背景，原违规图片不再展示
- **备注**：当前需求未明确是否发送 IM 通知及钉钉群同步，待产品确认

### 5.4 重置房间名称（Reset Room Name）

- **触发条件**：房间名称内容存在违规
- **重置效果**：房间名称重置为空或平台默认名称，原违规名称不再展示
- **备注**：当前需求未明确是否发送 IM 通知及钉钉群同步，待产品确认

### 5.5 重置房间头像（Reset Room Avatar）

- **触发条件**：房间头像图片存在违规
- **重置效果**：房间头像重置为默认头像，原违规图片不再展示
- **备注**：当前需求未明确是否发送 IM 通知及钉钉群同步，待产品确认

## 六、IM 通知机制

| 字段 | 说明 |
|------|------|
| 发送时机 | 超管点击「Confirm」后即时触发 |
| 发送对象 | 被处置房间的房主 |
| 发送方 | 系统官方账号（官方通知） |
| 通知内容 | 说明被重置的内容类型 + 违规提示 + 「Go to check >>」跳转按钮 |
| 跳转目标 | 「Go to check >>」跳转至房主的个人语音房；房间不存在时合理兜底 |
| 时效要求 | 操作完成后即时下发，无明显延迟 |

> 当前已明确：重置房间公告、重置房间欢迎消息操作后会下发 IM 通知。
> 重置背景、名称、头像是否也需要 IM 通知，待产品确认。

---

## 七、钉钉群同步机制

| 字段 | 说明 |
|------|------|
| 触发条件 | 超管执行重置操作后 |
| 目标群 | 对应的平台审核钉钉群 |
| 消息格式 | 包含房主 uid 和被重置内容的原始值 |
| 目的 | 方便后续同步审核，调整违规处置策略 |

> 当前已明确：重置房间公告、重置房间欢迎消息后需同步钉钉群。
> 重置背景、名称、头像是否也需要钉钉同步，待产品确认。

---

## 八、边界与异常场景

| 场景 | 处理规则 |
|------|----------|
| 目标内容本身已为空 | 操作仍正常执行，不报错，状态维持为空 |
| 连续快速点击「Confirm」 | 只执行一次重置，防止重复触发 |
| 房主语音房已关闭时点击「Go to check >>」 | 合理兜底处理（提示房间已关闭或跳转至创建房间页），不崩溃 |

---

## 九、多语言 & RTL

- 操作菜单、二次确认弹窗文案、IM 通知内容均需支持：英语、阿语、土语、俄语
- 阿语下整体界面需支持 RTL 镜像布局

---

## 十、必查场景汇总

| 场景 | 关键验证点 |
|------|-----------|
| 超管身份验证 | 仅超管可见 Punish the room 入口 |
| 菜单顺序 | 5 项操作顺序固定，与 PRD 一致 |
| 二次确认弹窗 | 每个操作均有确认弹窗，文案提示不可逆 |
| 重置即时生效 | 确认后内容立即清空，无需刷新 |
| 房主 IM 通知（公告/欢迎消息） | 收到官方 IM，「Go to check >>」可跳转 |
| 钉钉群同步（公告/欢迎消息） | 同步消息包含 uid + 原始内容 |
| 空内容重置不报错 | 内容已空时仍可执行操作 |
| 多语言展示正确 | 英/阿/土/俄均无乱码 |
| 阿语 RTL 镜像 | 菜单与弹窗布局符合 RTL 规范 |
