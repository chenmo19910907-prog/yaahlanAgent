## 核心业务规则摘要（便于评审/写用例时快速对齐）

### A. 配置与后台

- **主题活动配置 key**：`themeActivityConfig`（见「主题房活动优化」Sheet 中 MSE 配置说明）。
- **超管「不推荐房间」自动关闭时长**：配置项 `noRecommendMinutes`，**默认 180（即 3 小时）**；开关在 3 小时内保持打开，超时后需退出房间再进可见关闭；**重复开关会重置 3 小时计时**。

### B. 房间设置 Banner（与主题房同版落地）

- 入口：**房间设置弹窗上方**新增 Banner 位；支持多图**左右滑动**、**尾部循环**、**自动轮播**；点击卡片完成跳转（GOTO/URL）。
- **版本控制**：Banner 可配置适配客户端版本；不符合版本可不展示；未配置版本则全版本展示。
- **后台类型**：Banner 类型含「房间设置」；样式可配置非榜单 / TOP3 / TOP1 / CP / PK；榜单维度可配置用户榜 / 房间榜 / 家族榜。

### C. 超管「不推荐房间」与列表关系

- **可见性**：仅超管在房间「关闭面板」可见该开关，默认关；非超管不可见。
- **持久化**：再次打开面板、解散/重建房间后仍保持上次开关状态（直至自动关闭逻辑生效）。
- **列表影响（与主题房列表联动）**：打开不推荐后，**推荐列表不展示该房间**；**主题房列表「正在进行」Tab 不展示**（用例注明「即将开始是否生效需确认」）；其他列表（热门/聊天/音乐/游戏、我的关注/加入/看过、主题房我的页、往期记录等）按用例描述为「正常展示」或「后续沟通不展示」——**以产品最终结论为准**。

### D. 主题房与 PK / 创建的互斥（活动优化 Sheet）

- **房间内存在 PK 时不可创建主题房**；结束 PK 后可创建。
- **乱斗 / 团战 / 1V1 PK**：若 PK 时段内存在「即将开始」的主题房活动，则**不可开启 PK**，Toast：`同一时间段有即将开始的活动，不可开启pk`；活动取消或结束后可恢复 PK（三种 PK 规则一致，用例见第一章合并小节）。

### E. 主题房活动列表（列表页 Sheet）

- **入口**：Game 页 Banner、房间列表 Banner、房间设置弹窗 Banner、创建房间菜单等均可进入主题房列表。
- **结构**：标题栏（返回、标题、历史记录、活动说明「？」）；**正在进行**默认 Tab，可与 **即将开始** 切换；支持**左右滑**切换到 **我的活动**（我创建 / 我预约）。
- **公开列表过滤**：密码房、已关闭、不接受公开预约、被超管不推荐、**热度为 0** 的房间不展示；热度非 0 但房内无人可展示；不推荐过期后可再展示。
- **排序**：默认按**热度值**从高到低；可切换为按**活动开始时间倒序**。
- **热度公式（用例原文）**：`热度 = 麦上人数×80% + 围观人数×20% + 钻石数×40%`（验证时需对照 MOA/服务端口径）；并有用例约定活动开始前收钻、开始后钻石计热度为 0 等边界。

### F. 详情 / 创建 / 修改 / 开始 / 结束（后文逐 Sheet 展开）

- **活动类型**：生日房 / 婚礼房 / 庆典房；卡片背景、图标、默认/上传背景、审核失败文案、上传图裁剪+70% 遮罩等见「创建」「修改」Sheet。
- **文案长度**：活动名称最多 **30** 字（不可换行）；活动说明最多 **200** 字；周期内同主题创建达上限 Toast：`本周期此主题创建已达上限`。
- **活动开始**：全房间活动开始特效；按类型进入对应主题模式；礼物挑战挂件隐藏、活动倒计时挂件出现（房主可见关闭按钮，他人可见「？」进规则）；房间上方活动榜单入口；多原始房间类型（聊天/音乐/游戏/CP/社交等）可开始活动；游戏房进行中开始活动会**关闭游戏**；麦位关闭则开始活动时**麦席重置**；闭麦用户状态**保持不变**；创建者/预约者收到开始私信（含固定文案与跳转）。
- **活动结束**：倒计时自然结束或房主挂件手动结束（二次确认文案见 Sheet）；房间类型恢复活动前类型；挂件与榜单按钮恢复；结束页含榜单样式（前三特殊、最多 50 名、贡献值 km 缩写等）。
