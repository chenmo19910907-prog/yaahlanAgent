# 谁看过我（Viewed me）功能知识库

> **更新时间**：2025年5月13日
> **数据来源**：钉钉 Excel 访客 Sheet + UI 截图及规则补充

---

## 一、红点气泡

### 1.1 红点规则

| 属性 | 说明 |
|------|------|
| 触发条件 | **有新用户**看过我时展示 |
| 红点数值 | 展示实际新增数量；**≤ 99 时展示实际数字，超过 99 时固定显示 `99+`** |
| 同步位置 | 同步展示在**底导 tab icon 右上角** |

### 1.2 红点消除时机

| 操作 | 底导 icon 红点 |
|------|--------------|
| 点击进入「谁看过我」列表，**退出后** | 消失 |
| 在列表内**触发下拉刷新**后退出 | 不展示 |
| 在列表内**未触发刷新**后退出（期间有新访客） | 仍展示 |

---

## 二、谁看过我 列表页

### 2.1 列表基本规则

| 规则 | 说明 |
|------|------|
| 展示上限 | **最多 200 条**，翻页无重复数据 |
| 超出上限提示 | 底部文案：「仅支持查看最近 200 条访客记录」 |
| 下拉刷新 | 支持 |

### 2.2 列表每行展示内容

每条访客记录展示：
- 用户**头像**（支持头像框）
- **昵称**
- **性别 + 年龄**
- **VIP 标签**
- **国家 icon**
- **语音房在房状态**
- 右侧**操作按钮**（发起聊天）

### 2.3 列表交互规则

| 交互 | 行为 |
|------|------|
| 点击头像 | 跳转至该用户的 profile 页 |
| 用户在语音房中 | 点击跳转至对应语音房 |
| 用户在**私密语音房**中 | 不展示在房状态 |
| 点击右侧按钮 | 跳转至与该用户的聊天对话页 |

### 2.4 红点与列表刷新联动

- 在访客列表查看中有新访客到来：
  - **未触发列表刷新** → 退出列表后，入口处仍展示红点气泡
  - **已触发下拉刷新** → 退出列表后，不展示红点气泡

## 三、详情页权限区分

> 所有用户均进入同一「谁看过我」详情页（页面标题：Viewed me），在页面内按 VIP 状态展示不同内容。

### 3.1 非会员（未开通 VIP）— 详情页

**列表区域**（列表仍可见，但内容模糊处理）：

| 元素 | 展示规则 |
|------|---------|
| 头像 | **模糊显示** |
| 昵称 | **隐藏**（不可读） |
| 标签（国家/性别年龄/称号/徽章） | 可见 |
| 右侧按钮 | **Unlock**（紫色） |

**页面底部升级卡片**（固定吸底）：

| 元素 | 说明 |
|------|------|
| 头像展示 | 展示最新看过我的 **3 名**用户头像 |
| 文案 | `Active VIP1 to view all people interested in you` |
| 按钮 | **Activate Now**（金色），点击跳转至 VIP 开通页 |

### 3.2 会员（已开通 VIP）— 详情页

**列表区域**（完整展示）：

| 元素 | 展示规则 |
|------|---------|
| 头像 | 清晰展示（支持头像框） |
| 昵称 | 正常显示 |
| 标签（国家/性别年龄/称号/徽章/在房状态） | 正常显示 |
| 右侧按钮 | **Chat**（紫色），点击跳转聊天页 |

- 无底部升级卡片

## 四、隐身查看资料

| 属性 | 说明 |
|------|------|
| 入口 | 隐身设置页面新增「隐身查看资料」开关 |
| 解锁条件 | **VIP 9 及以上**可使用 |
| 开启效果 | 开启后，浏览他人 profile 页时，**对方客态「谁看过我」页面中不显示本用户的访问记录** |
| 关闭效果 | 关闭后，**隐身期间的访问记录不会补录**；关闭后重新访问对方 profile，该次记录正常出现在对方「谁看过我」中 |

---

## 五、VIP 特权卡片

- VIP 详情页增加**访客特权卡片**
- 覆盖范围：**VIP 1、VIP 2、VIP 3** 均包含该特权项

---

## 六、数值统计规则

- 入口展示的数量为**所有人看过我个人页的总次数（PV）**，非 UV
- 同一用户多次访问**累计叠加**，不去重（以天为单位计 UV 的规则仅用于红点触发判断）

---

## 七、机器人逻辑

- 每日**北京时间 10:00**，系统随机安排机器人访问用户的 profile 页
- 机器人访问记录**会出现在访客列表中**，与真实访客相同展示

---

| 优先级 | 场景 |

| P0 | 详情页非VIP：列表头像模糊、昵称隐藏、右侧按钮为 Unlock；底部吸底卡片展示 3 个访客头像 + Activate Now 按钮 |

| P1 | 列表 200 条上限 + 超出底部提示文案 |
| P1 | 列表展示字段完整性（头像/昵称/性别/年龄/VIP/国家/在房状态/按钮） |
| P1 | 在房状态点击跳转语音房；私密房间不展示在房状态 |
