## 1. 等级体系与入口

VIP 共 10 个等级（VIP1 ～ VIP10），等级越高享有特权越多。

**入口**：个人页 / 个人资料页 / 幸运大转盘 / 弹窗

**个人页 VIP 图标**：
- 未获得任何等级：展示「解锁更多特权」
- 已获得等级：展示对应 VIP1-VIP10 样式图标

---

## 2. VIP 页面

### 展示逻辑

- 进入默认展示用户「即将达到的等级」，可右滑展示当前等级
- 根据当前等级，仅展示 **≥ 当前等级** 的等级页面
- 未达到任何等级时，进入展示 VIP1
- 达到 VIP9 仍展示 VIP10；达到最高 VIP10 只展示 VIP10
- 下发体验卡时，根据当前等级展示

### 页面结构

| 区域 | 说明 |
|------|------|
| 标题 | VIP |
| 左侧返回按钮 | 点击返回上一页 |
| 右侧问号 | 点击进入 VIP 成长值说明页，返回后回到 VIP 页面 |
| VIP 等级列表 | VIP1-VIP10；根据当前等级展示 ≥ 当前等级；支持点击和左右滑动；仅 VIP10 时展示正常 |
| 动物徽章 | 根据 UI 展示，有悬浮粒子特效，左右滑动与 VIP 等级联动 |
| 说明文字 | 当前等级：`Current Level: X`；高于当前等级：`Still need X growth points`；已达到：`You are VIP level X` |
| 是否解锁 | 当前等级：不展示锁按钮；高于当前等级：展示锁按钮 + Locked |
| 直升充值入口 | 在当前等级上方展示 |
| 体验卡 | 在当前等级上方展示，与直升充值入口同时展示时均正常 |

### 当前等级区

**非 VIP 用户**：
- 文案：「你还不是 VIP 哦，快升级体验 VIP 吧」
- 展示充值按钮，点击跳转 VIP 成长值页面 → 吊起充值弹窗

**VIP 用户**：
- 文案：`当前等级：X（X days）当前成长值 X`
- 符合保级规则时展示保级文案（与详情页一致）
- 展示「?」，点击展示有效性说明规则弹窗

## 3. 装扮（Outfit）

页面内标题：**Outfit**，含以下装扮道具，按等级逐步解锁：

| 道具 | 解锁等级 | 可点击 |
|------|---------|--------|
| VIP 勋章 | VIP1-VIP10 | ❌ |
| 聊天气泡 | VIP2-VIP10 | ❌ |
| 专属头像框 | VIP3-VIP10 | ❌ |
| VIP 礼物 | VIP4-VIP10 | ✅（点击播放礼物特效） |
| 个人背景 | VIP5-VIP10 | ❌ |
| 专属座驾 | VIP6-VIP10 | ✅（点击播放座驾特效，首次进入需预加载） |
| 入场条 | VIP8-VIP10 | ❌ |

- 支持自动轮播
- VIP 勋章、聊天气泡、专属头像框、个人背景、VIP 铭牌：不支持点击

## 4. 特权体系（共 39 项）

### 4.1 特权总览（按解锁等级）

| 解锁等级 | 特权 |
|---------|------|
| VIP1 起 | 贵宾徽章、VIP 客户服务、无限问候、谁看过我 |
| VIP2 起 | 昵称变色（VIP2-5 红色，VIP6-10 彩虹色）、在线列表优先展示、专属聊天气泡 |
| VIP3 起 | 专属靓号、隐藏等级、专属头像框 |
| VIP4 起 | 专属客户服务（WhatsApp）、VIP 礼物、动态头像、专属表情符号、等级保证特权、隐藏获奖消息 |
| VIP5 起 | 全服升级广播、专属资料卡（mini 资料卡背景）、个人背景、定制礼物、在线隐身 |
| VIP6 起 | 防踢、专属座驾 |
| VIP7 起 | 延长有效期（有效期 60 天）、榜单隐身、进房隐身 |
| VIP8 起 | 入场条、资料页座驾展示、定制座驾 |
| VIP9 起 | 进房广播、隐身访问、资料页 VIP 背景、mini 资料卡背景 |
| VIP10 专属 | 防禁言、VIP 铭牌、VIP 体验卡、自定义昵称特效、定制礼物 VIP 装扮、上线全平台广播 |

**页面展示**：标题 `Privilege X/39`（X = 已解锁数量）；已解锁高亮，未解锁置灰；点击特权弹出详情弹窗，弹窗支持左右滑动浏览全部特权

### 4.2 关键特权说明

**专属靓号**：
- VIP3-VIP7：自定义 6-7 位数 ID
- VIP8-VIP9：自定义 4-7 位数 ID
- VIP10：自定义 3-7 位数 ID
- 靓号字符支持大小写字母、数字、阿拉伯字母；其他字符保存时提示格式错误

**昵称变色**：VIP2-VIP5 红色，VIP6-VIP10 彩虹色

**防踢**：在语音房无法被低 VIP 等级用户踢出

**防禁言**（VIP10）：无法被房主和房间管理员禁言；超管可正常禁言

**VIP 铭牌**（VIP10）：
- 有效期与 VIP10 绑定（内网 5 min，正式 60 天）
- 默认佩戴；展示在 mini 资料卡和资料页铭牌第一位
- VIP10 过期后，其他铭牌展示正常

**VIP 体验卡**（VIP10）：每次完成升级或保级，获得 3 张 VIP5（7 天）体验卡，下发至背包，有效期 60 天

**上线全平台广播**（VIP10）：
- 每天可发布 1 次（按大区时间判断）
- 登录后主动弹出广播发布弹窗（可在隐身设置关闭弹窗，但不影响发布）
- 进房隐身状态下不展示广播
- 广播样式：用户静态头像 + 昵称 + VIP10 图标 + 文案「登录上线」

**定制礼物 VIP 装扮**（VIP10）：
- VIP10 的定制礼物在礼物面板展示时增加背景框 + 用户头像（支持动态头像，不支持头像框）
- VIP10 降级后：定制礼物背景框展示为默认，不展示头像
- VIP10 再次升级后：恢复 VIP 背景框 + 头像展示

**专属客户服务**（VIP4）：点击后打开 WhatsApp；未安装时 toast 提示「已复制 Whatsapp 客服号码，请到 Whatsapp 添加客服」

**资料页 VIP 背景**（VIP9-VIP10）：v2.4.0 及之后展示新样式，v2.4.0 之前展示老样式

## 6. VIP 成长值

| 获取方式 | 兑换比例 |
|---------|---------|
| 购买成长值 | 1 钻石 = 3 成长值 |
| 充值 | 1 钻石 = 1 成长值 |

- **最低消费**：1 钻石（购买 3 成长值）
- **成长值上限**：145M；达到上限后不再继续增加
- 购买时：展示升级到下一等级所需成长值及花费钻石；余额不足时展示当前余额可购买数量

**成长值说明页（VIP 规则页内容）**：什么是 VIP、如何获得成长值、各等级与成长值要求、VIP 有效期、到期后成长值调整规则

## 7. 有效期与保级降级

### 7.1 有效期

- VIP1-VIP6：默认有效期（由购买钻石决定）
- **VIP7+**：有效期 60 天（延长有效期特权）

### 7.2 保级门槛与衰减（VIP8-VIP10 才有保级逻辑）

| VIP 等级 | 升级所需成长值 | 保级所需成长值 | 到期衰减比例 | 到期后最低留存 |
|---------|-------------|-------------|-----------|-------------|
| VIP8 | 4,000 万 | 1,900 万 | 50% | 2,000 万 |
| VIP9 | 6,000 万 | 2,800 万 | 50% | 3,000 万 |
| VIP10 | 10,000 万 | 4,500 万 | 45% | 5,500 万 |

### 7.3 降级规则

不保级时，降至对应等级：

| 当前等级 | 降至 |
|---------|------|
| VIP10 | VIP8 |
| VIP9 | VIP8 |
| VIP8 | VIP7 |
| VIP7 | VIP6 |
| VIP6 | VIP4 |
| VIP5 | VIP3 |
| VIP4 | VIP2 |
| VIP3 | VIP0（无 VIP） |
| VIP2 | VIP0（无 VIP） |
| VIP1 | VIP0（无 VIP） |

| VIP7 | 专属头像框、专属聊天气泡、迷你资料卡、专属座驾（V6-7 下发老座驾） |

**体验卡等级规则**：
- 用户当前等级 = 体验卡等级：延长 VIP 有效期
- 用户当前等级 < 体验卡等级：优先展示体验卡等级，对应物料下发
- 用户当前无 VIP：体验卡直接生效，对应物料下发
- 同时持有同等级 VIP 和体验卡：可继续体验更高等级体验卡
