# 活动主题房

> **来源文档**：Yaahlan-2.1.3版本需求（https://alidocs.dingtalk.com/i/nodes/lyQod3RxJK3gjMmMhPa9dXBBJkb4Mw9r）
> **整理时间**：2026-05-09

---

## 一、功能概述

活动主题房是以用户房间为载体，用户根据特殊主题需求创建的房间模式。活动开始时，用户房间将以对应主题的活动房间模式呈现。

**首批上线主题**：生日房、婚礼房、庆典房（共 3 个）

---

## 二、核心规则

| 序号 | 规则 |
|------|------|
| 1 | 房间等级 ≥ 3 的用户可创建活动，支持白名单 |
| 2 | 每个用户每月每个主题可举办 1 次；不同主题频次支持配置；**取消 2 次算举办 1 次** |
| 3 | 同一房间同一时间段只能进行一个主题活动，两个活动必须间隔 1 分钟以上 |
| 4 | 密码房、关闭房、创建时选择不可公开预订的活动默认为**非公开活动**，不展示在"活动正在进行"页 |
| 5 | 解散房间时该房间的活动自动取消；**活动进行中不可解散房间**，toast 提示"活动正在进行中，不可解散房间" |
| 6 | 每个活动可修改 **3 次**，超出上限后无法修改 |
| 7 | 取消的活动不可恢复；每个主题可取消 **2 次**（取消 2 次算举办 1 次） |
| 8 | **距离活动开始 30 分钟内**不可修改和取消活动 |
| 9 | 只有房主可以结束活动，且需二次弹窗确认 |
| 10 | 活动期间不可切换其他模式，不可 PK，点击 toast 提示 |

## 四、核心页面

### 4.1 正在进行页

- 包含两个 Tab：**正在进行** + **即将开始**
- 展示所有用户创建的公开主题房；密码房、关闭房、不公开预约的、被超管不推荐的不显示

**正在进行 Tab 排序规则：**
- 默认按热度排序：热度 = 麦上人数 × 80% + 围观人数 × 20% + 钻石数 × 40%；热度为 0 不展示
- 可切换为"时间"排序，先展示最近开始的活动

**即将开始 Tab 排序规则：**
- 默认按时间排序，先展示即将开始的活动
- 可切换为"热度"排序，按预约人数排序

**其他：** 下拉手动刷新；进详情页返回不自动刷新；空页面文案：「没有更多信息，创建一个你自己的活动吧！」

---

### 4.2 我的页

包含两个 Tab：**已创建** + **已预约**

**已创建 Tab 排列顺序：**
1. 正在进行的
2. 创建的活动（按时间倒序）
3. 已取消的活动（按时间倒序）
4. 已结束的活动（按时间倒序）

**已预约 Tab 排列顺序：**
1. 正在进行的（按热度排序）
2. 已预约的活动（按时间倒序）
3. 已取消的活动（按时间倒序）
4. 已结束的活动（按时间倒序）

相同时间以活动 ID 排序，先展示最近创建的活动。

列表底部文案：「仅展示最近三个月的活动」

**空页面文案：**
- 已创建 Tab：「没有更多信息，创建一个你自己的活动吧！」
- 已预约 Tab：「您还没有预约任何活动，请前往"正在进行"页面。」

---

### 4.3 往期记录页

展示最近三个月已结束的公开主题房；列表底部文案：「仅展示最近三个月的活动」

---

### 4.4 活动说明页

- 展示对应主题房的介绍，包括创建规则、主题房专属内容（具体以翻译文档为准）
- 规则下方分 Tab 展示专属内容：房间主题麦位图、活动礼物、头像框
- Tab 支持左右滑动和点击切换；活动礼物、头像框一行展示，超过 3 个滚动轮播

---

### 4.5 活动卡片内容（通用）

| 字段 | 说明 |
|------|------|
| 活动角标 | 主题标识 |
| 活动类型 | 生日房/婚礼房/庆典房 |
| 活动名称 | — |
| 卡片背景 | — |
| 活动开始时间 | 活动进行中显示"正在进行中"；以用户当前时区展示；格式：年/月/日/时:分 |
| 预约人数 | 活动进行中显示"加入"按钮 |

**活动详情页额外字段：**
- 活动开始及结束时间（格式：年/月/日/时:分～年/月/日/时:分）
- 房间信息：房间名、房间 ID，点击进入房间
- 活动说明
- 创建者信息：头像（支持动态，不显示头像框）、昵称、国家、性别、VIP、财富、魅力；点击进入 Profile 页
- 已预约列表：同字段，按预约时间展示（后预约的在上方）；人数 0 时不展示列表标题
- 分享按钮、操作按钮（加入/预约/编辑）

---

### 4.6 活动详情页交互

| 场景 | 说明 |
|------|------|
| 活动进行中 | 展示"加入"按钮，点击进入房间 |
| 活动未开始 - 客态 | 展示"预约"按钮；预约成功 toast 提示，按钮更新为已预约；预约上限 2000，到达上限提示"活动预约人数已满" |
| 活动未开始 - 主态 | 展示"编辑"按钮，点击进入编辑页 |
| 已取消/已结束 | 不展示操作按钮和右上角"更多菜单" |
| 举报 | 仅客态展示更多菜单；举报成功 toast"举报成功"，失败 toast"举报失败，请重试" |
| 低版本用户 | 点击加入/预约/分享按钮 toast 提示"请升级最新版本" |

---

### 4.7 活动举报审核

- 审核后台展示内容：活动类型、活动卡片背景、活动名、活动说明、举报文字描述
- **举报成立后**：活动重置为默认设置（卡片背景→默认主题背景；活动名→生日派对/婚礼派对/盛典派对；活动说明→无）；官方号给创建者发送提醒消息；不占修改次数，不通知预约用户

---

### 4.8 活动分享页

- 展示好友列表：头像（支持动态，不显示头像框）、昵称、性别、VIP；上限 200 个
- 排序规则：最近分享过活动的好友 → 最近发过消息的好友 → 按最近上线时间
- 邀请：点击"邀请"成功提示"成功发送邀请"，按钮变为"已邀请"；失败提示"邀请失败，请重试"
- 搜索：模糊检索所有好友（ID/昵称包含即可）；最多输入 30 个字符；无结果展示"未找到该用户"
- 被邀请用户：收到邀请者发送的 1v1 IM 消息，点击跳转活动详情页
- 用户可被重复邀请；整个页面关闭后重新进入不记录已邀请状态
- 头像支持点击打开资料页

---

### 4.9 活动编辑页

**前置判断（点击"创建活动"时）：**
- 无房间用户 → toast"请先创建房间"
- 房间等级 < 3 → 弹窗提示
- 当前周期已达创建上限 → 弹窗提示
- 低版本用户 → toast"请升级最新版本"

**编辑字段：**

| 字段 | 规则 |
|------|------|
| 活动类型 | 默认选中第一个可创建主题；已达本周期上限的主题不可选中，点击 toast"本周期此主题创建已达上限" |
| 活动卡片背景 | 默认选中用户上次发布成功的背景；支持自定义上传（同步审核）；审核失败 toast"上传图片违反平台规定，请重新上传" |
| 活动名称 | 上限 30 字符；点击"更新"自动生成（对应主题活动名库） |
| 活动说明 | 上限 200 字符（选填） |
| 活动开始时间 | 默认为创建时间的 24 小时后；可选项从当前时间 30 分钟后起，最晚到当月最后一天；距活动开始 30 分钟内不可编辑 |
| 活动时长 | 1/2/3 小时，默认 1 小时 |
| 公开预约 | 默认开；关闭需弹窗二次确认 |

**点击"下一步"校验：**
- 审核活动名称和活动说明（含敏感词则 toast 提示）
- 开始时间距当前不满 30 分钟 → toast"活动开始时间需修改为 30 分钟后"
- 当前时段已有其他活动 → toast"同一时间段已有其他活动"
- 超出修改次数上限 → toast"超出修改次数，不可修改"

**删除活动：**
- 仅二次编辑时展示删除按钮；二次确认后返回活动详情页；所有预约用户收到取消提醒
- 距活动开始 30 分钟内不可删除

---

### 4.10 活动预览页

展示内容：活动卡片（角标/类型/名称/背景/开始结束时间）、房间信息、活动说明、创建者信息、发布按钮

- 首次创建：无二次确认弹窗；开始时间距当前不满 30 分钟 toast 提示
- 修改后发布：二次弹窗确认；所有预约用户收到活动修改提醒消息

## 五、活动主题房（房间内）

### 5.1 房间模式切换规则

| 事件 | 规则 |
|------|------|
| 活动开始 | 房间自动切换到主题房模式；主麦位为空；其他麦上用户维持在麦上 |
| 游戏/PK 自动结束 | 切换到主题房模式时游戏/PK 自动结束 |
| PK 开启时检查 | 如所选 PK 时长内有即将开始的活动，toast"同一时间段有即将开始的活动，不可开启 PK" |
| 活动结束 | 房间自动切换回聊天模式（CP 14 麦 → 普通 15 麦；社交房 → 普通 8 麦）；超出麦位数的用户自动下麦 |

### 5.2 活动期间界面

- 右上角展示对应主题活动标签，根据活动时长开始倒计时
- 倒计时右侧：非房主展示"？"（点击跳转活动说明页）；房主展示关闭按钮（提前结束需二次确认）
- 活动期间不可切换模式，不可 PK，点击 toast 提示

### 5.3 低版本兼容

| 场景 | 处理 |
|------|------|
| 低版本用户在麦上，活动模式切换 | 将低版本用户踢下麦，toast"房主切换新房间模式，请升级最新版本" |
| 低版本用户点击上麦 | toast"请升级最新版本体验" |
| 其他用户邀请低版本用户上麦 | toast"该用户版本不支持此模式" |
| 低版本用户被踢出房间 | 弹窗提示"房主切换新房间模式，请升级最新版本。" |

### 5.4 主题房专属内容

| 专属项 | 说明 |
|--------|------|
| 活动开始动效 | 活动时间到自动切换时展示；新用户进房时展示 |
| 主题背景 | 默认使用主题背景，用户可自行更换 |
| 麦位样式 | 生日房/庆典房：主麦位 1 + 20 麦位；婚礼房：主麦位 2 + 20 麦位 |
| DJ 麦位 | 20 麦位中第一个为 DJ，展示特殊头框（不显示自己的头框） |
| 麦位皮肤 | 根据房间等级展示 |
| 礼物面板 | 专属主题 Tab，包含礼物道具和头像框 |
| 音乐推荐列表 | 专属主题音乐推荐列表 |
| 房间外显角标 | 活动进行时，Room 帧展示 |

### 5.5 活动排行榜

| 字段 | 说明 |
|------|------|
| 展示元素 | 头像（支持动态，不显示头像框）、昵称、性别（不显示年龄）、VIP 等级、财富等级、贡献值（活动值） |
| 人数 | 最多 50 人 |
| 吸底显示 | 当前名次；未上榜显示"50+"；引导文案"当前第 x 名/暂未上榜"；送礼按钮 |
| 统计规则 | 统计本次活动中送礼用户数据；相同分值先达到的排前 |
| 空态 | 无人送礼时显示空态数据 |
| 关闭逻辑 | 点击弹窗外空白区域或左侧返回按钮，或结果弹窗出现时关闭 |

### 5.6 活动结束结果弹窗

- 按活动值高到低排列，展示前 50 名
- 展示名称、头像、活动值；TOP3 特殊样式，展示贡献值最多的送礼用户头像
- 点击头像无交互；支持动态头像，不显示头像框
- 关闭逻辑：仅点击关闭按钮可关闭，点击空白无法关闭；展示 1 分钟后自动关闭

## 六、IM 消息样式

### 6.1 1v1 私聊消息（活动分享）

邀请人发给被邀请人，内容包含：活动卡片背景、活动名称、"查看详情"按钮；点击整个区域进入活动详情页

### 6.2 官方消息（Yaahlan 助理发送）

| 类型 | 触发时机 | 发送对象 | 消息内容 |
|------|----------|----------|---------|
| 活动开始提醒 | 活动开始时间 | 活动创建者 + 活动预约者 | 卡片背景 + "你创建/你预约的活动开始啦" + 进入房间按钮；点击进入活动房间 |
| 活动修改/取消提醒 | 活动被修改或取消时 | 活动预约者 | 卡片背景 + "你预约的活动更新/取消啦" + 查看详情；点击进入活动详情页 |
| 活动重置提醒（举报判罚） | 举报判罚成立后 | 活动创建者 | 默认主题卡片背景 + "你创建的活动违反平台规定，已重置活动信息" + 查看详情 |

## 七、超管功能

### 7.1 "不推荐房间"开关

- 位置：超管房间关闭面板
- 默认状态：关
- 开启后：该房间 **3 小时内**不展示在以下推荐位置，3 小时后开关状态恢复为关：
  1. Room 帧 explore 列表
  2. 活动正在进行页

## 八、必查场景汇总

| 场景 | 关键验证点 |
|------|-----------|
| 创建门槛 | 房间等级 < 3 拦截；每月每主题 1 次上限；白名单不受限 |
| 时间规则 | 30 分钟内不可修改/取消/删除；两个活动间隔 ≥ 1 分钟 |
| 房间模式切换 | 活动开始时自动切主题模式；活动结束自动切回聊天模式；麦上人数超限自动下麦 |
| 取消/修改次数 | 取消 2 次 = 举办 1 次；修改上限 3 次 |
| 低版本兼容 | 踢下麦 + toast 提示；不可上麦 |
| 举报判罚 | 重置活动为默认设置；发送官方 IM；不占修改次数 |
| 公屏消息卡片 | 24 小时内首次进房推送；预约按钮交互正确 |
| 排行榜 | 热度计算公式；结果弹窗展示逻辑 |
| 超管不推荐开关 | 3 小时后自动关闭；影响 Room 帧和活动正在进行页 |
| 多语言 | 英/阿/土/俄全场景展示正确；阿语 RTL 镜像 |
