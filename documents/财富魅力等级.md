## 1. 等级体系概览

共三种等级，各自独立累计：

| 等级类型 | 最高等级 | 等级分组 | 累计方式 |
|---------|---------|---------|---------|
| 财富等级 | LV35 | 1-5、6-10、11-15、16-20、21-25、26-30、31-35（共7组） | 赠送礼物，1 钻石礼物 = 1 财富值 |
| 魅力等级 | LV35 | 同财富等级分组（7组） | 收到礼物，1 钻石礼物 = 1 魅力值 |
| 游戏等级 | LV21 | 1-3、4-6、7-9、10-12、13-15、16-18、19-21（共7组） | 游戏获得，1 钻石 = 1 游戏值 |

## 2. 财富值 / 魅力值积累规则

### 财富值（赠送礼物累计）

| 礼物类型 | 财富值计算 |
|---------|---------|
| 普通礼物 | 礼物价值 × 1（1:1） |
| 道具礼物 | 礼物价值 × 1（1:1） |
| 盲盒礼物 | 按礼物价格 1:1 |
| 幸运礼物 | 按礼物价格 1:1 |
| 背包礼物（有价值/无价值） | **不增加**财富值 |
| 免费礼物 | **不增加**财富值 |

### 魅力值（收到礼物累计）

| 礼物类型 | 魅力值计算 |
|---------|---------|
| 普通礼物 | 礼物价值 × 1（1:1） |
| 道具礼物 | 礼物价值 × 1（1:1） |
| 盲盒礼物 | 按礼物价格 1:1 |
| 幸运礼物 | 按礼物价格 1:1 |
| 背包礼物（有价值） | **不增加**魅力值 |
| 免费礼物 | **不增加**魅力值 |

> **历史老版本（兼容说明）**：老版本送/收礼物为 10:1 换算（即 10 钻石礼物 = 1 财富/魅力值）；免费礼物在老版本会增加财富/魅力值

## 3. 入口与页面结构

### 3.1 礼物面板入口

- **财富等级徽章**：礼物面板顶部展示，显示等级徽章 + 等级进度条
  - 进度条：根据当前财富值按比例显示；选中礼物时实时预览增量（1:1）
  - 选背包礼物时只展示当前进度，不预览增量
  - 点击徽章 → 打开「我的等级页面」锚点到财富等级 tab
- **我的特权入口（特权中心）**：
  - 首次打开礼物面板显示引导文案「特权中心全新上线」，5s 后消失或点击入口消失
  - 引导文案只触发一次（与账号无关，卸载重装后重新触发）
  - 点击 → 打开特权中心半屏页面

### 3.2 我的页面入口

- 入口区域展示财富等级 + 魅力等级徽章
- 无财富/魅力等级时，对应徽章不展示
- 只有其中一种时，只展示有的那种
- 点击入口 → 打开「我的等级页面」锚点财富等级 tab

### 3.3 等级徽章点击跳转规则

| 点击对象 | 跳转目标 |
|---------|---------|
| 财富等级徽章 | 我的特权页面，定位到财富等级 tab |
| 魅力等级徽章 | 我的特权页面，定位到魅力等级 tab |
| 游戏等级徽章 | 我的特权页面，定位到游戏等级 tab |

| 权益 | 解锁条件 | 说明 |
|------|---------|------|
| 财富徽章 | ≥ LV1 | 等级越高徽章越尊贵；7 组徽章样式 |
| 进场特效 | ≥ LV1 | 等级越高特效越尊贵；无需佩戴自动生效 |
| 升级广播 | ≥ LV1 | 等级越高广播范围越大（见 §8.2） |
| 头像框 | ≥ LV1 | 永久有效；等级越高框越尊贵 |
| 聊天气泡 | ≥ LV1 | 永久有效；等级越高气泡越尊贵 |
| 送礼装扮（托盘） | ≥ LV6 | 无需佩戴，解锁后自动生效；1-5 级显示默认灰蓝底图 |

## 10. 魅力等级页面

结构与财富等级页面相同（等级徽章、小图、说明文案、左右切换、权益区），差异如下：

- **累计方式**：收到礼物，1 钻石礼物 = 1 魅力值
- **未满级文案**：「升级 LV.X 需要 Y 魅力值」
- **满级文案**：「已解锁最高魅力等级」
- **权益**：展示原魅力等级权益内容（魅力值徽章，去掉 0 级，展示 1-35 级 7 个徽章）
- **切换等级时**：下方特权展示**不变**（不像财富等级会随等级切换）

### 魅力等级升级广播

| 等级范围 | 广播类型 | 可见范围 | 样式 |
|---------|---------|---------|------|
| 1-5 级 | 聊聊消息 | 仅自己可见 | 等级徽章 + {昵称} 魅力升级 LVx |
| 6-15 级 | 聊聊消息 | 当前房间所有人 | 等级徽章 + {昵称} 魅力等级升级 LVx |
| 16-30 级 | 房间广播 | 当前房间所有人 | 第一行：{昵称}；第二行：魅力升级 LV.x（无点击事件） |
| 31-35 级 | 全服广播 | 全平台（含在线用户） | 第一行：{昵称}；第二行：魅力升级 LV.x（动态展示；升级方在房间内点击跳转，不在房间不跳转） |

## 14. 送礼托盘展示规则

| 收礼人数 | 托盘布局 |
|---------|---------|
| 1 人 | 送礼人头像居中，收礼人头像居中 |
| 2 人 | 送礼人头像居中，展示 2 个收礼人头像 |
| 3 人 | 送礼人头像居左，展示 3 个收礼人头像 |
| > 3 人 | 送礼人头像居左，展示 3 个收礼人头像，第 3 个上方显示 x+（x = 收礼人数 - 3） |

- 托盘样式根据财富等级显示对应送礼装扮；1-5 级显示默认送礼装扮
- 送礼物数量：送多个时显示数量（送 1 个不加 x1 标注）
- 支持场景：房间 / 私聊 / 群聊 / 动态送礼 / 好友关系页面
