# 充值 / 提现测试要点

> 测试执行与环境约束，补充 `testcase-kb/充值提现转账.md` 产品规则。

## iOS 线上真实充值

| 项 | 说明 |
|---|---|
| **包来源** | **必须使用 App Store 下载的安装包** |
| **不适用** | TestFlight、企业签、内测/Ad Hoc、本地 Xcode 安装等非 App Store 渠道包，**不能**作为 iOS **线上真实充值**（Production IAP）的验收依据 |
| **原因** | 真实扣款与 App Store IAP 链路、收据校验与包签名/渠道绑定；非商店包行为与线上一致性无保证 |

验收 iOS 线上充值、复充、首充等与支付到账相关用例前，先确认设备上的 Yaahlan 来自 App Store「获取/更新」，而非测试分发渠道。
